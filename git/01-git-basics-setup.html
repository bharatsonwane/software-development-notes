P. Practical Assignment

L1 L2
Use a throwaway folder. Run commands yourself; paste outputs into comments in 01-practice.md or a notes file.

L1 Fundamental

P.1. Warm-up

  1. Install or confirm git --version.
  2. Set user.name and user.email (global or local).
  3. git init a demo repo and make one empty commit or add a README.

P.2. Core tasks

  1. clone vs init — Clone a public repo; note .git presence. Init another empty project.
  2. three areas — Edit a file; show status before add, after add, after commit.
  3. config list — git config --list --show-origin and identify where name/email come from.
  4. clone depth — Try a shallow clone and comment when you’d use it.

L2 Intermediate

P.3. Challenge

  1. Draw (ASCII) working tree → index → HEAD for your demo repo after one commit.
  2. Break something safely: unset user.email locally and see the commit error; fix it.

P.4. Self-check

  • I can init and clone.
  • I know what staging means.
  • I configured identity correctly.
