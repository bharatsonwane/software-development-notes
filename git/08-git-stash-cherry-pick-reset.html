P. Practical Assignment

L1 L2
Practice recovery commands on disposable commits.

L1 Fundamental

P.1. Warm-up

  1. Stash uncommitted work; pop it back.
  2. Cherry-pick one commit onto another branch.
  3. Reset --soft and --mixed on an unpushed commit (compare).

P.2. Core tasks

  1. stash list — Multiple stashes; apply a specific one.
  2. revert — Revert a published commit (new undo commit).
  3. restore — Discard file changes vs restore from HEAD.
  4. reflog — Find a “lost” commit SHA and recover.

L2 Intermediate

P.3. Challenge

  1. Create detached HEAD on purpose; create a branch to save work.
  2. Document reset --hard danger and a safer alternative.

P.4. Self-check

  • I use stash for WIP context switches.
  • I know reset/restore/revert differences.
  • I can use reflog.
