P. Practical Assignment

L1 L2
Practice recovery commands on disposable commits.

L1 Fundamental

P.1. Warm-up

  1. Stash uncommitted work; pop it back. ▾ Solution 
    # Stash uncommitted changes in working tree and staging
git stash -u # (-u includes untracked files)

# Switch branches or pull changes cleanly
git switch main && git pull

# Pop stashed changes back into working tree
git switch -
git stash pop
  2. Cherry-pick one commit onto another branch. ▾ Solution 
    # Cherry-pick a specific commit by SHA onto current branch
git switch main
git cherry-pick 7b8c9d0
# Applies exact commit changes to current branch with new commit SHA
  3. Reset --soft and --mixed on an unpushed commit (compare). ▾ Solution 
    # git reset comparison:
# 1. --soft: Moves HEAD back, leaves all changes in Staging Area
git reset --soft HEAD~1

# 2. --mixed (default): Moves HEAD back, unstages changes to Working Tree
git reset --mixed HEAD~1

P.2. Core tasks

  1. stash list — Multiple stashes; apply a specific one. ▾ Solution 
    # List all stashed changesets
git stash list
# stash@{0}: WIP on main: 7a8b9c feature
# stash@{1}: WIP on dev: 1d2e3f quick fix

# Apply specific stash without dropping it from the stash stack
git stash apply stash@{1}
  2. revert — Revert a published commit (new undo commit). ▾ Solution 
    # Safely undo a published commit by generating a new inverse commit:
git revert 4d5e6f -m "revert: rollback broken authentication patch"
git push origin main
  3. restore — Discard file changes vs restore from HEAD. ▾ Solution 
    # Discard uncommitted changes in working tree (Git 2.23+):
git restore broken-file.js

# Unstage a file from staging back to working tree:
git restore --staged config.json
  4. reflog — Find a “lost” commit SHA and recover. ▾ Solution 
    # Find "lost" commits after bad reset using Reflog:
git reflog
# 1a2b3c4 HEAD@{0}: reset: moving to HEAD~1
# 5d6e7f8 HEAD@{1}: commit: important work was here!

# Recover the lost commit by branching from its SHA:
git branch recovered-work 5d6e7f8

L2 Intermediate

P.3. Challenge

  1. Create detached HEAD on purpose; create a branch to save work. ▾ Solution 
    # Enter detached HEAD (checkout raw commit SHA instead of branch)
git checkout 5d6e7f8
# Make test changes and commit:
git commit -am "test: experimental trial"

# Save work before switching away by creating a real branch:
git switch -c feature/experimental-saved
  2. Document reset --hard danger and a safer alternative. ▾ Solution 
    /*
git reset --hard Dangers & Safe Alternatives:
- DANGER: git reset --hard permanently erases all uncommitted changes in your working tree with NO way to recover them!
- SAFE ALTERNATIVES:
  1. Stash first: git stash -u before running any reset.
  2. Use git restore to discard only specific files.
  3. Create backup branch: git branch backup-before-reset
*/

P.4. Self-check

  • I use stash for WIP context switches.
  • I know reset/restore/revert differences.
  • I can use reflog.
