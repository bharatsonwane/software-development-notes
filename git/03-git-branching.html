P. Practical Assignment

L1 L2
Create throwaway branches; delete them when done.

L1 Fundamental

P.1. Warm-up

  1. Create and switch to feature/demo.
  2. List branches; rename one.
  3. Make a commit on the feature branch.

P.2. Core tasks

  1. switch — Move between main and feature without losing work.
  2. upstream — Set upstream when pushing (even to a local “remote” or document the flag).
  3. delete — Delete a merged vs unmerged branch (safe flags).
  4. orphan sketch — Comment when orphan branches are used.

L2 Intermediate

P.3. Challenge

  1. Simulate two features in parallel branches; switch and show log per branch.
  2. Explain in comments what HEAD points to after each switch.

P.4. Self-check

  • I create/switch/delete branches safely.
  • I know branch vs commit.
  • I avoid long-lived unpushed chaos.
