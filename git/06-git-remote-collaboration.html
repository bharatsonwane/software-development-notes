P. Practical Assignment

L1 L2
Use GitHub/GitLab or a second local bare repo as “remote”.

L1 Fundamental

P.1. Warm-up

  1. Add a remote; git remote -v.
  2. Push a branch; set upstream.
  3. Fetch and see new remote-tracking branches.

P.2. Core tasks

  1. pull — Pull with merge vs rebase; note the difference.
  2. PR sketch — Open or describe a PR with base/compare.
  3. fork model — Comment your fork → upstream sync steps.
  4. delete remote branch — After merge, delete remote feature branch.

L2 Intermediate

P.3. Challenge

  1. Simulate two clones collaborating on one bare remote.
  2. Recover from rejected non-fast-forward push safely (pull --rebase then push).

P.4. Self-check

  • I use remotes confidently.
  • I push/pull without panic.
  • I understand PR basics.
