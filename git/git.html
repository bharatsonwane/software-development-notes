Learning Path

Read files in numbered order 01 → 11. For each pass, stay at one depth across many concepts instead of finishing one file to L3 first.

Pass 1 → L1 across 01–11   What is it, and how do I use it?
Pass 2 → L2 across 01–11   How does it behave?
Pass 3 → L3 across 01–11   How does it work in complex cases?
Each file uses 1. Introduction, numbered topics, then C. Common questions and P. Practical Assignment. Practice in a throwaway repo; jot commands in NN-practice.md.
