P. Practical Assignment

L1 L2
Practice merges in a local-only repo first.

L1 Fundamental

P.1. Warm-up

  1. Branch, commit on both sides, merge feature into main. ▾ Solution 
    # Merge feature branch into main
git switch main
git merge feature/user-profile
  2. Create a conflict on purpose; resolve it. ▾ Solution 
    # Creating and resolving a merge conflict:
# 1. When Git encounters conflicting changes on the same lines, it pauses:
# "CONFLICT (content): Merge conflict in config.js"

# 2. Open file, manually remove conflict markers (<<<<<<<, =======, >>>>>>>)
# 3. Stage resolved file and complete merge:
git add config.js
git commit -m "merge: resolve conflict in config.js"
  3. Abort a merge mid-conflict once for practice. ▾ Solution 
    # Aborting a conflicted merge and returning working directory to pre-merge state:
git merge --abort

P.2. Core tasks

  1. fast-forward — Show a FF merge. ▾ Solution 
    # Fast-Forward Merge:
# Occurs when main has no new commits since the branch was created.
# Git simply moves the 'main' pointer forward without creating a merge commit.
git switch main
git merge feature/linear-task
# Output: "Updating 3a4b5c..6d7e8f Fast-forward"
  2. no-ff — Force a merge commit and compare history. ▾ Solution 
    # Forcing a merge commit (--no-ff) to preserve branch topology:
git switch main
git merge --no-ff feature/linear-task -m "merge: merge feature/linear-task into main"
  3. conflict markers — Resolve keeping both changes intentionally. ▾ Solution 
    /*
Conflict Marker Anatomy & Resolution:
<<<<<<< HEAD (Current branch: main)
const API_URL = "https://api.prod.com";
=======
const API_URL = "https://api.staging.com";
const TIMEOUT = 5000;
>>>>>>> feature/api-update

Resolved combination:
const API_URL = "https://api.prod.com";
const TIMEOUT = 5000;
*/
  4. merge tool — Note your preferred conflict editor. ▾ Solution 
    # Setting default merge conflict resolution tool (e.g. VS Code):
git config --global merge.tool code
git config --global mergetool.code.cmd 'code --wait "$MERGED"'

# Launch tool during conflict:
git mergetool

L2 Intermediate

P.3. Challenge

  1. Document the difference between merge commit and FF with two ASCII graphs. ▾ Solution 
    /*
Fast-Forward vs Merge Commit (--no-ff):

Fast-Forward (Linear History):
A --- B --- C (main, feature)

Merge Commit (--no-ff):
A --- B ──────── M (main)
       \       /
        C ─── D (feature)
*/
  2. Undo a merge with git revert -m 1 (after merge commit) or explain reset if unpushed. ▾ Solution 
    # Undoing an already pushed merge commit:
# -m 1 specifies that parent 1 (mainline branch) is kept as the baseline
git revert -m 1 <MERGE_COMMIT_SHA> -m "revert: rollback bad merge from release/v1.0"
