P. Practical Assignment

L1 L2
Practice merges in a local-only repo first.

L1 Fundamental

P.1. Warm-up

  1. Branch, commit on both sides, merge feature into main.
  2. Create a conflict on purpose; resolve it.
  3. Abort a merge mid-conflict once for practice.

P.2. Core tasks

  1. fast-forward — Show a FF merge.
  2. no-ff — Force a merge commit and compare history.
  3. conflict markers — Resolve keeping both changes intentionally.
  4. merge tool — Note your preferred conflict editor.

L2 Intermediate

P.3. Challenge

  1. Document the difference between merge commit and FF with two ASCII graphs.
  2. Undo a merge with git revert -m 1 (after merge commit) or explain reset if unpushed.

P.4. Self-check

  • I can merge and resolve conflicts.
  • I know FF vs merge commit.
  • I can abort a bad merge.
