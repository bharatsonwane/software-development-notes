P. Practical Assignment

L1 L2
Only rebase commits you have not shared (or coordinate carefully).

L1 Fundamental

P.1. Warm-up

  1. Rebase a feature branch onto updated main (local).
  2. Compare merge vs rebase histories visually.
  3. Run rebase -i and squash two commits.

P.2. Core tasks

  1. onto — Rebase onto a different base.
  2. conflict during rebase — Resolve and --continue.
  3. abort — Abort a rebase once.
  4. golden rule — Write when not to rebase.

L2 Intermediate

P.3. Challenge

  1. Interactive rebase: reword + drop one commit in a 4-commit branch.
  2. Explain force-push need after rebase of a published branch — and safer alternatives.

P.4. Self-check

  • I know rebase vs merge.
  • I can interactive-rebase locally.
  • I do not rewrite shared history casually.
