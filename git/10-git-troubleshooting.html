P. Practical Assignment

L1 L2
Break and fix in a playground repo — do not practice --hard on real work without a backup branch.

L1 Fundamental

P.1. Warm-up

  1. Enter detached HEAD; create a branch to keep the commit.
  2. Commit on wrong branch; move the commit with cherry-pick or reset.
  3. Use reflog to find yesterday’s tip.

P.2. Core tasks

  1. error catalog — Reproduce “refusing to merge unrelated histories” or document the fix.
  2. corrupt index — Comment recovery: git reset / remove index cautiously.
  3. permission denied (publickey) — Checklist for SSH failures.
  4. large file — What to do if you committed a huge binary.

L2 Intermediate

P.3. Challenge

  1. Write a personal runbook: 8 recovery commands with one-line purpose.
  2. Practice: undo last commit keeping changes, then redo cleanly.

P.4. Self-check

  • I recognize detached HEAD.
  • I recover with reflog.
  • I read Git errors calmly.
