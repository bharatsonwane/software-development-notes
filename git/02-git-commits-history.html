P. Practical Assignment

L1 L2
Practice commit hygiene. Prefer small, focused commits.

L1 Fundamental

P.1. Warm-up

  1. Stage part of changes with git add -p (or add specific files).
  2. Write a commit with a clear subject line.
  3. View git log --oneline and git show.

P.2. Core tasks

  1. diff — Unstaged vs staged vs last commit diffs.
  2. amend — Fix the last commit message (unpushed only).
  3. gitignore — Ignore .env and a dist/ folder; prove they stay untracked.
  4. log graph — git log --graph --oneline --all.

L2 Intermediate

P.3. Challenge

  1. Rewrite 3 bad commit messages into good ones (as comments).
  2. Recover an “almost lost” change: commit, reset soft, recommit differently.

P.4. Self-check

  • I stage intentionally.
  • I write useful commit messages.
  • I use gitignore for secrets/build output.
