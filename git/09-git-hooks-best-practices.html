P. Practical Assignment

L1 L2
Use a sample repo; hooks are local unless shared via a framework.

L1 Fundamental

P.1. Warm-up

  1. List hooks in .git/hooks.
  2. Enable a sample pre-commit that rejects WIP in the message.
  3. Write a conventional commit example set.

P.2. Core tasks

  1. commit-msg — Enforce subject length or prefix.
  2. secrets — Checklist of files that must never be committed.
  3. pre-commit framework — Note or install pre-commit.com style config (optional).
  4. signed commits — Comment when GPG/SSH signing helps.

L2 Intermediate

P.3. Challenge

  1. Design a minimal team hook policy (what runs locally vs CI).
  2. Show how to bypass a hook and why you usually should not.

P.4. Self-check

  • I know what hooks can enforce.
  • I follow commit message conventions.
  • I keep secrets out of git.
