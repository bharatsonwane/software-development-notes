Learning Path

Read files in numbered order. For each pass, stay at one depth across many concepts instead of finishing one file to L5 first.

Pass 1 → L1 across this track   What is it?
Pass 2 → L2 across this track   How do I use it?
Pass 3 → L3 across this track   How does it behave?
Pass 4 → L4 where useful   complex / internals
Pass 5 → L5 only where deeper knowledge is useful
