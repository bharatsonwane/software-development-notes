07. Type Narrowing & Guards

File 07 — typeof, instanceof, truthiness, type predicates, in.

1. Introduction

L1

L1 Fundamental

1.1. Overview

  • Narrowing refines a broad type to a specific one inside a branch so TypeScript allows safe operations.
function print(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase()); // string
  } else {
    console.log(value.toFixed(2));    // number
  }
}

1.2. Default rules and how to study this file

  • Default rule today: enable strict when you can; prefer precise types over any.
  • After reading sections 2–5, complete P. Practical Assignment in 07-practice.ts before File 08. Review C. Common questions.

2. typeof and instanceof narrowing

L1 L2

L1 Fundamental

2.1. typeof (primitives)

  • Works well for: string, number, boolean, bigint, symbol, undefined, function.
function assertString(x: unknown) {
  if (typeof x === "string") {
    x.length; // OK
  }
}

2.2. instanceof (objects / classes)

class ApiError extends Error {
  statusCode: number;
  constructor(message: string, statusCode: number) {
    super(message);
    this.statusCode = statusCode;
  }
}

function handle(err: unknown) {
  if (err instanceof ApiError) {
    console.log(err.statusCode);
  } else if (err instanceof Error) {
    console.log(err.message);
  }
}
  • instanceof checks the prototype chain — useful for class instances, not plain object shapes.

L2 Intermediate

  • Caveat: typeof null === "object" in JavaScript — combine with null check:
if (typeof value === "object" && value !== null) {
  // object (not null)
}

3. Truthiness narrowing

L1 L2

L1 Fundamental

  • Falsy values in JS: false, 0, -0, 0n, "", null, undefined, NaN.
function printName(name: string | null | undefined) {
  if (name) {
    console.log(name.toUpperCase());
  }
}

L2 Intermediate

3.1. Equality narrowing

function example(x: string | number, y: string | boolean) {
  if (x === y) {
    // x and y are both string here
  }
}

3.2. == null / != null

  • Checks both null and undefined:
if (value != null) {
  // value is neither null nor undefined
}

4. Type predicates (is)

L1 L2

L1 Fundamental

  • A type predicate tells TypeScript a boolean function narrows the type:
interface Fish {
  swim: () => void;
}

interface Bird {
  fly: () => void;
}

function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined;
}

function move(pet: Fish | Bird) {
  if (isFish(pet)) {
    pet.swim();
  } else {
    pet.fly();
  }
}

L2 Intermediate

  • Custom guards are essential for discriminated unions without a single tag field:
function isSuccess<T>(
  result: { ok: true; data: T } | { ok: false; error: string }
): result is { ok: true; data: T } {
  return result.ok === true;
}

L3 Advanced

4.2. Assertion Functions (asserts val is T)

  • Assertion Functions throw an error if a check fails, and instruct TypeScript to narrow the variable across the remaining execution flow without requiring an if/else block:
// 1. Asserting non-null / specific type:
function assertIsDefined<T>(val: T): asserts val is NonNullable<T> {
  if (val === null || val === undefined) {
    throw new Error(`Expected defined value, got ${val}`);
  }
}

// 2. Asserting a boolean condition:
function assertCondition(condition: boolean, msg: string): asserts condition {
  if (!condition) throw new Error(msg);
}

function processUser(id: string | null) {
  assertIsDefined(id);
  // id is automatically narrowed to 'string' for the rest of the scope!
  console.log(id.toUpperCase());
}

5. in operator narrowing

L1 L2

L1 Fundamental

  • Check if a property exists on an object:
type Cat = { meow: () => void };
type Dog = { bark: () => void };

function speak(pet: Cat | Dog) {
  if ("meow" in pet) {
    pet.meow();
  } else {
    pet.bark();
  }
}
  • Works with discriminated unions:
type Action =
  | { type: "increment"; amount: number }
  | { type: "reset" };

function reducer(state: number, action: Action): number {
  switch (action.type) {
    case "increment":
      return state + action.amount;
    case "reset":
      return 0;
  }
}

L2 Intermediate

5.1. Assignment narrowing

let x: string | number = "hello";
x = 42; // now narrowed to number in following code

5.2. Control flow analysis

  • TypeScript tracks narrowing across if, else, switch, early return, and throw:
function process(value: string | null) {
  if (!value) {
    return;
  }
  // value is string here
  console.log(value.length);
}

C. Common questions

L1 L2

L1 Fundamental

C.1. What is narrowing? ▾ Answer

Refining a union or unknown to a specific type inside a conditional branch.

C.2. What is a type predicate? ▾ Answer

Return type arg is Type on a boolean function — custom narrowing for TS.

L1 Fundamental

C.3. typeof vs instanceof? ▾ Answer

typeof for primitives (and functions). instanceof for class instances.

C.4. How do I narrow unknown from JSON.parse? ▾ Answer

Validate with typeof, Array.isArray, custom type guards, or libraries like Zod/io-ts.

C.5. Can I assert a type without narrowing? ▾ Answer

Type assertions (as Type) force TS to trust you — no runtime check. Prefer guards when data is external.

L2 Intermediate

C.6. Why doesn't typeof narrow null correctly? ▾ Answer

JS quirk — typeof null === "object". Always add value !== null.

C.7. Does narrowing work across function boundaries? ▾ Answer

Generally no — TS does not track mutations on outer variables inside nested functions (unless const or proven immutable).

C.8. What is discriminant narrowing? ▾ Answer

Switching on a shared field (kind, type, status) to narrow tagged unions (File 05).

  1. typeof narrow. ▾ Solution 
    function padLeft(value: string, padding: number | string): string {
  if (typeof padding === "number") {
    return " ".repeat(padding) + value; // Narrowed to number
  }
  return padding + value; // Narrowed to string
}

console.log(padLeft("Hello", 4));
console.log(padLeft("World", ">> "));
  2. instanceof narrow. ▾ Solution 
    function processDate(input: Date | string) {
  if (input instanceof Date) {
    console.log("Date year:", input.getFullYear()); // Narrowed to Date instance
  } else {
    console.log("String date:", input.slice(0, 4));  // Narrowed to string
  }
}

processDate(new Date());
processDate("2026-09-13");
  3. truthiness filter nulls. ▾ Solution 
    const rawList: (string | null | undefined)[] = ["Alice", null, "Bob", undefined, "Charlie"];

// Filter truthy values:
const validNames: string[] = rawList.filter((item): item is string => Boolean(item));
console.log("Clean names:", validNames); // ["Alice", "Bob", "Charlie"]

P.2. Core tasks

  1. isString predicate. ▾ Solution 
    // User-Defined Type Guard with 'val is string' return type
function isString(val: unknown): val is string {
  return typeof val === "string";
}

function printUpperCase(val: unknown) {
  if (isString(val)) {
    console.log(val.toUpperCase()); // Safely typed as string
  } else {
    console.log("Not a string");
  }
}

printUpperCase("typescript");
printUpperCase(42);
  2. in operator narrow. ▾ Solution 
    type Fish = { swim: () => void };
type Bird = { fly: () => void };

function moveAnimal(animal: Fish | Bird) {
  if ("swim" in animal) {
    animal.swim(); // Narrowed to Fish
  } else {
    animal.fly();  // Narrowed to Bird
  }
}

moveAnimal({ swim: () => console.log("Swimming...") });
  3. discriminant equality. ▾ Solution 
    type NetworkState =
  | { state: "loading" }
  | { state: "failed"; code: number }
  | { state: "success"; response: string };

function logStatus(s: NetworkState) {
  if (s.state === "success") {
    console.log("Success payload:", s.response);
  } else if (s.state === "failed") {
    console.log("Failed with code:", s.code);
  } else {
    console.log("Still loading...");
  }
}
  4. never default helper. ▾ Solution 
    function assertNever(x: never): never {
  throw new Error(`Unexpected value: ${JSON.stringify(x)}`);
}

function evaluateState(s: NetworkState) {
  switch (s.state) {
    case "loading": return "Loading...";
    case "failed": return `Error ${s.code}`;
    case "success": return s.response;
    default: return assertNever(s); // Exhaustiveness check
  }
}

L2 Intermediate

P.3. Challenge

  1. User|Admin guards. ▾ Solution 
    interface RegularUser {
  id: number;
  name: string;
}

interface SuperAdmin extends RegularUser {
  permissions: string[];
}

function isAdmin(user: RegularUser | SuperAdmin): user is SuperAdmin {
  return "permissions" in user && Array.isArray((user as SuperAdmin).permissions);
}

const u: RegularUser | SuperAdmin = { id: 1, name: "Bharat", permissions: ["root"] };
if (isAdmin(u)) {
  console.log("Admin permissions:", u.permissions.join(", "));
}
  2. Replace bad assertion with guard. ▾ Solution 
    // Avoid dangerous 'as' type assertions without validation:
// DANGEROUS:
// const data = JSON.parse(str) as User; // If JSON is malformed, crashes at runtime!

// SAFE: Type guard validation
function isValidUser(obj: any): obj is RegularUser {
  return typeof obj === "object" && obj !== null && typeof obj.id === "number" && typeof obj.name === "string";
}

const parsed: unknown = JSON.parse('{"id": 10, "name": "Dave"}');
if (isValidUser(parsed)) {
  console.log("Safely verified user name:", parsed.name);
}
