Learning Path

Read files in order 01 → 12. For each pass, stay at one depth across many concepts instead of finishing one file to L5 first.

Pass 1 → L1 across 01–12   What is it?
Pass 2 → L2 across 01–12   How do I use it?
Pass 3 → L3 across 01–12   How does it behave?
Pass 4 → L4 where useful   complex / internals
Pass 5 → L5 only where deeper knowledge is useful
Each file uses relative section numbers like 1., 1.1., and 1.1.1. within that file.
