3. Storage APIs

L1 L2

L1 Fundamental

3.1. localStorage and sessionStorage

localStorage.setItem("theme", "dark");
localStorage.getItem("theme");
localStorage.removeItem("theme");
localStorage.clear();

sessionStorage.setItem("tab", "1");  // cleared when tab closes

L1 Fundamental

  • Values are strings — JSON.stringify / parse for objects. Same-origin only.

L2 Intermediate

3.2. Cookies

  • Small key-value strings sent with HTTP requests — set via document.cookie or server Set-Cookie. Prefer httpOnly cookies for auth tokens (not accessible from JS).
  • Attributes: Secure, SameSite=Lax|Strict|None (CSRF), Path, Max-Age.
  • localStorage is typically ~5MB per origin; cookies are much smaller (~4KB each) and go on every matching request.

4. Fetch & AbortController

L1 L2

L1 Fundamental

4.1. Fetch API

const res = await fetch("/api/users", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Ada" }),
});
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();

4.2. History, URL, and encoding

history.pushState({}, "", "/new-path");
history.replaceState({}, "", "/other");

const url = new URL("https://example.com/path?q=1");
url.searchParams.get("q");      // "1"
url.searchParams.set("q", "hi there");
url.pathname;

encodeURIComponent("a b&c");    // "a%20b%26c" — query values
encodeURI("https://ex.com/a b"); // encodes less — whole URLs
decodeURIComponent("%20");
  • React Router wraps History API (React File 09).

4.3. FormData

const fd = new FormData(formElement);
fd.append("file", fileBlob, "photo.jpg");

await fetch("/upload", { method: "POST", body: fd });
// do not set Content-Type — browser sets multipart boundary

L2 Intermediate

4.4. AbortController

  • Cancel in-flight fetch:
const controller = new AbortController();
fetch("/api/slow", { signal: controller.signal });
controller.abort();  // rejects with AbortError

await fetch(url, { signal: AbortSignal.timeout(5_000) });
await fetch(url, { signal: AbortSignal.any([userAbort.signal, AbortSignal.timeout(5_000)]) });

5. Event handling

L1 L2

L1 Fundamental

5.1. Event delegation

  • One listener on parent handles events from children:
document.querySelector("#list").addEventListener("click", (e) => {
  if (e.target.matches("li.item")) {
    console.log("Clicked", e.target.dataset.id);
  }
});
  • Efficient for dynamic lists — fewer listeners.

5.2. stopPropagation and preventDefault

function onClick(e) {
  e.stopPropagation();  // don't bubble further
  e.preventDefault();   // don't default action (e.g. form submit, link nav)
}
  • React: e.stopPropagation(), e.preventDefault() on synthetic events (React File 03).

5.3. Custom events

const event = new CustomEvent("user-login", { detail: { id: 1 } });
window.dispatchEvent(event);

window.addEventListener("user-login", (e) => {
  console.log(e.detail.id);
});

L2 Intermediate

5.4. Bubbling and capturing

  • Events flow capture (window → target) then bubble (target → window). Default listeners run on bubble phase.
el.addEventListener("click", handler);                    // bubble (default)
el.addEventListener("click", handler, { capture: true }); // capture

5.5. Event properties and options

  • e.target — element that originated the event. e.currentTarget — element the listener is attached to (useful in delegation).
  • e.stopPropagation() — stop further bubbling/capturing. e.stopImmediatePropagation() — also skip other listeners on the same node.
  • e.composedPath() — full path including shadow DOM hosts (File 28).
  • { passive: true } — promises not to call preventDefault; improves scroll/touch performance. Browser may treat touch/wheel as passive by default on some targets.
list.addEventListener("click", (e) => {
  console.log(e.target);         // clicked child
  console.log(e.currentTarget);  // #list
  e.stopImmediatePropagation();
});

window.addEventListener("touchstart", onTouch, { passive: true });
window.addEventListener("wheel", onWheel, { passive: false }); // need preventDefault

6.1. Observers

APIFires when
MutationObserverDOM nodes are added/removed/changed

ResizeObserverAn element's size changes
 
const io = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (e.isIntersecting) loadMore();
  }
});
io.observe(sentinel);

6.2. Web Workers (brief)

  • A Worker is a separate thread — no DOM access. Talk via postMessage. Use for CPU-heavy work so the UI stays responsive (File 21 — one JS thread per context).
const w = new Worker("./heavy.js", { type: "module" });
w.postMessage({ n: 1e8 });
w.onmessage = (e) => console.log(e.data);

C. Common questions

L1 L2

L1 Fundamental

6.1. localStorage vs sessionStorage?

  • A: localStorage persists until cleared. sessionStorage clears when the tab closes.

6.2. DOM vs BOM?

  • A: DOM — document tree (elements). BOM — browser chrome (window, location, history, navigator).

L1 Fundamental

6.3. What is event delegation?

  • A: Attach one handler to a parent and use event.target to handle child events — good for dynamic lists.

6.4. What does preventDefault do?

  • A: Cancels the browser's default action (submit form, follow link).

6.5. What is AbortController for?

  • A: Cancel fetch or other abortable APIs — avoids race conditions when user navigates away.

L2 Intermediate

6.6. What is event bubbling?

  • A: Event propagates from target up through ancestors after the target handler runs.

6.7. encodeURI vs encodeURIComponent?

  • A: encodeURIComponent encodes &, =, ? — use for query values. encodeURI leaves URL structure intact.

6.8. When do I use IntersectionObserver?

  • A: When you need to know if an element is on screen — lazy images, infinite scroll — without scroll listeners.

6.9. target vs currentTarget?

  • A: target is where the event started; currentTarget is the element the listener is on (parent in delegation).

6.10. What is a passive listener?

  • A: { passive: true } promises you will not call preventDefault — helps scroll/touch performance. Use passive: false only when you must cancel the default.
