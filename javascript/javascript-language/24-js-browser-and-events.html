1. Introduction

L1

L1 Fundamental

1.1. Overview

  • JavaScript in the browser adds APIs beyond the language core. React apps abstract much of this (see React notes), but interviews still test the underlying model.

1.2. Default rules and how to study this file

  • Default rule today: default listeners run on the bubble phase; use delegation on stable parents for dynamic lists; call preventDefault / stopPropagation only when you mean to block default behavior or further propagation.
  • Interactive visualizer: open 24-js-browser-events-animation.html in a browser — capture/target/bubble, stopPropagation, preventDefault, delegation, once/remove (Run / Step).
  • After reading sections 2–6, complete P. Practical Assignment in 24-practice.js before File 25. Review C. Common questions.

3. Storage APIs

L1 L2

L1 Fundamental

3.1. localStorage and sessionStorage

localStorage.setItem("theme", "dark");
localStorage.getItem("theme");
localStorage.removeItem("theme");
localStorage.clear();

sessionStorage.setItem("tab", "1");  // cleared when tab closes

L1 Fundamental

  • Values are strings — JSON.stringify / parse for objects. Same-origin only.

L2 Intermediate

3.2. Cookies

  • Small key-value strings sent with HTTP requests — set via document.cookie or server Set-Cookie. Prefer httpOnly cookies for auth tokens (not accessible from JS).
  • Attributes: Secure, SameSite=Lax|Strict|None (CSRF), Path, Max-Age.
  • localStorage is typically ~5MB per origin; cookies are much smaller (~4KB each) and go on every matching request.

5. Event handling

L1 L2

L1 Fundamental

5.1. Event delegation

  • One listener on parent handles events from children:
document.querySelector("#list").addEventListener("click", (e) => {
  if (e.target.matches("li.item")) {
    console.log("Clicked", e.target.dataset.id);
  }
});
  • Efficient for dynamic lists — fewer listeners.

5.2. stopPropagation and preventDefault

function onClick(e) {
  e.stopPropagation();  // don't bubble further
  e.preventDefault();   // don't default action (e.g. form submit, link nav)
}
  • React: e.stopPropagation(), e.preventDefault() on synthetic events (React File 03).

5.3. Custom events

const event = new CustomEvent("user-login", { detail: { id: 1 } });
window.dispatchEvent(event);

window.addEventListener("user-login", (e) => {
  console.log(e.detail.id);
});

L2 Intermediate

5.4. Bubbling and capturing

  • Events flow capture (window → target) then bubble (target → window). Default listeners run on bubble phase.
el.addEventListener("click", handler);                    // bubble (default)
el.addEventListener("click", handler, { capture: true }); // capture

5.5. Event properties and options

  • e.target — element that originated the event. e.currentTarget — element the listener is attached to (useful in delegation).
  • e.stopPropagation() — stop further bubbling/capturing. e.stopImmediatePropagation() — also skip other listeners on the same node.
  • e.composedPath() — full path including shadow DOM hosts (File 28).
  • { passive: true } — promises not to call preventDefault; improves scroll/touch performance. Browser may treat touch/wheel as passive by default on some targets.
list.addEventListener("click", (e) => {
  console.log(e.target);         // clicked child
  console.log(e.currentTarget);  // #list
  e.stopImmediatePropagation();
});

window.addEventListener("touchstart", onTouch, { passive: true });
window.addEventListener("wheel", onWheel, { passive: false }); // need preventDefault

6.2. Web Workers (brief)

  • A Worker is a separate thread — no DOM access. Talk via postMessage. Use for CPU-heavy work so the UI stays responsive (File 21 — one JS thread per context).
const w = new Worker("./heavy.js", { type: "module" });
w.postMessage({ n: 1e8 });
w.onmessage = (e) => console.log(e.data);

C. Common questions

L1 L2

L1 Fundamental

C.1. localStorage vs sessionStorage? ▾ Answer

localStorage persists until cleared. sessionStorage clears when the tab closes.

C.2. DOM vs BOM? ▾ Answer

DOM — document tree (elements). BOM — browser chrome (window, location, history, navigator).

L1 Fundamental

C.3. What is event delegation? ▾ Answer

Attach one handler to a parent and use event.target to handle child events — good for dynamic lists.

C.4. What does preventDefault do? ▾ Answer

Cancels the browser's default action (submit form, follow link).

C.5. What is AbortController for? ▾ Answer

Cancel fetch or other abortable APIs — avoids race conditions when user navigates away.

L2 Intermediate

C.6. What is event bubbling? ▾ Answer

Event propagates from target up through ancestors after the target handler runs.

C.7. encodeURI vs encodeURIComponent? ▾ Answer

encodeURIComponent encodes &, =, ? — use for query values. encodeURI leaves URL structure intact.

C.8. When do I use IntersectionObserver? ▾ Answer

When you need to know if an element is on screen — lazy images, infinite scroll — without scroll listeners.

C.9. target vs currentTarget? ▾ Answer

target is where the event started; currentTarget is the element the listener is on (parent in delegation).

C.10. What is a passive listener? ▾ Answer

{ passive: true } promises you will not call preventDefault — helps scroll/touch performance. Use passive: false only when you must cancel the default.

P.2. Core tasks

  1. event delegation — One listener on a parent handling child clicks via target. ▾ Solution 
    // Event Delegation Pattern:
// Instead of attaching N listeners to each <li>, attach one listener to the parent <ul>
function setupDelegation(listContainer) {
  listContainer.addEventListener("click", (event) => {
    const item = event.target.closest("li");
    if (!item || !listContainer.contains(item)) return;

    console.log("Clicked item dataset id:", item.dataset.id);
    console.log("Item text content:      ", item.textContent);
  });
}

console.log("Event delegation attached to parent container.");
  2. fetch JSON — fetch a public JSON endpoint; handle errors. ▾ Solution 
    async function fetchUsers() {
  try {
    const res = await fetch("https://jsonplaceholder.typicode.com/users/1");
    if (!res.ok) throw new Error(`HTTP error! status: ${res.status}`);
    const data = await res.json();
    console.log("Fetched user:", data.name);
  } catch (err) {
    console.error("Fetch error:", err.message);
  }
}

if (typeof fetch !== "undefined") {
  fetchUsers();
}
  3. AbortController — Abort a fetch after 100ms timeout. ▾ Solution 
    async function fetchWithAbortTimeout(url, timeoutMs = 100) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeoutMs);

  try {
    const res = await fetch(url, { signal: controller.signal });
    return await res.json();
  } catch (err) {
    if (err.name === "AbortError") {
      console.log("Fetch request aborted due to timeout!");
    } else {
      console.error("Request failed:", err);
    }
  } finally {
    clearTimeout(timer);
  }
}

console.log("AbortController timeout configured with 100ms signal.");
  4. dataset — Read/write data-* attributes. ▾ Solution 
    // Dataset read/write pattern:
if (typeof document !== "undefined") {
