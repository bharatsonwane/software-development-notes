10. Regular Expressions

File 10 — patterns for search and replace on strings (File 09).

NotesExamplesPracticeInterview

L1 Fundamental

  • A regular expression describes a pattern in text. In JavaScript it is a RegExp object (File 02). You use it to test, search, extract, or replace in strings.

L1 Fundamental

  • Default rule today: prefer a literal /pattern/flags when the pattern is fixed. Use new RegExp(string, flags) only when the pattern is built at runtime. Always think about the g flag and lastIndex.

1. Regular expressions

L1 Fundamental

1.1. Literal vs constructor

const lit = /hello/i;
const dyn = new RegExp("hello", "i");

lit.test("Hello");  // true
  • Escape \\ in constructor strings: new RegExp("\\\\d+") equals /\d+/.

1.3. Flags

FlagMeaning
gGlobal — all matches; advances lastIndex
iIgnore case
mMultiline — ^/$ per line
sDotall — . matches newline
uUnicode (code points, \p{...})
ySticky — match only at lastIndex
vUnicode sets (newer class syntax)

1.4. RegExp methods

/\d+/.test("id-42");     // true
const re = /(\d+)/;
re.exec("id-42");        // ["42", "42", index, input, groups]

const g = /\d+/g;
g.exec("a1 b22");        // ["1"]
g.lastIndex;             // 2
g.exec("a1 b22");        // ["22"]
  • With g, reuse of the same RegExp object is stateful. Prefer matchAll or a fresh literal in a loop.

1.5. String methods

const s = "Price: $12 and $3";

s.match(/\d+/);          // ["12"] — first only
[...s.matchAll(/\d+/g)]; // full match objects for every match
s.search(/\d+/);         // 8 — index, or -1
s.replace(/\d+/, "N");   // first only
s.replaceAll(/\d+/g, "N"); // all — replacement regex must be global
s.split(/\s+/);          // ["Price:", "$12", "and", "$3"]

L2 Intermediate

1.6. Groups

const re = /(?<year>\d{4})-(?<month>\d{2})/;
const m = re.exec("2026-08");
m[1];              // "2026"
m.groups.year;     // "2026"

"a1b2".replace(/(\d)/g, "[$1]");  // "a[1]b[2]"
  • (?:...) groups without capturing. Lookahead (?=...) / lookbehind (?<=...) assert without consuming.

1.7. lastIndex pitfall

const re = /a/g;
re.test("a");   // true, lastIndex now 1
re.test("a");   // false — starts at index 1
re.lastIndex = 0;

2. Common questions

L1 L2

L1 Fundamental

2.1. Literal or new RegExp?

  • A: Literal when the pattern is known at write time. Constructor when the pattern string is built at runtime.

L1 Fundamental

2.2. Why does the same regex fail the second test?

  • A: The g (or y) flag stores lastIndex on the object. Reset it, or do not reuse a global regex across calls.

2.3. match vs matchAll?

  • A: match with g returns only the matched strings. matchAll needs g and yields match objects including groups.

L2 Intermediate

2.4. How do I escape user input in a pattern?

  • A: Replace regex special characters before new RegExp (or use a well-tested escape helper). Never interpolate raw user text into a regex.
