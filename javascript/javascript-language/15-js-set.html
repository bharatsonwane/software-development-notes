2. Set

L1 L2

L1 Fundamental

  • Unique values — duplicates ignored:
const set = new Set([1, 2, 2, 3]);
console.log(set.size);  // 3

set.add(4);
set.has(2);    // true
set.delete(1);

for (const value of set) {
  console.log(value);
}

L1 Fundamental

2.1. Dedupe an array

const unique = [...new Set([1, 2, 2, 3])];  // [1, 2, 3]

2.2. Set algebra (ES2025)

const a = new Set([1, 2, 3]);
const b = new Set([3, 4]);

a.union(b);               // Set {1, 2, 3, 4}
a.intersection(b);        // Set {3}
a.difference(b);          // Set {1, 2}
a.symmetricDifference(b); // Set {1, 2, 4}
a.isSubsetOf(b);          // false
a.isSupersetOf(new Set([1, 2]));  // true
a.isDisjointFrom(new Set([9]));   // true
  • These return new Sets. Older environments: copy to arrays and filter.

2.2.1. SameValueZero (NaN and ±0)

  • Set (and Map keys) use SameValueZero equality — like === except NaN equals NaN, and +0 equals -0.
const s = new Set([NaN, NaN, +0, -0]);
s.size;                 // 2 — one NaN, one zero
s.has(NaN);             // true
s.has(-0);              // true — same as +0

[NaN].includes(NaN);    // true — includes also uses SameValueZero
[NaN].indexOf(NaN);     // -1 — indexOf uses ===

L2 Intermediate

2.3. WeakSet

  • Values must be objects. Entries can be garbage-collected when no other references exist. Not iterable; no size.
const ws = new WeakSet();
const obj = { id: 1 };
ws.add(obj);
ws.has(obj);  // true
// When obj is dropped, the entry may disappear
  • Compare with WeakMap in File 16. Memory / GC: File 23.

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the difference between Set and array filter for uniqueness? ▾ Answer

Set enforces uniqueness on every add. [...new Set(arr)] dedupes an existing array. Set also offers O(1) has checks.

L2 Intermediate

C.2. When should I use WeakSet? ▾ Answer

To remember that an object was seen (e.g. already processed) without preventing garbage collection. You cannot iterate or ask for size.

C.3. How do I get the intersection of two Sets? ▾ Answer

a.intersection(b) (ES2025), or [...a].filter((x) => b.has(x)).

C.4. Why can a Set hold only one NaN? ▾ Answer

Membership uses SameValueZero, where NaN equals NaN (unlike ===). +0 and -0 also count as the same key.

P.1. Warm-up

  1. Create a Set from an array with duplicates; log size. ▾ Solution 
    const nums = [1, 2, 2, 3, 3, 3, 4];
const set = new Set(nums);

console.log("Set values:", Array.from(set)); // [1, 2, 3, 4]
console.log("Set size:  ", set.size);        // 4
  2. add, has, delete a few values. ▾ Solution 
    const set = new Set();

set.add("apple");
set.add("banana");
console.log("Has apple?", set.has("apple")); // true

set.delete("apple");
console.log("Has apple after delete?", set.has("apple")); // false
  3. Iterate a Set with for...of. ▾ Solution 
    const colors = new Set(["red", "green", "blue"]);

for (const color of colors) {
  console.log("Color:", color);
}

P.2. Core tasks

  1. union(a, b) — Return a new Set. ▾ Solution 
    function union(a, b) {
  return new Set([...a, ...b]);
}

const s1 = new Set([1, 2, 3]);
const s2 = new Set([3, 4, 5]);

console.log("Union:", Array.from(union(s1, s2))); // [1, 2, 3, 4, 5]
  2. intersection(a, b) — Values in both. ▾ Solution 
    function intersection(a, b) {
  return new Set([...a].filter(item => b.has(item)));
}

const s1 = new Set([1, 2, 3]);
const s2 = new Set([2, 3, 4]);

console.log("Intersection:", Array.from(intersection(s1, s2))); // [2, 3]
  3. difference(a, b) — In a but not b. ▾ Solution 
    function difference(a, b) {
  return new Set([...a].filter(item => !b.has(item)));
}

const s1 = new Set([1, 2, 3, 4]);
const s2 = new Set([3, 4, 5]);

console.log("Difference (s1 - s2):", Array.from(difference(s1, s2))); // [1, 2]
  4. uniqueWords(str) — Split on spaces into a Set. ▾ Solution 
    function uniqueWords(sentence) {
  const words = sentence.toLowerCase().match(/\w+/g) || [];
  return new Set(words);
}

const text = "The quick brown fox jumps over the lazy dog the quick fox";
console.log("Unique words count:", uniqueWords(text).size); // 8

L2 Intermediate

P.3. Challenge

  1. SameValueZero — Show Set treats NaN as equal to NaN. ▾ Solution 
    // Set uses SameValueZero algorithm:
const nanSet = new Set();
nanSet.add(NaN);
nanSet.add(NaN);

console.log("Set size with two NaNs:", nanSet.size); // 1 (NaN is treated as equal to NaN)
console.log("Has NaN?               ", nanSet.has(NaN)); // true
  2. object identity — Add two different {} objects; explain size 2. ▾ Solution 
    const objSet = new Set();

const obj1 = {};
const obj2 = {};

objSet.add(obj1);
objSet.add(obj2);

console.log("Set size with two {} literals:", objSet.size); // 2
// Explanation: Sets compare objects by reference identity, not structural equality.
// obj1 and obj2 occupy different memory addresses, so they are considered distinct entries.
