2. Set

L1 L2

L1 Fundamental

  • Unique values — duplicates ignored:
const set = new Set([1, 2, 2, 3]);
console.log(set.size);  // 3

set.add(4);
set.has(2);    // true
set.delete(1);

for (const value of set) {
  console.log(value);
}

L1 Fundamental

2.1. Dedupe an array

const unique = [...new Set([1, 2, 2, 3])];  // [1, 2, 3]

2.2. Set algebra (ES2025)

const a = new Set([1, 2, 3]);
const b = new Set([3, 4]);

a.union(b);               // Set {1, 2, 3, 4}
a.intersection(b);        // Set {3}
a.difference(b);          // Set {1, 2}
a.symmetricDifference(b); // Set {1, 2, 4}
a.isSubsetOf(b);          // false
a.isSupersetOf(new Set([1, 2]));  // true
a.isDisjointFrom(new Set([9]));   // true
  • These return new Sets. Older environments: copy to arrays and filter.

2.2.1. SameValueZero (NaN and ±0)

  • Set (and Map keys) use SameValueZero equality — like === except NaN equals NaN, and +0 equals -0.
const s = new Set([NaN, NaN, +0, -0]);
s.size;                 // 2 — one NaN, one zero
s.has(NaN);             // true
s.has(-0);              // true — same as +0

[NaN].includes(NaN);    // true — includes also uses SameValueZero
[NaN].indexOf(NaN);     // -1 — indexOf uses ===

L2 Intermediate

2.3. WeakSet

  • Values must be objects. Entries can be garbage-collected when no other references exist. Not iterable; no size.
const ws = new WeakSet();
const obj = { id: 1 };
ws.add(obj);
ws.has(obj);  // true
// When obj is dropped, the entry may disappear
  • Compare with WeakMap in File 16. Memory / GC: File 23.

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the difference between Set and array filter for uniqueness?

  • A: Set enforces uniqueness on every add. [...new Set(arr)] dedupes an existing array. Set also offers O(1) has checks.

L2 Intermediate

C.2. When should I use WeakSet?

  • A: To remember that an object was seen (e.g. already processed) without preventing garbage collection. You cannot iterate or ask for size.

C.3. How do I get the intersection of two Sets?

  • A: a.intersection(b) (ES2025), or [...a].filter((x) => b.has(x)).

C.4. Why can a Set hold only one NaN?

  • A: Membership uses SameValueZero, where NaN equals NaN (unlike ===). +0 and -0 also count as the same key.
