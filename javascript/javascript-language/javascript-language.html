Learning Path

Read files in order 01 → 29. For each pass, stay at one depth across many concepts instead of finishing one file to L3 first.

Pass 1 → L1 across 01–29   What is it, and how do I use it?
Pass 2 → L2 across 01–29   How does it behave?
Pass 3 → L3 across 01–29   How does it work in complex cases?
Each file uses relative section numbers like 1., 1.1., and 1.1.1. within that file. All chapter files 01–29 use 1. Introduction, numbered topics, then C. Common questions and P. Practical Assignment — write code after each chapter before moving on.
