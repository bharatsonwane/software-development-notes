16. Map

File 16 — any-value keys, vs object, WeakMap.

NotesExamplesPracticeInterview

L1 Fundamental

  • A Map is a key/value collection. Unlike objects (File 13), keys can be any value (objects, functions, numbers), not only strings/symbols.

L1 Fundamental

  • Interactive visualizer: 22-js-es6-plus-animation.html (Map/Set scenarios).

1. Map

L1 L2

L1 Fundamental

  • Any value as key, insertion order, size property:
const map = new Map();

map.set("name", "Bharat");
map.set(42, "number key");
map.set({ id: 1 }, "object key");

map.get("name");     // "Bharat"
map.has(42);         // true
map.size;            // 3

map.delete(42);
map.clear();         // remove all

L1 Fundamental

1.1. Iterate

const userMap = new Map([["a", 1], ["b", 2]]);

L2 Intermediate

1.2. WeakMap

  • Keys must be objects. Entries can be garbage-collected when no other references exist. Not iterable; no size.
const wm = new WeakMap();
const obj = { id: 1 };

wm.set(obj, "metadata");
wm.get(obj);  // "metadata"

// When obj is dropped, entry may disappear
Map / SetWeakMap / WeakSet

  • Use WeakMap for private metadata on objects without preventing GC (File 23). WeakSet is File 15.

2. Common questions

L1 L2

L1 Fundamental

2.1. When should I use Map instead of a plain object?

  • A: When keys are not strings, you need insertion order with non-integer keys, frequent size checks, or frequent add/delete without prototype noise.

L2 Intermediate

2.2. What is the difference between WeakMap and Map?

  • A: WeakMap keys must be objects, holds weak references (GC-friendly), is not iterable, and has no size. Map holds keys strongly and supports full iteration.
