1.1. Overview

  • A Map is a key/value collection. Unlike objects (File 13), keys can be any value (objects, functions, numbers), not only strings/symbols.

2. Map

L1 L2

L1 Fundamental

  • Any value as key, insertion order, size property:
const map = new Map();

map.set("name", "Bharat");
map.set(42, "number key");
map.set({ id: 1 }, "object key");

map.get("name");     // "Bharat"
map.has(42);         // true
map.size;            // 3

map.delete(42);
map.clear();         // remove all

2.1.1. SameValueZero keys (NaN and ±0)

  • Map key equality matches Set: SameValueZero — one NaN key; +0 and -0 are the same key (File 15).
const m = new Map();
m.set(NaN, "a");
m.set(NaN, "b");
m.get(NaN);             // "b" — same key
m.set(+0, 1);
m.set(-0, 2);
m.get(0);               // 2

2.1.2. Map.groupBy

  • Group items into a Map keyed by any value (objects, numbers, etc.). Object.groupBy is the same idea with string keys (File 14).
const rows = [
  { type: "a", n: 1 },
  { type: "b", n: 2 },
  { type: "a", n: 3 },
];

const byType = Map.groupBy(rows, (r) => r.type);
byType.get("a");  // [{ type: "a", n: 1 }, { type: "a", n: 3 }]

const oddEven = Map.groupBy([1, 2, 3, 4], (n) => n % 2 === 0);
oddEven.get(true);  // [2, 4]

L2 Intermediate

2.2. WeakMap

  • Keys must be objects. Entries can be garbage-collected when no other references exist. Not iterable; no size.
const wm = new WeakMap();
const obj = { id: 1 };

wm.set(obj, "metadata");
wm.get(obj);  // "metadata"

// When obj is dropped, entry may disappear
Map / SetWeakMap / WeakSet
Keys / valuesAny / anyObjects only

GCHolds stronglyWeak — good for caches attached to DOM nodes
  • Use WeakMap for private metadata on objects without preventing GC (File 23). WeakSet is File 15.

C. Common questions

L1 L2

L1 Fundamental

C.1. When should I use Map instead of a plain object? ▾ Answer

When keys are not strings, you need insertion order with non-integer keys, frequent size checks, or frequent add/delete without prototype noise.

L2 Intermediate

C.2. What is the difference between WeakMap and Map? ▾ Answer

WeakMap keys must be objects, holds weak references (GC-friendly), is not iterable, and has no size. Map holds keys strongly and supports full iteration.

C.3. How does Map treat NaN as a key? ▾ Answer

SameValueZero — all NaN values share one key. +0 and -0 are also the same key.

C.4. When do I use Map.groupBy vs Object.groupBy? ▾ Answer

Use Map.groupBy when the group key is not a string (objects, numbers, booleans). Use Object.groupBy for plain string/symbol keys that you want as a record (File 14).

P.1. Warm-up

  1. Create a Map; set/get/has a few entries. ▾ Solution 
    const map = new Map();

map.set("name", "Bharat");
map.set("topic", "JavaScript Map");

console.log("Get name:  ", map.get("name")); // "Bharat"
console.log("Has topic? ", map.has("topic")); // true
console.log("Map size:  ", map.size);       // 2

map.delete("name");
console.log("Has name after delete? ", map.has("name")); // false
  2. Use an object as a key and retrieve the value. ▾ Solution 
    const userKey = { id: 101 };
const roleMap = new Map();

roleMap.set(userKey, "Administrator");

console.log("Look up by object reference:", roleMap.get(userKey)); // "Administrator"
console.log("Look up with new literal:     ", roleMap.get({ id: 101 })); // undefined (different object reference!)
  3. Convert Map to array of pairs with [...map]. ▾ Solution 
    const scores = new Map([
  ["Alice", 95],
  ["Bob", 88],
  ["Charlie", 92]
]);

const pairs = [...scores];
console.log("Array of pairs:", pairs);
// [["Alice", 95], ["Bob", 88], ["Charlie", 92]]

P.2. Core tasks

  1. countChars(str) — Frequency Map of characters. ▾ Solution 
    function countChars(str) {
  const freq = new Map();
  for (const ch of str) {
    freq.set(ch, (freq.get(ch) ?? 0) + 1);
  }
  return freq;
}

const counts = countChars("javascript");
console.log("Character counts:", [...counts]);
// [["j", 1], ["a", 2], ["v", 1], ["s", 1], ["c", 1], ["r", 1], ["i", 1], ["p", 1], ["t", 1]]
  2. invertMap(m) — Swap keys/values (assume values are unique). ▾ Solution 
    function invertMap(m) {
  const inverted = new Map();
  for (const [key, value] of m) {
    inverted.set(value, key);
  }
  return inverted;
}

const original = new Map([["a", 1], ["b", 2], ["c", 3]]);
console.log("Inverted Map:", [...invertMap(original)]);
// [[1, "a"], [2, "b"], [3, "c"]]
  3. mergeMaps(a, b) — Later map wins on conflicts. ▾ Solution 
    function mergeMaps(a, b) {
  // Later map (b) overwrites duplicate keys in a
  return new Map([...a, ...b]);
}

const mapA = new Map([["theme", "light"], ["fontSize", 12]]);
const mapB = new Map([["theme", "dark"], ["showLineNumbers", true]]);

console.log("Merged Map:", [...mergeMaps(mapA, mapB)]);
// [["theme", "dark"], ["fontSize", 12], ["showLineNumbers", true]]
  4. groupToMap(arr, keyFn) — Map from key to array of items. ▾ Solution 
    function groupToMap(arr, keyFn) {
  const map = new Map();
  for (const item of arr) {
    const key = keyFn(item);
    if (!map.has(key)) map.set(key, []);
    map.get(key).push(item);
  }
  return map;
}

const fruits = ["apple", "apricot", "banana", "blueberry", "cherry"];
const grouped = groupToMap(fruits, f => f[0]);

for (const [letter, list] of grouped) {
  console.log(`${letter} -> ${list.join(", ")}`);
}
// a -> apple, apricot
// b -> banana, blueberry
// c -> cherry

L2 Intermediate

P.3. Challenge

  1. Map vs object — Demo why "__proto__" / inherited keys make objects awkward as dictionaries. ▾ Solution 
    // Plain Object Pitfall: prototype pollution and key collisions
const plainObj = {};
console.log("toString in plainObj:", "toString" in plainObj); // true (inherited from Object.prototype!)

// Map Safety: keys are strictly isolated without prototype pollution
const safeMap = new Map();
console.log("safeMap.has('toString'):", safeMap.has("toString")); // false
safeMap.set("__proto__", "Safe custom key");
console.log(safeMap.get("__proto__")); // "Safe custom key"
  2. WeakMap note — Write a short comment (or tiny example) of a private-data WeakMap pattern. ▾ Solution 
    // Private state management using WeakMap
const privateData = new WeakMap();

class UserSession {
  constructor(userId, token) {
    privateData.set(this, { userId, token });
  }

  getUserId() {
    return privateData.get(this).userId;
  }
}

let session = new UserSession(42, "secret-token-xyz");
console.log("User ID:", session.getUserId()); // 42
console.log("Token directly exposed?", session.token); // undefined

// When session is nullified, its private data is eligible for garbage collection
session = null;
