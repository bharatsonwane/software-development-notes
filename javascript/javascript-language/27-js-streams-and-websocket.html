27. Streams & WebSocket

File 27 — ReadableStream / TransformStream, fetch bodies, WebSocket messaging.

1. Introduction

L1

L1 Fundamental

1.1. Overview

  • Streams process data in chunks (download, upload, transform) without loading everything into memory. WebSocket is a full-duplex socket for low-latency messaging.

1.2. Default rules and how to study this file

  • Default rule today: use fetch + streaming body for large HTTP payloads; use WebSocket (or SSE) for live bidirectional updates. Async iteration: File 21.

2.2. TransformStream (pipe)

const upper = new TransformStream({
  transform(chunk, controller) {
    controller.enqueue(chunk.toUpperCase());
  },
});

const readable = new ReadableStream({
  start(controller) {
    controller.enqueue("hi");
    controller.close();
  },
});

const out = readable.pipeThrough(upper);
const reader = out.getReader();
console.log((await reader.read()).value); // "HI"

L2 Intermediate

2.3. Backpressure (idea)

  • If the consumer is slow, the stream signals the producer to slow down (via promise-based write / pull). Avoid buffering unbounded chunks in memory.
  • Node has its own stream API (stream.Readable); modern Node also supports Web Streams.

3. WebSocket

L1 L2

L1 Fundamental

  • Persistent connection after HTTP upgrade. Both sides can send anytime.
const ws = new WebSocket("wss://example.com/socket");

ws.addEventListener("open", () => {
  ws.send(JSON.stringify({ type: "hello" }));
});

ws.addEventListener("message", (e) => {
  console.log(e.data); // string or Blob/ArrayBuffer if binaryType set
});

ws.addEventListener("error", console.error);
ws.addEventListener("close", (e) => {
  console.log(e.code, e.reason);
});

L1 Fundamental

3.1. Ready states and binary

ws.readyState; // 0 CONNECTING, 1 OPEN, 2 CLOSING, 3 CLOSED
ws.binaryType = "arraybuffer";
ws.send(new Uint8Array([1, 2, 3]));
ws.close(1000, "done");

L2 Intermediate

3.2. Practical notes

  • Reconnection, heartbeats, and auth tokens are application-level — not built into the API.
  • Prefer wss:// in production. For one-way server push, SSE (EventSource) is simpler.
  • Compare with HTTP polling / long-poll — WebSocket wins for chat, collaborative edits, live feeds.

C. Common questions

L1 L2

L1 Fundamental

C.1. When streams vs reading full body? ▾ Answer

Stream when the payload is large or you want progressive UI. Use res.json() / res.text() for small complete responses (File 24).

L2 Intermediate

C.2. WebSocket vs fetch? ▾ Answer

fetch is request/response. WebSocket stays open for many messages both ways with lower overhead after connect.

async function runDemoStream() {
  if (typeof ReadableStream === "undefined") {
    console.log("ReadableStream is available in Web/modern Node environments.");

  }

  const stream = new ReadableStream({
    start(controller) {
      controller.enqueue("Chunk 1");
      controller.enqueue("Chunk 2");
      controller.enqueue("Chunk 3");
      controller.close();
    }
  });

function setupWebSocket(url) {

    console.log("WebSocket is a browser / Node 'ws' API.");

  2. backpressure note — Write 5–8 lines explaining why producers must respect pull/desiredSize. ▾ Solution 
    /*
Backpressure Explanation:
- Fast Producer / Slow Consumer problem: If a producer generates data at 100 MB/s but the consumer can only process 10 MB/s, unconsumed chunks accumulate in memory, leading to high latency and Out-Of-Memory (OOM) crashes.
- How Streams solve this: WritableStream signals backpressure via its internal desiredSize and ready promise.
- When the buffer reaches highWaterMark, desiredSize becomes <= 0. The upstream pipeline pauses pulling from the producer until the consumer finishes processing current chunks.
*/
console.log("Backpressure mechanism documented.");
  3. WS message protocol — JSON encode/decode helpers for {type, payload}. ▾ Solution 
    const Protocol = {
  encode(type, payload) {
    return JSON.stringify({
      type,
      payload,
      timestamp: Date.now()
    });
  },
  decode(rawMessage) {
    try {
      const data = JSON.parse(rawMessage);
      if (!data.type) throw new Error("Missing message type");
      return data;
    } catch (err) {
      console.error("Invalid protocol message:", err.message);
      return null;
    }
  }
};

const packet = Protocol.encode("chat", { text: "Hello WebSocket!" });
console.log("Encoded:", packet);
console.log("Decoded:", Protocol.decode(packet));
  4. reconnect policy — Pseudocode exponential backoff reconnect. ▾ Solution 
    function connectWithBackoff(url, attempt = 0) {
  const maxAttempts = 5;
  const baseDelay = 500; // ms
  const delay = Math.min(baseDelay * Math.pow(2, attempt), 10000);

  console.log(`Connecting to ${url}... (Attempt #${attempt + 1}, delay: ${delay}ms)`);

  // Simulated reconnection failure trigger
  if (attempt < maxAttempts) {
    setTimeout(() => {
      console.log(`Attempt #${attempt + 1} failed. Retrying...`);
      connectWithBackoff(url, attempt + 1);
    }, delay);
  } else {
    console.log("Max reconnection attempts reached. Giving up.");
  }
}

  1. TransformStream — Uppercase chunks in a transform (browser). ▾ Solution 
    // TransformStream Uppercasing demo:
async function testTransformStream() {
  if (typeof TransformStream === "undefined") return;

  const uppercaseTransform = new TransformStream({
    transform(chunk, controller) {
      controller.enqueue(chunk.toUpperCase());
    }
  });

  const readable = new ReadableStream({
    start(controller) {
      controller.enqueue("hello ");
      controller.enqueue("world ");
      controller.enqueue("streams!");
      controller.close();
    }
  });

  const transformedStream = readable.pipeThrough(uppercaseTransform);
  const reader = transformedStream.getReader();

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    console.log("Transformed chunk:", value);
  }
}

testTransformStream();
  2. heartbeat — Interval ping on WebSocket; clear on close. ▾ Solution 
    function startHeartbeat(ws) {
  let pingInterval = setInterval(() => {
    if (ws?.readyState === 1 /* OPEN */) {
      ws.send(JSON.stringify({ type: "ping" }));
      console.log("Heartbeat ping sent");
    }
  }, 30000);

  // Clear timer when connection closes or errors to prevent memory leaks
  const stopHeartbeat = () => {
    clearInterval(pingInterval);
    console.log("Heartbeat stopped");
  };

  return stopHeartbeat;
}

console.log("Heartbeat watchdog helper initialized.");
