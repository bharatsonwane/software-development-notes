26. Typed Arrays & Binary Data

File 26 — ArrayBuffer, TypedArray views, DataView, transferables.

1. Introduction

L1

L1 Fundamental

1.1. Overview

  • JavaScript arrays hold mixed values. Binary data (network packets, images, audio, WASM) uses a fixed byte buffer plus typed views.

1.2. Default rules and how to study this file

  • Default rule today: use a TypedArray (Uint8Array, etc.) for homogeneous numeric buffers; use DataView when endianness or mixed field sizes matter; pass buffers with structuredClone / Worker transfer (File 02, 24).
  • After reading sections 2–4, complete P. Practical Assignment in 26-practice.js before File 27. Review C. Common questions.

2. ArrayBuffer

L1 L2

L1 Fundamental

  • An ArrayBuffer is a raw contiguous block of bytes. You do not read/write it directly — attach a view.
const buf = new ArrayBuffer(8);  // 8 bytes
buf.byteLength;                  // 8

L1 Fundamental

2.1. Detach / transfer

  • Transferring a buffer (Workers, structuredClone(..., { transfer })) detaches the original — byteLength becomes 0.
const buf = new ArrayBuffer(4);
const moved = structuredClone(buf, { transfer: [buf] });
buf.byteLength;    // 0 — detached
moved.byteLength;  // 4

3. TypedArrays

L1 L2

L1 Fundamental

  • TypedArrays are views over an ArrayBuffer with a fixed element type:
TypeBytes / elementRange (approx)
Uint8Array10–255
Int8Array1−128–127
Uint16Array / Int16Array216-bit
Uint32Array / Int32Array432-bit
Float32Array / Float64Array4 / 8IEEE floats
BigInt64Array / BigUint64Array8bigint elements
 
const bytes = new Uint8Array(4);
bytes[0] = 255;
bytes[1] = 10;

const fromValues = Uint8Array.from([1, 2, 3]);
const shared = new Uint8Array(bytes.buffer);  // same underlying buffer

bytes.length;       // element count
bytes.byteLength;   // bytes
bytes.buffer;       // ArrayBuffer
  • Many array methods work (map, slice, set) but TypedArrays are not normal Arrays (Array.isArray is false).

L1 Fundamental

3.1. Common uses

// Fetch binary
const res = await fetch("/file.bin");
const buf = await res.arrayBuffer();
const view = new Uint8Array(buf);

// Text encode/decode
const enc = new TextEncoder().encode("hi");  // Uint8Array
const text = new TextDecoder().decode(enc);

L2 Intermediate

3.2. Multiple views, one buffer

const buf = new ArrayBuffer(4);
const u8 = new Uint8Array(buf);
const u16 = new Uint16Array(buf);
u8[0] = 0x01;
u8[1] = 0x02;
u16[0];  // depends on endianness of the platform for multi-byte reads

4. DataView

L2

L2 Intermediate

  • DataView reads/writes mixed sizes with explicit endianness — ideal for binary protocols.
const buf = new ArrayBuffer(8);
const dv = new DataView(buf);

dv.setUint16(0, 0x1234, false); // big-endian
dv.setFloat32(2, 3.14, true);   // little-endian
dv.getUint16(0, false);         // 0x1234
  • Third argument littleEndian: true = LE, false = BE.

C. Common questions

L1 L2

L1 Fundamental

C.1. Array vs TypedArray?

  • A: Arrays hold any values and grow. TypedArrays are fixed-type numeric views over bytes — faster and required for many binary APIs.

L2 Intermediate

C.2. When do I use DataView?

  • A: When parsing/writing mixed field widths or when you must control endianness. Prefer a single TypedArray when the buffer is homogeneous.

C.3. What is a transferable?

  • A: An object (e.g. ArrayBuffer) that can move ownership to another context without copying — original becomes detached.

P. Practical Assignment

L1 L2
Work with ArrayBuffer / TypedArrays carefully — endianness matters for DataView.

L1 Fundamental

P.1. Warm-up

  1. Create an ArrayBuffer of 16 bytes and a Uint8Array view.
  2. Write values into Uint8Array; read them back.
  3. Create a DataView and setUint16 with little-endian true/false; compare bytes.

P.2. Core tasks

  1. bytes to hex — Format Uint8Array as hex string.
  2. copy buffer — Copy a slice of a buffer into a new one.
  3. float bits — Use DataView setFloat32/getFloat32 round-trip.
  4. shared views — Two typed views on same buffer; show aliasing.

L2 Intermediate

P.3. Challenge

  1. pack header — Pack version:u8, flags:u8, length:u16 into a buffer.
  2. TextEncoder — Encode a string to Uint8Array and decode back (browser/Node util).

P.4. Self-check

  • I know TypedArrays are views on ArrayBuffer.
  • I set endianness explicitly with DataView.
  • I do not assume byte layout across platforms without documenting it.
