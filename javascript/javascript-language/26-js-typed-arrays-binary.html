26. Typed Arrays & Binary Data

File 26 — ArrayBuffer, TypedArray views, DataView, transferables.

1. Introduction

L1

L1 Fundamental

1.1. Overview

  • JavaScript arrays hold mixed values. Binary data (network packets, images, audio, WASM) uses a fixed byte buffer plus typed views.

1.2. Default rules and how to study this file

  • Default rule today: use a TypedArray (Uint8Array, etc.) for homogeneous numeric buffers; use DataView when endianness or mixed field sizes matter; pass buffers with structuredClone / Worker transfer (File 02, 24).
  • After reading sections 2–4, complete P. Practical Assignment in 26-practice.js before File 27. Review C. Common questions.

2. ArrayBuffer

L1 L2

L1 Fundamental

  • An ArrayBuffer is a raw contiguous block of bytes. You do not read/write it directly — attach a view.
const buf = new ArrayBuffer(8);  // 8 bytes
buf.byteLength;                  // 8

L1 Fundamental

2.1. Detach / transfer

  • Transferring a buffer (Workers, structuredClone(..., { transfer })) detaches the original — byteLength becomes 0.
const buf = new ArrayBuffer(4);
const moved = structuredClone(buf, { transfer: [buf] });
buf.byteLength;    // 0 — detached
moved.byteLength;  // 4

3. TypedArrays

L1 L2

L1 Fundamental

  • TypedArrays are views over an ArrayBuffer with a fixed element type:
TypeBytes / elementRange (approx)
Uint8Array10–255
Int8Array1−128–127
Uint16Array / Int16Array216-bit
Uint32Array / Int32Array432-bit
Float32Array / Float64Array4 / 8IEEE floats
BigInt64Array / BigUint64Array8bigint elements
 
const bytes = new Uint8Array(4);
bytes[0] = 255;
bytes[1] = 10;

const fromValues = Uint8Array.from([1, 2, 3]);
const shared = new Uint8Array(bytes.buffer);  // same underlying buffer

bytes.length;       // element count
bytes.byteLength;   // bytes
bytes.buffer;       // ArrayBuffer
  • Many array methods work (map, slice, set) but TypedArrays are not normal Arrays (Array.isArray is false).

L1 Fundamental

3.1. Common uses

// Fetch binary
const res = await fetch("/file.bin");
const buf = await res.arrayBuffer();
const view = new Uint8Array(buf);

// Text encode/decode
const enc = new TextEncoder().encode("hi");  // Uint8Array
const text = new TextDecoder().decode(enc);

L2 Intermediate

3.2. Multiple views, one buffer

const buf = new ArrayBuffer(4);
const u8 = new Uint8Array(buf);
const u16 = new Uint16Array(buf);
u8[0] = 0x01;
u8[1] = 0x02;
u16[0];  // depends on endianness of the platform for multi-byte reads

4. DataView

L2

L2 Intermediate

  • DataView reads/writes mixed sizes with explicit endianness — ideal for binary protocols.
const buf = new ArrayBuffer(8);
const dv = new DataView(buf);

dv.setUint16(0, 0x1234, false); // big-endian
dv.setFloat32(2, 3.14, true);   // little-endian
dv.getUint16(0, false);         // 0x1234
  • Third argument littleEndian: true = LE, false = BE.

C. Common questions

L1 L2

L1 Fundamental

C.1. Array vs TypedArray? ▾ Answer

Arrays hold any values and grow. TypedArrays are fixed-type numeric views over bytes — faster and required for many binary APIs.

L2 Intermediate

C.2. When do I use DataView? ▾ Answer

When parsing/writing mixed field widths or when you must control endianness. Prefer a single TypedArray when the buffer is homogeneous.

C.3. What is a transferable? ▾ Answer

An object (e.g. ArrayBuffer) that can move ownership to another context without copying — original becomes detached.

P. Practical Assignment

L1 L2
Work with ArrayBuffer / TypedArrays carefully — endianness matters for DataView.

L1 Fundamental

P.1. Warm-up

  1. Create an ArrayBuffer of 16 bytes and a Uint8Array view. ▾ Solution 
    // Create 16-byte raw memory buffer
const buffer = new ArrayBuffer(16);
console.log("Buffer byte length:", buffer.byteLength); // 16

// Create 8-bit unsigned integer view over the buffer
const uint8View = new Uint8Array(buffer);
console.log("Uint8Array element count:", uint8View.length); // 16
  2. Write values into Uint8Array; read them back. ▾ Solution 
    const buffer = new ArrayBuffer(4);
const view = new Uint8Array(buffer);

view[0] = 10;
view[1] = 255;
view[2] = 128;
view[3] = 42;

console.log("Index 0:", view[0]); // 10
console.log("Index 1:", view[1]); // 255
console.log("All bytes:", Array.from(view)); // [10, 255, 128, 42]
  3. Create a DataView and setUint16 with little-endian true/false; compare bytes. ▾ Solution 
    const buffer = new ArrayBuffer(4);
const dv = new DataView(buffer);

// 0x1234 = 4660 in decimal
// Little-endian (true): least significant byte stored first -> [0x34, 0x12]
dv.setUint16(0, 0x1234, true);

// Big-endian (false): most significant byte stored first -> [0x12, 0x34]
dv.setUint16(2, 0x1234, false);

const bytes = new Uint8Array(buffer);
console.log("Little-endian bytes (index 0,1):", [bytes[0].toString(16), bytes[1].toString(16)]); // ["34", "12"]
console.log("Big-endian bytes    (index 2,3):", [bytes[2].toString(16), bytes[3].toString(16)]); // ["12", "34"]

P.2. Core tasks

  1. bytes to hex — Format Uint8Array as hex string. ▾ Solution 
    function bytesToHex(uint8Array) {
  return Array.from(uint8Array)
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
}

const data = new Uint8Array([0xde, 0xad, 0xbe, 0xef]);
console.log("Hex string:", bytesToHex(data)); // "deadbeef"
  2. copy buffer — Copy a slice of a buffer into a new one. ▾ Solution 
    const original = new Uint8Array([10, 20, 30, 40, 50]);

// Slice creates a new ArrayBuffer copy
const clonedView = new Uint8Array(original.buffer.slice(1, 4));
clonedView[0] = 99;

console.log("Cloned view:  ", Array.from(clonedView)); // [99, 30, 40]
console.log("Original view:", Array.from(original));   // [10, 20, 30, 40, 50] (unmutated)
  3. float bits — Use DataView setFloat32/getFloat32 round-trip. ▾ Solution 
    const buf = new ArrayBuffer(4);
const dv = new DataView(buf);

const originalFloat = 3.1415927;
dv.setFloat32(0, originalFloat, true); // Little endian

const readFloat = dv.getFloat32(0, true);
console.log("Original float:", originalFloat);
console.log("Read back:     ", readFloat);
console.log("Match:         ", Math.abs(originalFloat - readFloat) < 0.0001); // true
  4. shared views — Two typed views on same buffer; show aliasing. ▾ Solution 
    const sharedBuf = new ArrayBuffer(4);

const u8 = new Uint8Array(sharedBuf);
const u16 = new Uint16Array(sharedBuf);

// Mutating via 16-bit view
u16[0] = 0x0501; // 1 in low byte, 5 in high byte (little-endian)

// Aliased 8-bit view automatically reflects changes:
console.log("u8[0]:", u8[0]); // 1
console.log("u8[1]:", u8[1]); // 5

L2 Intermediate

P.3. Challenge

  1. pack header — Pack version:u8, flags:u8, length:u16 into a buffer. ▾ Solution 
    // Packet Header Spec:
// [0]   version: uint8 (1 byte)
// [1]   flags:   uint8 (1 byte)
// [2-3] length:  uint16 (2 bytes, little-endian)
function packHeader(version, flags, length) {
  const buf = new ArrayBuffer(4);
  const dv = new DataView(buf);

  dv.setUint8(0, version);
  dv.setUint8(1, flags);
  dv.setUint16(2, length, true);

  return new Uint8Array(buf);
}

const headerBytes = packHeader(1, 0x80, 1024);
console.log("Packed header bytes:", Array.from(headerBytes));
// [1, 128, 0, 4] (1024 = 0x0400 -> 0x00, 0x04 in little-endian)
  2. TextEncoder — Encode a string to Uint8Array and decode back (browser/Node util). ▾ Solution 
    const text = "Hello, WebAssembly & Binary JS!";

// Encode string to UTF-8 Uint8Array:
const encoder = new TextEncoder();
const encoded = encoder.encode(text);
console.log("Encoded byte length:", encoded.byteLength);

// Decode back to string:
const decoder = new TextDecoder();
const decoded = decoder.decode(encoded);
console.log("Decoded string:     ", decoded);

P.4. Self-check

  • I know TypedArrays are views on ArrayBuffer.
  • I set endianness explicitly with DataView.
  • I do not assume byte layout across platforms without documenting it.
