2. Custom elements

L1 L2

L1 Fundamental

  • Name must include a hyphen. Extend HTMLElement and register with customElements.define.
class HelloWorld extends HTMLElement {
  connectedCallback() {
    this.textContent = "Hello";
  }
}
customElements.define("hello-world", HelloWorld);
// <hello-world></hello-world>

L1 Fundamental

2.1. Lifecycle callbacks

CallbackWhen
connectedCallbackInserted into document
disconnectedCallbackRemoved from document
attributeChangedCallbackObserved attribute changes
adoptedCallbackMoved to a new document
 
class Greeter extends HTMLElement {
  static get observedAttributes() { return ["name"]; }

  attributeChangedCallback(name, oldVal, newVal) {
    if (name === "name") this.render();
  }

  connectedCallback() { this.render(); }

  render() {
    this.textContent = `Hello, ${this.getAttribute("name") ?? "guest"}`;
  }
}
customElements.define("x-greeter", Greeter);

3. Shadow DOM

L1 L2

L1 Fundamental

  • Shadow DOM attaches an isolated DOM tree — styles and markup do not leak to/from the page by default.
class Card extends HTMLElement {
  constructor() {
    super();
    const root = this.attachShadow({ mode: "open" });
    root.innerHTML = `
      <style>p { color: navy; }</style>
      <p><slot></slot></p>
    `;
  }
}
customElements.define("x-card", Card);
  • mode: "open" → el.shadowRoot accessible. "closed" hides it (rare; security theater).

L2 Intermediate

3.1. Events and composed

  • Events from shadow trees may not bubble to the light DOM unless composed: true. Use e.composedPath() (File 24) to see hosts.
this.dispatchEvent(new CustomEvent("save", {
  bubbles: true,
  composed: true,
  detail: { id: 1 },
}));

4. Templates & slots

L1

L1 Fundamental

  • <template> holds inert HTML to clone. <slot> projects light-DOM children into the shadow tree.
// Light DOM:
// <x-card><span slot="title">Hi</span>Body</x-card>

// Shadow HTML:
// <slot name="title"></slot>
// <slot></slot>  — default slot

C. Common questions

L1 L2

L1 Fundamental

C.1. Why require a hyphen in the tag name? ▾ Answer

Spec rule so custom tags never collide with future HTML elements.

L2 Intermediate

C.2. Shadow DOM vs iframe? ▾ Answer

Shadow DOM is style/DOM encapsulation inside the same document and JS realm. iframes are separate documents (heavier; true process isolation only with care).

P.2. Core tasks

  1. <fancy-greeting> — Reflect name attribute to shadow text. ▾ Solution 
    class FancyGreeting extends (typeof HTMLElement !== "undefined" ? HTMLElement : Object) {
  static get observedAttributes() {
    return ["name"];
  }

  constructor() {
    super();
    if (this.attachShadow) {
      this.attachShadow({ mode: "open" });
      this.shadowRoot.innerHTML = `<p>Welcome, <span id="target">Guest</span>!</p>`;
    }
  }

  attributeChangedCallback(name, oldValue, newValue) {
    if (name === "name" && this.shadowRoot) {
      this.shadowRoot.querySelector("#target").textContent = newValue || "Guest";
    }
  }
}

if (typeof customElements !== "undefined" && !customElements.get("fancy-greeting")) {
  customElements.define("fancy-greeting", FancyGreeting);
}

  3. events — Dispatch a CustomEvent when clicked. ▾ Solution 
    class ActionButton extends (typeof HTMLElement !== "undefined" ? HTMLElement : Object) {
  connectedCallback() {
    this.addEventListener("click", () => {
      this.dispatchEvent(new CustomEvent("action-triggered", {
        bubbles: true,
        composed: true, // Allows crossing Shadow DOM boundary
        detail: { actionId: "submit_form", timestamp: Date.now() }
      }));
    });
  }
}

if (typeof customElements !== "undefined" && !customElements.get("action-button")) {
  customElements.define("action-button", ActionButton);
}
  4. disconnectedCallback — Clear a timer started on connect. ▾ Solution 
    class TickingClock extends (typeof HTMLElement !== "undefined" ? HTMLElement : Object) {
  connectedCallback() {
    this.timerId = setInterval(() => {
      console.log("Clock tick:", new Date().toLocaleTimeString());
    }, 1000);
  }

  disconnectedCallback() {
    // Critical: prevent memory leaks when element is removed from DOM
    clearInterval(this.timerId);
    console.log("Clock removed from DOM: timer cleared.");
  }
}

if (typeof customElements !== "undefined" && !customElements.get("ticking-clock")) {
  customElements.define("ticking-clock", TickingClock);
}

L2 Intermediate

P.3. Challenge

  1. form-associated sketch — Comment or implement a minimal custom input pattern. ▾ Solution 
    /*
Form-Associated Custom Element Pattern (ElementInternals API):
- Allows custom elements to participate in standard HTML <form> submission, validation, and resets.
*/
class CustomInput extends (typeof HTMLElement !== "undefined" ? HTMLElement : Object) {
  static formAssociated = true;

  constructor() {
    super();
    if (this.attachInternals) {
      this.internals_ = this.attachInternals();
    }
  }

  set value(val) {
    this.internals_?.setFormValue(val);
  }
}

console.log("Form-associated custom input pattern defined.");
  2. closed vs open shadow — Demo accessibility to shadowRoot from outside. ▾ Solution 
    // Open vs Closed Shadow DOM demonstration:
if (typeof document !== "undefined") {
  // 1. Open Shadow DOM:
  const openHost = document.createElement("div");
  const openShadow = openHost.attachShadow({ mode: "open" });
  console.log("openHost.shadowRoot === openShadow:", openHost.shadowRoot === openShadow); // true

  // 2. Closed Shadow DOM:
  const closedHost = document.createElement("div");
  closedHost.attachShadow({ mode: "closed" });
  console.log("closedHost.shadowRoot:", closedHost.shadowRoot); // null (inaccessible from outside)
} else {
  console.log("Open vs Closed: host.shadowRoot returns the root if mode === 'open', null if mode === 'closed'.");
}
