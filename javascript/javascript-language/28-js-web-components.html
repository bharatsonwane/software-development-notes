2. Custom elements

L1 L2

L1 Fundamental

  • Name must include a hyphen. Extend HTMLElement and register with customElements.define.
class HelloWorld extends HTMLElement {
  connectedCallback() {
    this.textContent = "Hello";
  }
}
customElements.define("hello-world", HelloWorld);
// <hello-world></hello-world>

L1 Fundamental

2.1. Lifecycle callbacks

CallbackWhen
connectedCallbackInserted into document
disconnectedCallbackRemoved from document
attributeChangedCallbackObserved attribute changes
adoptedCallbackMoved to a new document
 
class Greeter extends HTMLElement {
  static get observedAttributes() { return ["name"]; }

  attributeChangedCallback(name, oldVal, newVal) {
    if (name === "name") this.render();
  }

  connectedCallback() { this.render(); }

  render() {
    this.textContent = `Hello, ${this.getAttribute("name") ?? "guest"}`;
  }
}
customElements.define("x-greeter", Greeter);

3. Shadow DOM

L1 L2

L1 Fundamental

  • Shadow DOM attaches an isolated DOM tree — styles and markup do not leak to/from the page by default.
class Card extends HTMLElement {
  constructor() {
    super();
    const root = this.attachShadow({ mode: "open" });
    root.innerHTML = `
      <style>p { color: navy; }</style>
      <p><slot></slot></p>
    `;
  }
}
customElements.define("x-card", Card);
  • mode: "open" → el.shadowRoot accessible. "closed" hides it (rare; security theater).

L2 Intermediate

3.1. Events and composed

  • Events from shadow trees may not bubble to the light DOM unless composed: true. Use e.composedPath() (File 24) to see hosts.
this.dispatchEvent(new CustomEvent("save", {
  bubbles: true,
  composed: true,
  detail: { id: 1 },
}));

4. Templates & slots

L1

L1 Fundamental

  • <template> holds inert HTML to clone. <slot> projects light-DOM children into the shadow tree.
// Light DOM:
// <x-card><span slot="title">Hi</span>Body</x-card>

// Shadow HTML:
// <slot name="title"></slot>
// <slot></slot>  — default slot

C. Common questions

L1 L2

L1 Fundamental

C.1. Why require a hyphen in the tag name?

  • A: Spec rule so custom tags never collide with future HTML elements.

L2 Intermediate

C.2. Shadow DOM vs iframe?

  • A: Shadow DOM is style/DOM encapsulation inside the same document and JS realm. iframes are separate documents (heavier; true process isolation only with care).
