2. Object-oriented concepts

L1

L1 Fundamental

2.1. Encapsulation

  • Hide internal state — closures (File 18), # private fields (this file), or module scope (File 22).

2.2. Inheritance

  • Share behavior via extends (this file) or the prototype chain (File 20).

L1 Fundamental

2.3. Polymorphism

  • Same interface, different implementations — method override in subclasses:
class Shape { area() { throw new Error("implement"); } }
class Circle extends Shape {
  constructor(r) { super(); this.r = r; }
  area() { return Math.PI * this.r ** 2; }
}

2.4. Abstraction

  • Expose simple API, hide complexity — e.g. fetch wrapper, repository class over raw HTTP.

3. Classes

L1 L2 L3

L1 Fundamental

  • ES6 class syntax is clearer but compiles to prototype + constructor mechanics.

3.1. Class basics

class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    return `Hi, ${this.name}`;
  }

  isAdult() {
    return this.age >= 18;
  }
}

const u = new User("Bharat", 30);
u.greet();  // "Hi, Bharat!"
  • Methods are on User.prototype (non-enumerable).
  • constructor is the initialization function called by new.
  • No hoisting like function declarations — TDZ until class line (File 08).
typeof User;  // "function" — classes are functions
User.prototype.greet === u.greet;  // false — bound method, but same prototype fn

3.2. Static methods and fields

  • Static — on the constructor, not instances:
class User {
  static fromJSON(json) {
    const data = JSON.parse(json);
    return new User(data.name, data.age);
  }

  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const u = User.fromJSON('{"name":"Bharat","age":30}');
  • Static fields (ES2022+):
class Config {
  static apiUrl = "https://api.example.com";
  static version = 1;
}

Config.apiUrl;
  • Instance fields (ES2022+):
class Counter {
  count = 0;

  increment() {
    this.count++;
  }
}

3.3. Getters and setters

class Rectangle {
  constructor(width, height) {
    this.width = width;
    this.height = height;
  }

  get area() {
    return this.width * this.height;
  }

  set area(value) {
    // example: set square from area
    const side = Math.sqrt(value);
    this.width = side;
    this.height = side;
  }
}

const rect = new Rectangle(4, 5);
rect.area;       // 20 — accessed like property
rect.area = 25;  // uses setter
  • Also valid in object literals (File 13):
const user = {
  _name: "",
  get name() { return this._name; },
  set name(v) { this._name = v.trim(); },
};

L2 Intermediate

3.4. extends and super

class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // must call before using `this` in subclass constructor
    this.breed = breed;
  }

  speak() {
    return `${this.name} barks`;
  }
}

const d = new Dog("Rex", "Lab");
d.speak();  // "Rex barks"
  • Rules:
  • super(...) in subclass constructor must run before this is used.
  • super.method() calls parent prototype method.
class Dog extends Animal {
  speak() {
    return super.speak() + " (loudly)";
  }
}

L3 Advanced

3.6. Private fields and methods (ES2022+)

  • True instance privacy with #:
class BankAccount {
  #balance = 0;

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}

const acct = new BankAccount();
acct.deposit(100);
// acct.#balance;  // SyntaxError — private outside class
  • Private is hard privacy — not accessible via closure trick from outside. Different from convention _prefix.

3.7. new.target

  • Inside a function or constructor, new.target is the constructor that was invoked with new, or undefined if called without new.
function User(name) {
  if (!new.target) {
    return new User(name);  // allow call without new
  }
  this.name = name;
}

class Animal {
  constructor() {
    console.log(new.target.name);  // subclass name when `new Dog()`
  }
}
class Dog extends Animal {}
new Dog();  // "Dog"
  • Useful for factory-style constructors and detecting which subclass was constructed. Prototype mechanics: File 20.

C. Common questions

L1 L2

L1 Fundamental

C.1. What are the OOP pillars in JavaScript? ▾ Answer

Encapsulation (hide state), inheritance (extends / prototypes), polymorphism (override methods), abstraction (simple API over complexity).

L1 Fundamental

C.2. When do I use class vs a plain object? ▾ Answer

Use class when you need many instances with shared methods, inheritance, or instanceof. Use a plain object (File 13) for one-off records / DTOs.

L2 Intermediate

C.3. Is class different from prototypes? ▾ Answer

At runtime, no — class is sugar over constructor + prototype. File 20 shows the compiled shape.

C.4. Why must super() run before this in a subclass? ▾ Answer

The parent constructor sets up the instance. Until super() returns, this is not initialized.

C.5. What is new.target? ▾ Answer

Meta-property: the constructor invoked with new (or undefined without new). In subclasses it is the most-derived constructor.

  1. Define a Person class with constructor and a method. ▾ Solution 
    class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  describe() {
    return `${this.name} is ${this.age} years old.`;
  }
}

const p = new Person("Bharat", 28);
console.log(p.describe()); // "Bharat is 28 years old."
  2. Extend it with Student and call super. ▾ Solution 
    class Student extends Person {
  constructor(name, age, grade) {
    super(name, age); // Calls parent constructor
    this.grade = grade;
  }

  study() {
    return `${this.name} is studying in grade ${this.grade}.`;
  }
}

const s = new Student("Alice", 20, "A");
console.log(s.describe()); // Inherited: "Alice is 20 years old."
console.log(s.study());    // "Alice is studying in grade A."
  3. Add a getter (e.g. fullName). ▾ Solution 
    class User {
  constructor(firstName, lastName) {
    this.firstName = firstName;
    this.lastName = lastName;
  }

  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  }
}

const u = new User("Bharat", "Sonwane");
console.log("Full name:", u.fullName); // "Bharat Sonwane"

P.2. Core tasks

  1. BankAccount — deposit/withdraw with validation; private field or closure for balance. ▾ Solution 
    class BankAccount {
  #balance = 0; // True private field

  constructor(initialAmount = 0) {
    if (initialAmount > 0) this.#balance = initialAmount;
  }

  deposit(amount) {
    if (amount <= 0) throw new Error("Deposit amount must be positive");
    this.#balance += amount;
    return this.#balance;
  }

  withdraw(amount) {
    if (amount > this.#balance) throw new Error("Insufficient funds");
    this.#balance -= amount;
    return this.#balance;
  }

  get balance() {
    return this.#balance;
  }
}

const account = new BankAccount(100);
account.deposit(50);
account.withdraw(30);
console.log("Current balance:", account.balance); // 120
// account.#balance throws SyntaxError outside the class
  2. static factory — User.createAdmin(name) static method. ▾ Solution 
    class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  static createAdmin(name) {
    return new User(name, "admin");
  }
}

const admin = User.createAdmin("Alice");
console.log("User:", admin.name, "| Role:", admin.role); // Alice | admin
  3. instanceof — Verify inheritance chain for your classes. ▾ Solution 
    console.log("s instanceof Student:", s instanceof Student); // true
console.log("s instanceof Person: ", s instanceof Person);  // true
console.log("s instanceof Object: ", s instanceof Object);  // true
  4. override — Child method calls super.method(). ▾ Solution 
    class Animal {
  makeSound() {
    return "Some generic animal sound";
  }
}

class Dog extends Animal {
  makeSound() {
    return `${super.makeSound()} -> Bark! Bark!`;
  }
}

const d = new Dog();
console.log(d.makeSound());
// "Some generic animal sound -> Bark! Bark!"

L2 Intermediate

P.3. Challenge

  1. composition vs inheritance — Model a Car that has an Engine object instead of extending Engine; comment tradeoff. ▾ Solution 
    // Composition: Car HAS-AN Engine (favor composition over inheritance)
class Engine {
  constructor(horsepower) {
    this.horsepower = horsepower;
  }
  start() {
    return `Vroom (${this.horsepower} HP)`;
  }
}

class Car {
  constructor(make, engine) {
    this.make = make;
    this.engine = engine;
  }
  drive() {
    return `${this.make} starting: ${this.engine.start()}`;
  }
}

const myCar = new Car("Tesla", new Engine(450));
console.log(myCar.drive()); // "Tesla starting: Vroom (450 HP)"
  2. new.target — Guard a constructor so it errors if called without new (function form) or document class behavior. ▾ Solution 
    function StrictConstructor(name) {
  if (!new.target) {
    throw new TypeError("StrictConstructor must be invoked with 'new'");
  }
  this.name = name;
}

try {
  StrictConstructor("Bad call");
} catch (err) {
  console.log("new.target guard:", err.message);
}

const instance = new StrictConstructor("Good call");
console.log("Created successfully:", instance.name); // "Good call"
