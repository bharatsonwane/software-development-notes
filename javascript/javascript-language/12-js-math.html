1. Math object

L1 L2

L1 Fundamental

  • Math is not a constructor — you call Math.method(...) directly. Constants: Math.PI, Math.E.

L2 Practical

1.1. Common methods

Math.abs(-5);       // 5
Math.ceil(4.2);     // 5
Math.floor(4.8);    // 4
Math.round(4.5);    // 5
Math.max(1, 5, 3);  // 5
Math.min(1, 5, 3);
Math.pow(2, 3);     // 8 — or 2 ** 3
Math.sqrt(16);      // 4
Math.random();      // 0 <= n < 1
Math.trunc(4.9);    // 4

1.2. Random integer in range

function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

1.3. Math.random vs crypto

  • Math.random() is fine for UI shuffle / games — not for tokens, IDs, or security.
crypto.randomUUID();  // "3b12f1df-..." — preferred IDs in browsers and modern Node

const bytes = new Uint8Array(16);
crypto.getRandomValues(bytes);  // CSPRNG

2. Common questions

L1 L2

L1 Fundamental

2.1. Is Math a number type?

  • A: No. It is a namespace object of functions and constants. Values you pass in and get back are File 11 numbers.

L2 Practical

2.2. How do you get a random integer in a range?

  • A: Math.floor(Math.random() * (max - min + 1)) + min (inclusive min and max).

2.3. Should I use Math.random for IDs?

  • A: No for secrets or uniqueness you care about. Use crypto.randomUUID() or crypto.getRandomValues.
