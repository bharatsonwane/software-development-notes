29. Performance & User Timing

File 29 — performance.now, marks/measures, Navigation Timing, observers.

L1 Fundamental

  • Measure real timings with the Performance APIs instead of guessing. App-level habits (debounce, avoid reflows) are File 23; interview engine notes are File 25.

L1 Fundamental

  • Default rule today: mark critical user journeys with User Timing; use DevTools Performance panel for deep dives; watch Core Web Vitals with PerformanceObserver when shipping web apps.

1. High resolution time

L1

L1 Fundamental

  • performance.now() returns ms since page time origin — monotonic, sub-ms precision. Prefer over Date.now() for durations.
const t0 = performance.now();
doWork();
const ms = performance.now() - t0;
console.log(`took ${ms.toFixed(2)} ms`);

2. User Timing

L1 L2

L1 Fundamental

  • Marks name a moment; measures name a duration between marks (or now).
performance.mark("fetch-start");
await fetch("/api");
performance.mark("fetch-end");
performance.measure("fetch", "fetch-start", "fetch-end");

const [entry] = performance.getEntriesByName("fetch");
console.log(entry.duration);

performance.clearMarks();
performance.clearMeasures();

L2 Intermediate

2.1. PerformanceObserver

const obs = new PerformanceObserver((list) => {
  for (const e of list.getEntries()) {
    console.log(e.name, e.duration, e.entryType);
  }
});
obs.observe({ type: "measure", buffered: true });
// Also: "mark", "navigation", "resource", "paint", "largest-contentful-paint", …

3. Navigation & Resource Timing

L2

L2 Intermediate

  • Navigation Timing — how the document loaded (DNS, connect, DOMContentLoaded, load).
  • Resource Timing — each script/CSS/image fetch.
const nav = performance.getEntriesByType("navigation")[0];
nav.domContentLoadedEventEnd - nav.startTime;

const resources = performance.getEntriesByType("resource");
resources.filter((r) => r.initiatorType === "script");
  • Paint timings: first-paint, first-contentful-paint. LCP / CLS / INP need observers / web-vitals libraries for reliable field data.

4. Common questions

L1 L2

L1 Fundamental

4.1. Why not Date.now() for benchmarks?

  • A: System clock can jump (NTP, user change). performance.now() is monotonic relative to the time origin.

L2 Intermediate

4.2. Mark vs measure?

  • A: A mark is a timestamp label. A measure is a duration entry between two marks (or a mark and now).
