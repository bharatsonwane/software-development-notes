07. Timers

File 07 — run a function once or repeatedly after a delay.

setTimeout setInterval clearTimeout clearInterval

L1 Fundamental

  • Timers schedule a function (File 05) to run later. They do not pause the rest of the program — other code keeps running until the delay finishes.
APIWhat it does
setTimeout()Runs a function once after a delay.
setInterval()Runs a function repeatedly.
clearTimeout()Cancels a timeout.
clearInterval()Stops an interval.

L2 Practical

Default rule today: save the id that setTimeout/setInterval returns, and always clearTimeout/clearInterval when you no longer need the callback.

1. setTimeout and clearTimeout

L1 L2 L3

L1 Fundamental

1.1. Run once after a delay

const id = setTimeout(() => {
  console.log("After 1 second");
}, 1000);

clearTimeout(id);  // cancel before it runs
  • Delay is in milliseconds: 1000 is 1 second.
  • setTimeout returns an id. Pass that id to clearTimeout to cancel.

L2 Practical

1.2. Extra arguments

setTimeout((name) => {
  console.log(`Hello, ${name}`);
}, 500, "Bharat");

L3 Intermediate

1.3. Delay 0 is not immediate

  • setTimeout(fn, 0) still runs after the current call stack. File 20 (event loop) explains why.

2. setInterval and clearInterval

L1 L2 L3

L1 Fundamental

2.1. Run repeatedly

let count = 0;
const id = setInterval(() => {
  count++;
  console.log(count);
  if (count >= 5) clearInterval(id);
}, 500);
  • setInterval keeps calling the function until you clearInterval.

L2 Practical

  • Always clearInterval when done — leftover intervals keep running and can leak memory (File 22).

L3 Intermediate

2.2. requestAnimationFrame

  • For smooth animation synced to display refresh (~60fps), prefer rAF over setInterval:
function animate() {
  // update positions
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);

// cancel: cancelAnimationFrame(id);

3. Common questions

L1 L2 L3

L1 Fundamental

3.1. What is the difference between setTimeout and setInterval?

  • A: setTimeout runs once after a delay. setInterval repeats until cleared.

L2 Practical

3.2. What do clearTimeout and clearInterval do?

  • A: clearTimeout cancels a pending timeout so it never runs. clearInterval stops a repeating interval. Both need the id returned by setTimeout/setInterval.

3.3. Why use requestAnimationFrame?

  • A: It batches visual updates with the browser repaint cycle — smoother than a fixed setInterval.
