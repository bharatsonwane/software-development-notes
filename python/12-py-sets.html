1. Introduction

L1

L1 Fundamental

1.1. Overview

  • A Set in Python is an unordered, mutable, unindexed collection of unique, hashable objects. It is represented by the built-in set type.
  • Sets mirror mathematical set theory: duplicates are strictly impossible, order is not guaranteed, and elements cannot be accessed using numeric indices or slices (s[0] raises a TypeError).
  • The primary superpowers of sets in Python are instantaneous $O(1)$ average-time membership testing (x in s), automatic duplicate elimination, and highly optimized mathematical set algebra (unions, intersections, differences).

1.2. Internal Implementation in CPython

Under the Hood (PySetObject): In CPython, a set is implemented as a hash table with open addressing and quadratic probing, very similar to dictionary keys:
  • When an item is inserted, Python computes its hash using hash(item) and maps it to a hash bucket.
  • Constant Time Operations: Lookup (in), insertion (add), and deletion (discard) execute in $O(1)$ average time complexity, compared to $O(N)$ linear scans in lists and tuples.
  • Requirement: Because sets rely on hashing, every element inserted into a set must be hashable (immutable objects whose hash value never changes).

2. Set properties and creation

L1 L2

L1 Fundamental

2.1. Core Characteristics of Python Sets

PropertyBehaviorDetails
Unordered Yes Elements do not maintain any predictable sequence. Iteration order depends on hash values and table sizing.
Unique Elements Yes Duplicate values are silently ignored and discarded upon insertion.
Mutable Collection Yes You can add and remove elements dynamically.
Unindexed Yes Indexing (s[0]) and slicing (s[1:3]) are unsupported and raise TypeError.
Hashable Elements Mandatory Elements must be immutable (integers, floats, strings, tuples). Mutable objects like lists, dicts, and sets are illegal.

2.2. Ways to Create a Set & The Empty Set Trap

The Empty Set Trap: Writing s = {} does NOT create an empty set; it creates an empty Dictionary (dict) for historical reasons. To create an empty set, you must use the set() constructor. 
# The Empty Set Trap:
empty_dict = {}
print(type(empty_dict))  # <class 'dict'>

empty_set = set()
print(type(empty_set))   # <class 'set'>

# Set literals with non-empty elements:
primes = {2, 3, 5, 7, 11}
print(primes)

# Automatic deduplication:
numbers = {10, 20, 10, 30, 20, 40}
print("Deduplicated:", numbers)  # {40, 10, 20, 30} (Duplicates removed)

# Creating set from any iterable:
char_set = set("MISSISSIPPI")
print("Unique chars:", char_set)  # {'M', 'I', 'S', 'P'}

list_dedup = set([1, 2, 2, 3, 4, 4, 5])
print("List deduplication:", list_dedup)  # {1, 2, 3, 4, 5}

L2 Intermediate

2.3. The Unhashable Type Error

A set can only contain objects that possess a lifetime-constant hash value. Attempting to insert a mutable container raises a TypeError:

# Valid elements (Immutable / Hashable):
valid_set = {10, "Sonwane", (1, 2, 3), 3.14}
print("Valid set:", valid_set)

# Invalid elements (Mutable / Unhashable):
# bad1 = {[1, 2], [3, 4]}  # TypeError: unhashable type: 'list'
# bad2 = {{1, 2}, {3, 4}}  # TypeError: unhashable type: 'set'
# bad3 = {{"a": 1}}        # TypeError: unhashable type: 'dict'

2.4. The frozenset (Immutable Set)

  • A frozenset is an immutable, read-only version of a Python set.
  • Because it is immutable, a frozenset is hashable: it can be used as a dictionary key or stored as an element inside another set.
fs = frozenset([1, 2, 3, 4, 4])
print(fs)           # frozenset({1, 2, 3, 4})
# fs.add(5)         # AttributeError: 'frozenset' object has no attribute 'add'

# Using frozenset as a dictionary key:
role_permissions = {
    frozenset(["read", "write"]): "Editor",
    frozenset(["read"]): "Viewer",
    frozenset(["read", "write", "delete", "admin"]): "Admin"
}

user_perms = frozenset(["write", "read"])
print("Role:", role_permissions[user_perms])  # Editor (Order-independent lookup!)

3. Important set methods

L1 L2

L1 Fundamental

3.1. Adding Elements: add() vs update()

MethodArgumentBehavior
s.add(item) Single hashable item Inserts the item directly into the set ($O(1)$).
s.update(*iterables) One or more iterables Unpacks all items from the iterables and adds them individually. 
s = {10, 20}

# add():
s.add(30)
print(s)  # {10, 20, 30}

# update() takes multiple iterables (lists, strings, tuples, sets):
s.update([40, 50], (60, 70), "AB")
print("After update:", s)  # {10, 20, 30, 40, 50, 60, 70, 'A', 'B'}

3.2. Removing Elements: remove() vs discard()

Key Interview Difference:
  • s.remove(x): Removes x. If x is missing, it raises a KeyError.
  • s.discard(x): Removes x if present. If x is missing, it does nothing silently without raising an error. Always prefer discard() when deleting elements that might not exist.
fruits = {"apple", "banana", "cherry"}

# discard() is safe:
fruits.discard("banana")
fruits.discard("mango")  # No error raised even though 'mango' is absent
print("After discard:", fruits)  # {'apple', 'cherry'}

# remove() raises error on missing item:
fruits.remove("apple")
print("After remove:", fruits)   # {'cherry'}
# fruits.remove("mango")         # Raises KeyError: 'mango'

L2 Intermediate

3.3. pop() and clear()

  • s.pop(): Removes and returns an arbitrary element from the set. Raises KeyError if the set is empty. (Note: "arbitrary" does not mean cryptographically random; it depends on internal hash bucket placement).
  • s.clear(): Removes all elements, leaving an empty set (set()).
tags = {"python", "cloud", "backend", "api"}

removed_tag = tags.pop()
print(f"Popped tag: '{removed_tag}', Remaining tags: {tags}")

tags.clear()
print("After clear:", tags)  # set()

4. Mathematical and membership operators

L1 L2

L1 Fundamental

4.1. Set Algebraic Operations Table

OperationOperatorMethodDefinition
Union A | B A.union(B) All elements present in set A, set B, or both.
Intersection A & B A.intersection(B) Only elements present in both set A and set B.
Difference A - B A.difference(B) Elements present in A that are NOT in B.
Symmetric Difference A ^ B A.symmetric_difference(B) Elements in A or B, but NOT in both (Exclusive OR).
Operator vs Method Nuance: The operators (|, &, -, ^) strictly require both operands to be sets. The corresponding methods (union(), intersection(), etc.) accept any iterable (list, tuple, string, dictionary) as arguments! 
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}

print("Union (|):                ", a | b)                 # {1, 2, 3, 4, 5, 6, 7, 8}
print("Intersection (&):         ", a & b)                 # {4, 5}
print("Difference (a - b):        ", a - b)                 # {1, 2, 3}
print("Difference (b - a):        ", b - a)                 # {6, 7, 8}
print("Symmetric Diff (a ^ b):    ", a ^ b)                 # {1, 2, 3, 6, 7, 8}

# Method accepts arbitrary iterables:
print("Union with list:          ", a.union([99, 100]))     # {1, 2, 3, 4, 5, 99, 100}
# print(a | [99, 100])  # Raises TypeError: unsupported operand type(s) for |: 'set' and 'list'

L2 Intermediate

4.2. In-Place Set Mutation Operations

You can update a set in-place using augmented assignment operators:

  • a |= b: a.update(b) (Union in-place)
  • a &= b: a.intersection_update(b) (Intersection in-place)
  • a -= b: a.difference_update(b) (Difference in-place)
  • a ^= b: a.symmetric_difference_update(b) (Symmetric diff in-place)

4.3. Subset, Superset & Disjoint Relations

small = {1, 2}
large = {1, 2, 3, 4}
disjoint = {5, 6}

# Subset (<=) and Proper Subset (<):
print("small issubset large:     ", small.issubset(large))    # True
print("small <= large:            ", small <= large)           # True
print("small < large (proper):    ", small < large)            # True

# Superset (>=):
print("large is superset of small:", large.issuperset(small))  # True

# Disjoint (zero shared elements):
print("small isdisjoint disjoint: ", small.isdisjoint(disjoint)) # True

5. Set comprehension

L1 L2

L1 Fundamental

5.1. Syntax & Mental Model

Set comprehension uses curly braces {} with an expression and iteration clause. It dynamically builds a set while automatically deduplicating values:

# General Syntax:
# {  for  in  if  }

# Extract unique lengths of words:
words = ["apple", "banana", "cherry", "fig", "date", "banana", "kiwi"]
lengths = {len(w) for w in words}
print("Unique word lengths:", lengths)  # {4, 5, 6, 3}

# Unique uppercase vowels in a paragraph:
text = "The quick brown fox jumps over the lazy dog"
vowels = {char.upper() for char in text if char.lower() in "aeiou"}
print("Unique vowels:", vowels)  # {'E', 'U', 'I', 'O', 'A'}

5.2. Practical Sanitization & File Extensions

# Extract unique file extensions from a list of filenames:
files = ["main.py", "test.py", "index.html", "style.css", "script.PY", "notes.txt", "app.js"]
extensions = {f.rsplit(".", 1)[-1].lower() for f in files if "." in f}

C. Common questions

L1 L2

L1 Fundamental

C.1. Why does {} create a dictionary instead of an empty set? ▾ Answer

Dictionaries were introduced in Python long before sets (sets were added in Python 2.3 as a module, and made built-in syntax in Python 2.4). Because {} was already established as the literal for an empty dictionary, reusing it for sets would have broken existing code.

Consequently, an empty set must be instantiated explicitly using set().

C.2. Why is membership testing (item in s) O(1) in a set but O(N) in a list? ▾ Answer

In a list, elements are stored sequentially. To check if an item exists, Python must iterate through the list from index 0 to $N-1$ until a match is found ($O(N)$ linear search).

In a set, elements are indexed via a hash table. Python computes hash(item) in $O(1)$ time, directly jumps to the calculated bucket address in memory, and verifies whether the bucket is occupied. This results in $O(1)$ average-case lookup time regardless of whether the set contains 10 items or 10,000,000 items.

C.3. What is the difference between remove() and discard()? ▾ Answer
  • s.remove(x): Removes x from the set. If x is not present, it raises a KeyError. Use this only when the absence of an item indicates an abnormal application state.
  • s.discard(x): Removes x if present. If absent, it silently completes without error. Ideal for idempotent cleanups.
C.4. Why can't a set contain a list or another set? What is hashability? ▾ Answer

To place an object into a hash table, Python must compute its hash code via hash(obj). An object is hashable only if:

  1. Its hash value never changes during its entire lifetime.
  2. It can be compared for equality with other objects (__eq__).

Because lists, dictionaries, and sets are mutable, their contents can change at any time. If an object's contents change, its hash value would change, meaning Python would search for it in the wrong hash bucket! To preserve hash table integrity, Python forbids mutable objects from being inserted into sets, raising TypeError: unhashable type: 'list'.

L2 Intermediate

C.5. What is a frozenset and when should you use it? ▾ Answer

A frozenset is an immutable, hashable variant of a set. Because it cannot be modified after construction, it implements __hash__().

You should use a frozenset when:

  • You need to use a set as a dictionary key (e.g. mapping a composite set of user roles or tag combinations to a permission level).
  • You need to store sets inside another set (a "set of sets").
C.6. What is the difference between set operators (| , &) and set methods (union, intersection)? ▾ Answer

Operand Type Flexibility:

  • Set operators (A | B, A & B, A - B, A ^ B) strictly require both operands to be instances of set or frozenset. If one operand is a list, Python raises a TypeError.
  • Set methods (A.union(B), A.intersection(B)) accept any arbitrary iterable (e.g. lists, tuples, dictionaries, generator expressions) as arguments.
C.7. What is the difference between Difference (A - B) and Symmetric Difference (A ^ B)? ▾ Answer
  • Difference (A - B): Elements that belong strictly to set A and do not exist in set B (Relative complement). Order matters: A - B != B - A.
  • Symmetric Difference (A ^ B): Elements that belong to A or B, but NOT to both. It is equivalent to (A | B) - (A & B). It is commutative: A ^ B == B ^ A.
C.8. Why is s.pop() considered arbitrary rather than random? ▾ Answer

s.pop() does not use a random number generator. Instead, it scans the underlying CPython hash table array from index 0 onwards and removes the very first occupied entry it encounters.

Because the physical slot an element occupies depends strictly on its hash value and table resize history, consecutive calls in the same Python process will pop elements in deterministic hash-table order, not a uniformly distributed random order.

def is_pangram(sentence: str) -> bool:
    alphabet_set = set(string.ascii_lowercase)
    sentence_set = {ch.lower() for ch in sentence if ch.isalpha()}
    return alphabet_set <= sentence_set

  1. Challenge 1: Jaccard Similarity Coefficient — Calculate text similarity between two documents based on set intersection and union. ▾ Solution 
    def jaccard_similarity(text1: str, text2: str) -> float:
    set1 = set(text1.lower().split())
    set2 = set(text2.lower().split())
    intersection_len = len(set1 & set2)
    union_len = len(set1 | set2)
    return round(intersection_len / union_len, 4) if union_len > 0 else 1.0

s1 = "data science with python and machine learning algorithms"
s2 = "machine learning and deep learning with python algorithms"
similarity = jaccard_similarity(s1, s2)
print(f"Jaccard Similarity: {similarity * 100:.2f}%")
# Jaccard Similarity: 55.56%
  2. Challenge 2: Role-Based Access Control (RBAC) Engine — Implement permission verification using set algebra and frozenset. ▾ Solution 
    # User has assigned permissions:
user_permissions = {"read:posts", "write:posts", "read:profile"}

# Endpoint requires specific permissions:
required_permissions = {"read:posts", "write:posts"}
admin_permissions = {"read:posts", "write:posts", "delete:posts"}

def has_access(granted: set, required: set) -> bool:
    # All required permissions must be a subset of granted permissions:
    return required <= granted

print("Has admin access:   ", has_access(user_permissions, admin_permissions))     # False
