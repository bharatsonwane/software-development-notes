P.1. Warm-up

  1. Skim the section map; write a 3-bullet comment summarizing Aliasing vs cloning. ▾ Solution 
    # Summary of Aliasing vs Cloning:
# 1. Aliasing ('b = a') gives an existing object another reference name (same memory address).
# 2. Cloning creates a separate copy of the object in memory (different memory address).
# 3. Changes to an alias affect the original object; changes to a clone do not.
  2. Create a tiny example related to Shallow copy vs deep copy and print the result. ▾ Solution 
    # Shallow copy vs deep copy:
import copy

original = [1, [2, 3]]
shallow = copy.copy(original)
deep = copy.deepcopy(original)

shallow[1].append(4)  # Mutates inner list in original too!
print("Original after shallow mutate:", original) # [1, [2, 3, 4]]

deep[1].append(99)   # Completely independent!
print("Original after deep mutate:", original)    # [1, [2, 3, 4]]
print("Deep copy contents:", deep)               # [1, [2, 3, 99]]

  1. Task 1: Aliasing vs cloning — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 1: Aliasing vs cloning
# Aliasing:
orig_list = [10, 20, 30]
alias_list = orig_list
print("id(orig):", id(orig_list), "== id(alias):", id(alias_list))
alias_list.append(40)
print("orig_list modified through alias:", orig_list)  # [10, 20, 30, 40]

# Cloning via slicing:
clone_list = orig_list[:]
clone_list.append(50)
print("orig_list after clone append:", orig_list)      # [10, 20, 30, 40]
print("clone_list:", clone_list)                      # [10, 20, 30, 40, 50]
  2. Task 2: Shallow copy vs deep copy — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 2: Shallow copy vs deep copy
import copy

nested = {"user": "Alice", "preferences": {"theme": "dark", "zoom": 100}}

shallow_dict = copy.copy(nested)
deep_dict = copy.deepcopy(nested)

# Mutate nested dictionary:
shallow_dict["preferences"]["theme"] = "light"
print("Original theme after shallow change:", nested["preferences"]["theme"]) # 'light'

deep_dict["preferences"]["theme"] = "sepia"
print("Original theme after deep change:", nested["preferences"]["theme"])    # 'light' (unaffected!)
print("Deep dict theme:", deep_dict["preferences"]["theme"])                 # 'sepia'
  3. Cheat sheet — Comment 5 key facts about Aliasing, Cloning, and Copy. ▾ Solution 
    # Cheat sheet — 5 Key Facts about Aliasing, Cloning, and Copy:
# 1. Assignment ('=') NEVER creates a copy; it only binds another name to the existing object.
# 2. 'is' checks if two references share the same id; '==' checks if values are equal.
# 3. Slice operator [:], list.copy(), and dict.copy() all perform SHALLOW copies.
# 4. Shallow copy duplicates outer container but copies references to nested objects.
# 5. copy.deepcopy() recursively traverses and duplicates every nested container and object.

  1. Mini project — Combine two topics from this file into one short script related to Aliasing, Cloning, and Copy. ▾ Solution 
    # Mini Project: Safe Configuration Snapshot & Rollback Engine
import copy

class ConfigManager:
    def __init__(self, initial_config):
        self.config = initial_config
        self.snapshots = []
    
    def take_snapshot(self):
        # Deep copy ensures snapshots are immutable records of past state
        self.snapshots.append(copy.deepcopy(self.config))
        print(f"Snapshot taken at version {len(self.snapshots)}")
    
    def rollback(self):
        if self.snapshots:
            self.config = self.snapshots.pop()
            print("Rolled back to previous snapshot successfully.")
        else:
            print("No snapshot available to rollback.")

mgr = ConfigManager({"server": {"host": "localhost", "port": 8000}})
mgr.take_snapshot()

# Mutate nested configuration:
mgr.config["server"]["port"] = 9999
print("Mutated config:", mgr.config)

# Rollback:
mgr.rollback()
print("Restored config:", mgr.config)
