26. Aliasing, Cloning, and Copy

Reference assignment, identity vs equality, shallow copy mechanics, and recursive deep copy.

Aliasing is vs == copy.copy() copy.deepcopy() Mutable Compound Objects

1. Introduction

L1

L1 Fundamental

1.1. Overview: How Python Manages Variables and Memory

In Python, variables are not direct memory "boxes" that store raw values. Instead, a variable is a name tag (reference pointer) bound to an object in heap memory. Multiple variables can point to the exact same object simultaneously.

When working with mutable compound objects (like lists, dictionaries, sets, or custom class instances), misunderstanding the distinction between aliasing, shallow copying, and deep copying is one of the most frequent causes of silent data corruption bugs.

1.2. Identity (is) vs Equality (==)

  • Equality (==): Evaluates whether two objects contain the same values or state (invokes __eq__).
  • Identity (is): Evaluates whether two variables point to the exact same memory address (compares id(a) == id(b)).
list_a: list[int] = [1, 2, 3]
list_b: list[int] = [1, 2, 3]
list_c: list[int] = list_a  # Aliasing

print("list_a == list_b:", list_a == list_b)  # True (equal content)
print("list_a is list_b:", list_a is list_b)  # False (distinct objects in RAM)
print("list_a is list_c:", list_a is list_c)  # True (same memory location!)

1.3. Typing Identity & Copy Operations (TypeVar & Generic Containers)

In modern Python 3.10+, static type checkers preserve container types through copy operations. Use TypeVar when implementing custom copy dunder protocols:

import copy
from typing import TypeVar, Any

T = TypeVar("T")

def duplicate_container(data: list[T]) -> list[T]:
    """Clone container while preserving exact item types."""
    return copy.copy(data)

class Node:
    def __init__(self, val: int) -> None:
        self.val: int = val

    def __copy__(self: T) -> T:
        return type(self)(self.val)

    def __deepcopy__(self: T, memo: dict[int, Any]) -> T:
        copied: T = type(self)(self.val)
        memo[id(self)] = copied
        return copied

n1: Node = Node(42)
n2: Node = copy.deepcopy(n1)
print(f"n1 val={n1.val}, n2 val={n2.val}, is duplicate={n1 is not n2}")

2. Aliasing vs cloning

L1 L2

L1 Fundamental

2.1. Aliasing: Multiple Names for One Object

Aliasing happens when you assign one variable to another using the assignment operator = (e.g., b = a). This creates a second reference to the exact same object; no new object is allocated in memory.

If the underlying object is mutable, modifying it through any alias immediately affects all other references to it.

original_users: list[str] = ["Alice", "Bob"]
alias_users: list[str] = original_users  # Aliasing: both point to the same list

# Mutating via the alias:
alias_users.append("Charlie")

print("original_users:", original_users)  # ['Alice', 'Bob', 'Charlie']
print("alias_users:   ", alias_users)     # ['Alice', 'Bob', 'Charlie']
print("id(original):", id(original_users))
print("id(alias):   ", id(alias_users))   # Identical IDs

L2 Intermediate

2.2. Cloning: Independent Top-Level Containers

Cloning creates a brand new top-level container object with its own distinct memory address. Common ways to clone a list include:

  • Slice notation: clone = original[:]
  • The .copy() method: clone = original.copy()
  • Constructor function: clone = list(original)
original_nums: list[int] = [10, 20, 30]
cloned_nums: list[int] = original_nums[:]  # Creating a clone

cloned_nums.append(40)

print("Original:", original_nums)  # [10, 20, 30] (Unchanged!)
print("Cloned:  ", cloned_nums)    # [10, 20, 30, 40]
print("original is cloned:", original_nums is cloned_nums)  # False

3. Shallow copy vs deep copy

L1 L2

L1 Fundamental

3.1. The Limitation of Shallow Copy

Both slicing ([:]) and copy.copy() produce a shallow copy. A shallow copy constructs a new compound object and then inserts references into it to the objects found in the original.

If the original object contains nested mutable objects (e.g. a list of lists, or a dictionary containing lists), the outer container is duplicated, but the nested inner objects are shared by reference!

import copy

# Matrix with nested lists
matrix: list[list[int]] = [[1, 2], [3, 4]]

# Creating a shallow copy
shallow_matrix: list[list[int]] = copy.copy(matrix)

# 1. Mutating the outer container:
shallow_matrix.append([5, 6])
print("matrix length:", len(matrix))                # 2 (matrix unaffected)
print("shallow_matrix length:", len(shallow_matrix)) # 3

# 2. Mutating an INNER nested element:
shallow_matrix[0][0] = 999  # Modifies the shared inner list [1, 2]!

print("Original matrix[0]:", matrix[0])         # [999, 2] (UNEXPECTED MUTATION!)
print("Shallow matrix[0]: ", shallow_matrix[0]) # [999, 2]
print("Inner list identity:", matrix[0] is shallow_matrix[0])  # True!

L2 Intermediate

3.2. Deep Copy: True Recursive Duplication

A deep copy constructed via copy.deepcopy() creates a new compound object and then recursively copies all nested objects found within it, creating completely independent duplicate copies at every level of depth.

import copy
from typing import Any

original_data: dict[str, Any] = {
    "project": "Alpha",
    "teams": ["Engineering", "DevOps"],
    "meta": {"version": 1.0}
}

# Deep copy
deep_data: dict[str, Any] = copy.deepcopy(original_data)

# Mutating nested structures in the deep copy:
deep_data["teams"].append("Security")
deep_data["meta"]["version"] = 2.0

print("Original teams:", original_data["teams"])  # ['Engineering', 'DevOps'] (Pristine!)
print("Deep copy teams:", deep_data["teams"])      # ['Engineering', 'DevOps', 'Security']

print("Original version:", original_data["meta"]["version"])  # 1.0
print("Deep copy version:", deep_data["meta"]["version"])      # 2.0

3.3. Cyclic References and Memoization

In complex data structures, an object may reference itself (circular reference). If copy.deepcopy() simply used naive recursion, it would crash with a RecursionError. Instead, deepcopy() maintains an internal memo dictionary tracking already-copied objects to safely handle self-referencing and cyclic graphs.

import copy
from typing import Any

# Self-referencing list:
cyclic_list: list[Any] = [1, 2]
cyclic_list.append(cyclic_list)  # Index 2 points to cyclic_list itself!

# Deep copy handles cycles safely without infinite recursion:
safe_copy: list[Any] = copy.deepcopy(cyclic_list)
print("Safe copy element 0:", safe_copy[0])
print("Safe copy cycle check:", safe_copy[2] is safe_copy)  # True (Preserves cycle structure!)

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the fundamental difference between aliasing and copying in Python? ▾ Answer

Aliasing (b = a): Does not create a new object. It assigns a new variable name pointing to the exact same object in memory (a is b is True). Changes made via one name affect the other.

Copying (b = a.copy()): Allocates a brand new object in memory with identical contents (a == b is True, but a is b is False). Modifying the top-level container b does not affect a.

C.2. What is the difference between == and is? ▾ Answer

== checks for value equality (calls __eq__), checking whether two objects contain identical data.

is checks for object identity, comparing their memory addresses (id(a) == id(b)). Two distinct objects can be equal in value ([1, 2] == [1, 2]) while not being identical ([1, 2] is [1, 2] is False).

C.3. What is the exact difference between a shallow copy and a deep copy? ▾ Answer

A shallow copy (via copy.copy() or lst[:]) duplicates only the outermost container. Nested objects (like sub-lists or dictionaries) inside the container are not cloned; their memory references are shared between the original and the copy.

A deep copy (via copy.deepcopy()) recursively duplicates all nested objects at every level of depth, ensuring that modifying any nested component in the copy has zero effect on the original.

C.4. What are the common ways to create a shallow copy? ▾ Answer
  • Lists: lst.copy(), slice lst[:], or type constructor list(lst).
  • Dictionaries: d.copy() or type constructor dict(d).
  • Sets: s.copy() or type constructor set(s).
  • Generic: copy.copy(obj) from the standard copy module.

L2 Intermediate

C.5. How does copy.deepcopy() prevent infinite loops with cyclic references? ▾ Answer

copy.deepcopy() accepts an internal memo dictionary (mapping id(orig_object) to copied_object). Before copying an object, deepcopy() checks if its ID already exists in the memo map.

If it exists, it returns the already-created copy reference instead of re-entering recursion, elegantly handling self-referencing and circular object graphs without stack overflow.

C.6. How do immutable objects behave when passed to copy.copy() and copy.deepcopy()? ▾ Answer

Because immutable objects (integers, floats, strings, frozensets, and tuples containing only immutables) can never be modified in-place, Python optimizes copying by returning the original object reference directly:

import copy

s: str = "hello"
print(copy.copy(s) is s)      # True
print(copy.deepcopy(s) is s)  # True

However, if a tuple contains a mutable object (e.g. t = ([1, 2], 3)), deepcopy(t) will create a new tuple containing a deep-copied list.

C.7. How do custom classes implement custom copying behavior? ▾ Answer

Custom classes can define two special dunder methods:

  • __copy__(self): Called by copy.copy(obj) to implement custom shallow copying.
  • __deepcopy__(self, memo): Called by copy.deepcopy(obj, memo) to implement custom deep copying, passing memo to any child copies via copy.deepcopy(child, memo).
C.8. Why should you avoid deepcopy() in performance-critical loops? ▾ Answer

copy.deepcopy() is relatively slow because it performs extensive Python-level reflection, inspects object dictionaries, maintains the memo table, and handles recursion. In high-throughput systems (such as processing 50,000 JSON payloads/sec), deep copying large graphs introduces significant CPU and memory overhead. Instead, consider immutable data patterns or manual shallow updates.

P.3. Challenge

  1. Mini project — Build a Configuration Manager class that provides safe snapshot rollbacks using copy.deepcopy(). ▾ Solution 
    # Mini Project: Config Snapshot Manager
import copy
from typing import Any

class ConfigManager:
    def __init__(self, initial_config: dict[str, Any]) -> None:
        self.config: dict[str, Any] = copy.deepcopy(initial_config)
        self.snapshots: list[dict[str, Any]] = []

    def set(self, key_path: str, value: Any) -> None:
        keys: list[str] = key_path.split(".")
        target: Any = self.config
        for k in keys[:-1]:
            target = target[k]
        target[keys[-1]] = value

    def create_snapshot(self) -> None:
        self.snapshots.append(copy.deepcopy(self.config))
        print("[SNAPSHOT] Saved state.")

    def rollback(self) -> None:
        if not self.snapshots:
            raise IndexError("No snapshots available for rollback!")
        self.config = self.snapshots.pop()
        print("[ROLLBACK] Restored previous state.")

initial: dict[str, Any] = {"database": {"host": "localhost", "replicas": ["db1", "db2"]}}
mgr: ConfigManager = ConfigManager(initial)
mgr.create_snapshot()

mgr.set("database.host", "remote.host.com")
mgr.set("database.replicas", ["remote1"])
print("Modified config:", mgr.config)

mgr.rollback()
print("Restored config:", mgr.config)

import copy
from typing import Any

node_a: dict[str, Any] = {"name": "A"}
node_b: dict[str, Any] = {"name": "B"}
node_a["neighbor"] = node_b
