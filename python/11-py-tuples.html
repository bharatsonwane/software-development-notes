P.2. Core tasks

  1. Task 1: Introduction to tuple — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 1: Introduction to tuple
# Tuple packing and unpacking:
point = 4, 5, 6  # Parentheses are optional in packing
x, y, z = point  # Unpacking
print(f"Point: {point}, x={x}, y={y}, z={z}")

# Single element tuple trap:
not_a_tuple = ("apple")
is_a_tuple = ("apple",)
print("not_a_tuple type:", type(not_a_tuple)) # str
print("is_a_tuple type:", type(is_a_tuple))   # tuple
  2. Task 2: Tuple methods and functions — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 2: Tuple methods and functions
data = ("apple", "banana", "cherry", "banana")
print("Occurrences of 'banana':", data.count("banana"))
print("First index of 'cherry':", data.index("cherry"))

# Tuples support concatenation and repetition (+ and *):
t1 = (1, 2)
t2 = (3, 4)
t_combined = t1 + t2
t_repeated = t1 * 3
print("Combined:", t_combined)
print("Repeated:", t_repeated)
  3. Task 3: Tuple comprehension patterns — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 3: Tuple comprehension patterns
# Note: (x for x in ...) creates a generator expression, NOT a tuple!
gen = (x * 2 for x in range(5))
print("Generator expression:", gen)

# To create a tuple from comprehension, pass the generator to tuple():
t_comp = tuple(x * 2 for x in range(5))
print("Tuple from generator:", t_comp)
  4. Task 4: Tuple vs list differences — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 4: Tuple vs list differences
import sys

lst = [1, 2, 3, 4, 5]
tpl = (1, 2, 3, 4, 5)

print("List size in bytes:", sys.getsizeof(lst))
print("Tuple size in bytes:", sys.getsizeof(tpl)) # Significantly smaller!

# Tuples can be dictionary keys:
locations = {
    (40.7128, -74.0060): "New York",
    (34.0522, -118.2437): "Los Angeles"
}
print("Location lookup:", locations[(40.7128, -74.0060)])
# {[1, 2]: 'Error'} would raise TypeError: unhashable type: 'list'

P.3. Challenge

  1. Mini project — Combine two topics from this file into one short script related to Tuples. ▾ Solution 
    # Mini Project: Transaction Record Keeper using collections.namedtuple
from collections import namedtuple

Transaction = namedtuple("Transaction", ["id", "user", "amount", "status"])

ledger = [
    Transaction(101, "Alice", 250.00, "COMPLETED"),
    Transaction(102, "Bob", 15.50, "PENDING"),
    Transaction(103, "Charlie", 420.00, "COMPLETED"),
    Transaction(104, "Diana", 85.00, "FAILED")
]

completed_total = sum(t.amount for t in ledger if t.status == "COMPLETED")
print("Ledger Transactions:")
for t in ledger:
    print(f"  Tx #{t.id} - {t.user:<8}: ${t.amount:>7.2f} [{t.status}]")
print("-" * 35)
print(f"Total Completed Volume: ${completed_total:.2f}")
  2. Edge cases — List 3 edge cases or mistakes beginners make; demonstrate at least one safely. ▾ Solution 
    # Tuple Pitfalls & Edge Cases:
# 1. Mutability inside a tuple:
# A tuple itself cannot be altered, but mutable objects inside it CAN be modified:
t = (1, [2, 3])
t[1].append(4)
print("Tuple with mutated inner list:", t)  # (1, [2, 3, 4])

# 2. Single-element comma requirement:
x = (5)   # int!
y = (5,)  # tuple!
print("type(5):", type(x), "| type((5,)):", type(y))
