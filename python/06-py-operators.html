  • Operators combine values into expressions. Python’s set is similar to other languages, with important details: / vs //, and/or/not (words, not &&), and is vs ==.

5. Membership (in) and identity (is)

L1 L2

L1 Fundamental

5.1. in / not in

"a" in "cat"        # True
3 in [1, 2, 3]      # True
"x" not in {"a": 1} # True — checks keys

5.2. is / is not

  • is tests object identity (same object in memory), not equality of value.
a = [1, 2]
b = a
c = [1, 2]
a is b          # True — same object
a is c          # False
a == c          # True — same contents

x = None
x is None       # correct None check

L2 Intermediate

  • Small ints / interned strings may share identity for equal values — do not rely on is for ints/strings. Use ==.
a = 256
b = 256
a is b          # often True (implementation detail)

a = 257
b = 257
a is b          # often False — use ==

C. Common questions

L1 L2

L1 Fundamental

C.1. Difference between / and //? ▾ Answer

/ always does true (float) division in Python 3. // does floor division.

C.2. Difference between == and is? ▾ Answer

== compares values. is compares identity. Use is for None.

L2 Intermediate

C.3. What do and/or return? ▾ Answer

The last evaluated operand — not necessarily True/False. Useful for defaults: name or "Guest".

C.4. Why is -5 // 2 equal to -3? ▾ Answer

Floor division rounds toward negative infinity, not toward zero.

P.1. Warm-up

  1. Compute 7 // 2, 7 % 2, 7 ** 2, 7 / 2. ▾ Solution 
    # Arithmetic operators:
print("7 // 2 (integer floor division):", 7 // 2)  # 3
print("7 % 2  (modulo remainder):", 7 % 2)         # 1
print("7 ** 2 (exponentiation):", 7 ** 2)          # 49
print("7 / 2  (float true division):", 7 / 2)      # 3.5
  2. Show short-circuit: False and print("x"). ▾ Solution 
    # Short-circuit evaluation:
# In 'False and ...', the right-hand expression is NEVER evaluated
result = False and print("This will NEVER be printed!")
print("Short-circuit and result:", result)  # False

# In 'True or ...', the right side is also skipped
result2 = True or print("Also never evaluated")
print("Short-circuit or result:", result2)   # True
  3. Membership: "a" in "cat"; 3 in [1,2,3]. ▾ Solution 
    # Membership operators 'in' and 'not in':
print("'a' in 'cat':", 'a' in 'cat')          # True
print("'z' in 'cat':", 'z' in 'cat')          # False
print("3 in [1, 2, 3]:", 3 in [1, 2, 3])      # True
print("10 not in [1, 2, 3]:", 10 not in [1, 2, 3]) # True

P.2. Core tasks

  1. clamp with ops — Without min/max functions, clamp n into [lo, hi] using comparisons. ▾ Solution 
    def clamp(n, lo, hi):
    """Clamp n into range [lo, hi] using only comparison operators."""
    if n < lo:
        return lo
    elif n > hi:
        return hi
    return n

print("clamp(3, 5, 10):", clamp(3, 5, 10))   # 5
print("clamp(7, 5, 10):", clamp(7, 5, 10))   # 7
print("clamp(15, 5, 10):", clamp(15, 5, 10)) # 10
  2. is vs == — Compare two equal lists with == and is; explain. ▾ Solution 
    # '==' checks equality of values; 'is' checks identity (same memory address):
list1 = [1, 2, 3]
list2 = [1, 2, 3]
list3 = list1

print("list1 == list2:", list1 == list2)  # True (same values)
print("list1 is list2:", list1 is list2)  # False (different heap objects)
print("list1 is list3:", list1 is list3)  # True (both reference the exact same object)
  3. bitwise flags — Pack/unpack two flags with | and &. ▾ Solution 
    # Bitwise flags with | (OR) and & (AND):
READ_PERMISSION = 0b001
WRITE_PERMISSION = 0b010
EXECUTE_PERMISSION = 0b100

# Pack permissions:
user_perm = READ_PERMISSION | WRITE_PERMISSION  # 0b011

# Unpack / check permission:
can_read = bool(user_perm & READ_PERMISSION)
can_execute = bool(user_perm & EXECUTE_PERMISSION)

print("User permissions bin:", bin(user_perm))
print("Can read:", can_read)        # True
print("Can execute:", can_execute)  # False
  4. precedence — Predict 2 + 3 * 4 and (2+3)*4. ▾ Solution 
    # Operator Precedence Demonstration:
# Multiplication has higher precedence than addition:
calc1 = 2 + 3 * 4
print("2 + 3 * 4:", calc1)      # 14 (3 * 4 = 12; 2 + 12 = 14)

# Parentheses override default precedence:
calc2 = (2 + 3) * 4
print("(2 + 3) * 4:", calc2)    # 20 (5 * 4 = 20)

    # Traditional XOR swap (low-level, historical):
a = 15
b = 27

  2. Write truth table printer for and/or/not on all bool pairs. ▾ Solution 
    # Truth table printer for boolean operators:
print(f"{'A':<6} {'B':<6} {'A and B':<10} {'A or B':<10} {'not A':<6}")
print("-" * 38)
for a in (True, False):
    for b in (True, False):
        print(f"{str(a):<6} {str(b):<6} {str(a and b):<10} {str(a or b):<10} {str(not a):<6}")
