1. Introduction

L1

L1 Fundamental

1.1. Overview

  • A Module in Python is simply a file containing Python definitions, functions, classes, and executable statements with a .py extension.
  • As programs grow in size, putting all code in a single file becomes unmaintainable. Modules allow dividing large applications into self-contained, logically cohesive units that can be reused across different projects.
  • Modules provide namespace isolation: functions or variables defined in one module do not automatically clash with identical names in other modules.

2. Introduction to modules

L1 L2

L1 Fundamental

2.1. Creating a Module

Any valid Python file is automatically an importable module. Suppose we save a file named calc.py:

# calc.py
"""A simple arithmetic utility module."""

PI = 3.14159

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

In another file located in the same directory, we can import and utilize it immediately:

# main.py
import calc

print(calc.PI)               # 3.14159
print(calc.add(10, 20))      # 30
print(calc.multiply(5, 6))   # 30

L2 Intermediate

2.2. The Module Search Path: sys.path

How Python Finds Modules: When executing an import foo statement, Python searches for foo.py sequentially through the list of directory strings stored in sys.path:
  1. Current Working Directory: The directory containing the input script (or the current directory in interactive sessions).
  2. PYTHONPATH Environment Variable: List of directory paths set by the operating system environment.
  3. Standard Library Directories: Where Python's built-in modules (math, os, sys, json) are installed.
  4. Site-Packages: Third-party libraries installed via pip (in your active virtual environment or global Python install).
If the module is not found in any of these paths, Python raises a ModuleNotFoundError: No module named 'foo'. 
import sys

print("Module search path (first 3 entries):")
for path in sys.path[:3]:
    print(" ", path)

# Dynamically adding a custom directory to search path at runtime:
# sys.path.append("/custom/path/to/modules")

3. import forms, naming conflicts, reloading

L1 L2

L1 Fundamental

3.1. The 5 Forms of Import Statements

Syntax FormExampleAccess PatternPros & Cons
1. Basic import import math math.sqrt(16) Clear namespace origin; no name collisions.
2. Aliased import as import numpy as np np.array([1, 2]) Convenient shorthand for long module names.
3. Specific member import from math import sqrt, pi sqrt(16) Direct member access without prefix.
4. Member import with alias from math import sqrt as sq sq(16) Resolves local naming collisions.
5. Wildcard import (*) from math import * sin(pi / 2) Discouraged: Pollutes local namespace, hides origin, can accidentally overwrite variables.

L2 Intermediate

3.2. Module Caching in sys.modules

  • When a module is imported for the first time, Python executes its top-level code and caches the resulting module object in the sys.modules dictionary.
  • Subsequent import statements referencing that module anywhere in the program simply retrieve the cached instance from sys.modules without re-executing the file.

3.3. Dynamic Reloading with importlib.reload()

If you modify a module file on disk while a long-running process (like an interactive shell or server) is running, executing import calc again will NOT re-read the file. You must explicitly reload it using importlib.reload():

import importlib
import math

# Reload the module fresh from disk:
importlib.reload(math)

4. dir(), help(), __doc__, __file__, __name__

L1 L2

L1 Fundamental

4.1. Introspection Built-ins: dir() and help()

  • dir(module): Returns an alphabetical list of all valid attribute and function names defined inside the module.
  • help(module): Launches the interactive help documentation viewer generated from the module's docstrings.
import math

# Inspect all symbols in math:
symbols = dir(math)
print("Total symbols in math:", len(symbols))
print("First 10 symbols:", symbols[:10])

L2 Intermediate

4.2. Special Module Attributes

AttributeTypePurpose
__doc__ str The module-level docstring defined at the very top of the file.
__file__ str The absolute filesystem path where the module's source code resides.
__name__ str The module name string, or "__main__" if executed directly as the entry point.
__all__ list[str] Defines public export list: restricts which symbols are exported when someone runs from module import *.

4.3. The Execution Guard: if __name__ == "__main__":

How __name__ Works:
  • When you run a file directly from the terminal (python3 app.py), Python sets its __name__ attribute to the string "__main__".
  • When the file is imported by another script (import app), Python sets its __name__ attribute to its actual filename: "app".
  • Wrapping executable demo code inside if __name__ == "__main__": ensures that test code or CLI execution runs only when launched directly, and remains completely silent when imported as a library.
# service.py
def start_server():
    print("Server running on port 8080...")

if __name__ == "__main__":
    # This block ONLY runs when executed via: python3 service.py
    # It does NOT run when another file does: import service
    print("Executing service.py directly in standalone mode.")
    start_server()

L2 Intermediate

5.2. Sequence Operations: choice(), choices(), sample(), shuffle()

  • random.choice(seq): Picks 1 random item from a non-empty sequence.
  • random.choices(seq, k=N): Picks $N$ items with replacement (duplicates possible).
  • random.sample(seq, k=N): Picks $N$ unique items without replacement (lottery/sampling).
  • random.shuffle(list): Shuffles a mutable list in-place. Returns None.
import random

deck = ["A♠", "K♠", "Q♠", "J♠", "10♠", "A♥", "K♥", "Q♥", "J♥", "10♥"]

# Pick one card:
print("Single pick: ", random.choice(deck))

# Lottery draw (3 unique cards without replacement):
print("Sample draw: ", random.sample(deck, k=3))

# Shuffle deck in-place:
cards = list(deck)
random.shuffle(cards)
print("Shuffled:    ", cards[:4])

# OTP / Verification Code Generator:
def generate_otp(length=6) -> str:
    digits = [str(random.randint(0, 9)) for _ in range(length)]
    return "".join(digits)

print("Generated 6-digit OTP:", generate_otp())
Security Note: The random module uses the Mersenne Twister algorithm, which is completely deterministic and unsuitable for cryptographic purposes (passwords, auth tokens, crypto keys). For secure generation, use the standard library secrets module: secrets.token_hex(16).

6.2. Number Theory, Powers & Logarithms

import math

# Number theory:
print("GCD(48, 18):       ", math.gcd(48, 18))       # 6
print("LCM(48, 18):       ", math.lcm(48, 18))       # 144 (Python 3.9+)
print("Combinations (5C2):", math.comb(5, 2))        # 10 (Python 3.8+)
print("Permutations (5P2):", math.perm(5, 2))        # 20 (Python 3.8+)

# Powers and square roots:
print("Square root:       ", math.sqrt(25))          # 5.0
print("Cube root:         ", math.cbrt(27))          # 3.0 (Python 3.11+)

# Logarithms:
print("Natural log ln(e): ", math.log(math.e))       # 1.0
print("Log base 10 (1000):", math.log10(1000))       # 3.0
print("Log base 2 (64):   ", math.log2(64))          # 6.0

# Trigonometry (Expects radians; use math.radians()):
angle_rad = math.radians(90)
print("sin(90 deg):       ", math.sin(angle_rad))    # 1.0

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the purpose of if __name__ == "__main__":? ▾ Answer

Every Python module has a built-in __name__ attribute:

  • If the file is run directly as the entry point program (python3 file.py), Python sets __name__ = "__main__".
  • If the file is imported by another module (import file), Python sets __name__ = "file".

The guard if __name__ == "__main__": ensures that unit tests, CLI parsers, or demo scripts execute only when the file is run as a script, preventing unwanted side effects when the file is imported elsewhere.

C.2. Why is from module import * considered bad practice? ▾ Answer

Wildcard imports are strongly discouraged for three reasons:

  1. Namespace Pollution & Shadowing: It dumps hundreds of symbols into the local namespace, potentially overwriting existing variables or built-in functions silently.
  2. Readability: Code reviewers cannot determine where a function originated (e.g. is dump() from os, sys, or json?).
  3. Static Analysis: Linters (Flake8, Pylance, Ruff) cannot detect undefined variables or unused imports effectively.
C.3. How does sys.modules optimize repeated imports? ▾ Answer

sys.modules is an internal dictionary that maps module names to already loaded module objects. When an import statement is encountered:

  1. Python checks if the module name is in sys.modules.
  2. If present, it returns the cached module object immediately ($O(1)$ dictionary lookup), skipping disk I/O and code execution.
  3. If absent, it locates the file via sys.path, compiles it to bytecode, executes its top-level statements, stores it in sys.modules, and returns it.
C.4. What is the difference between random.randint() and random.randrange()? ▾ Answer
  • random.randint(a, b): Returns an integer in range $[a, b]$ where both $a$ and $b$ are inclusive. randint(1, 6) can return 1, 2, 3, 4, 5, or 6.
  • random.randrange(start, stop[, step]): Follows standard Python slicing/range semantics where stop is exclusive ($[start, stop)$). randrange(1, 6) can return 1, 2, 3, 4, or 5 (never 6). Also accepts an optional step argument.

L2 Intermediate

C.5. Why shouldn't the random module be used for generating passwords or tokens? ▾ Answer

The random module uses the Mersenne Twister algorithm. It is a pseudo-random number generator (PRNG) designed for statistical simulations, not cryptography.

After observing 624 consecutive generated outputs, an attacker can completely reconstruct the internal 2,496-byte state and accurately predict all future and past numbers. For cryptographic tokens, passwords, and security nonces, always use the secrets module, which interfaces with OS-level entropy sources (/dev/urandom).

C.6. What is the difference between random.choices() and random.sample()? ▾ Answer
  • random.choices(population, k=N): Sampling with replacement. An item can be chosen multiple times. Can accept item weights.
  • random.sample(population, k=N): Sampling without replacement. Every selected element is guaranteed to be unique. Raises ValueError if $k > \text{len}(population)$.
C.7. What does the __all__ variable inside a module do? ▾ Answer

__all__ is a list of strings defined at the module level that specifies the exact public API exported when a consumer executes from module import *.

Any symbol not listed in __all__ is treated as private and will not be imported during a wildcard import.

C.8. How does Python prevent circular import deadlocks? ▾ Answer

A circular import occurs when Module A imports Module B, which in turn imports Module A.

Because Module A is already registered in sys.modules when it begins executing, Module B receives an uninitialized / partially executed Module A object. If Module B attempts to access a function from A that has not yet been defined in the file, Python raises an AttributeError or ImportError.

Remedies: Move imports inside functions (deferred imports), merge the modules, or refactor shared dependencies into a separate third module.

  1. Task 1: Secure Password Generator — Generate a randomized password with mixed character sets. ▾ Solution 
    import random
import string

def generate_password(length=12) -> str:
    pool = string.ascii_letters + string.digits + "!@#$%^&*"
    # Ensure at least 1 lower, 1 upper, 1 digit, 1 special
    pwd = [
        random.choice(string.ascii_lowercase),
        random.choice(string.ascii_uppercase),
        random.choice(string.digits),
        random.choice("!@#$%^&*")
    ]
    pwd += random.choices(pool, k=length - 4)
    random.shuffle(pwd)
    return "".join(pwd)

print("Generated password:", generate_password(16))

  4. Task 4: Dynamic Module Inspector — Print all public functions and their docstrings from a given module. ▾ Solution 
    import math

def inspect_public_functions(mod):
    funcs = {}
    for name in dir(mod):
        if not name.startswith("_"):
            obj = getattr(mod, name)
            if callable(obj):
                funcs[name] = (obj.__doc__ or "").strip().split("\n")[0]
    return funcs

math_docs = inspect_public_functions(math)
for fn_name in sorted(list(math_docs.keys()))[:5]:
    print(f"{fn_name:<10}: {math_docs[fn_name]}")

P.3. Challenge

  1. Challenge 1: Monte Carlo Pi Estimation — Estimate the value of pi using random coordinates inside a unit circle. ▾ Solution 
    import random
import math

def estimate_pi(num_samples=100_000) -> float:
    inside_circle = 0
    for _ in range(num_samples):
        x = random.random()
        y = random.random()
        if x**2 + y**2 <= 1.0:
            inside_circle += 1
    return (inside_circle / num_samples) * 4

est = estimate_pi(100_000)
print(f"Estimated Pi: {est:.5f} | Actual math.pi: {math.pi:.5f} | Error: {abs(est - math.pi):.5f}")
  2. Challenge 2: Plugin Loader System via sys.modules — Dynamically import and register handlers at runtime. ▾ Solution 
    import importlib
import importlib.util

plugin_registry = {}

def load_plugin(module_name: str):
    # Verify module existence via find_spec (Exceptions covered in Module 24)
    spec = importlib.util.find_spec(module_name)
    if spec is not None:
        mod = importlib.import_module(module_name)
        plugin_registry[module_name] = mod
        print(f"Successfully loaded plugin: {module_name}")
        return mod
    else:
        print(f"Plugin load failed: module {module_name!r} not found")
        return None

load_plugin("json")
load_plugin("math")
load_plugin("non_existent_plugin")
print("Registry contains:", list(plugin_registry.keys()))
