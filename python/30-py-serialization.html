30. Serialization (pickle, JSON, YAML)

Object persistence, cross-language JSON data exchange, YAML configuration management, and critical security considerations.

pickle JSON & Custom Encoders jsonpickle PyYAML & safe_load Security & Insecure Deserialization

1. Introduction

L1

L1 Fundamental

1.1. What is Serialization & Deserialization?

  • Serialization (Marshalling / Pickling / Encoding): The process of converting an in-memory Python object (e.g., a dictionary, custom class instance, or nested list) into a persistent stream of bytes or a text format (JSON, YAML). This allows the object to be saved to disk, stored in a database/cache, or transmitted over a network.
  • Deserialization (Unmarshalling / Unpickling / Decoding): The reverse process: reading a byte stream or text document and reconstructing the original in-memory Python object with its state and types intact.

1.2. Format Comparison Matrix

Format Type Human Readable? Language Portability Security Risks Ideal Use Cases
pickle Binary No Python-only CRITICAL (Arbitrary Code Execution) Short-term caching of complex Python objects, multiprocessing queues.
JSON Text Yes Universal (All languages) Safe (Standard JSON parser cannot execute code) REST APIs, web services, database documents (MongoDB, Postgres JSONB).
YAML Text Highly readable Universal Medium (Safe if using safe_load) Application configurations (Docker Compose, Kubernetes, CI/CD pipelines).

1.3. Serialization Typing & Signatures

In modern typed Python, serialization functions accept generic objects and return encoded strings or bytes. Deserialized outputs start as dynamically-typed payloads (Any) requiring explicit casting or type narrowing:

import json
import pickle
from typing import Any

# Serializer signatures:
# json.dumps(obj: Any, ...) -> str
# json.loads(s: str, ...) -> Any
# pickle.dumps(obj: Any, ...) -> bytes
# pickle.loads(data: bytes, ...) -> Any

raw_data: dict[str, Any] = {"service": "auth", "port": 8080, "active": True}

# Typed JSON round-trip:
encoded_json: str = json.dumps(raw_data)
decoded_dict: dict[str, Any] = json.loads(encoded_json)

# Typed pickle round-trip:
encoded_pickle: bytes = pickle.dumps(raw_data)
decoded_pickle: dict[str, Any] = pickle.loads(encoded_pickle)

2. Object serialization with pickle

L1 L2

L1 Fundamental

2.1. The pickle Module API

Python's built-in pickle module serializes arbitrary Python objects into a binary byte format. The API provides four primary functions:

  • pickle.dump(obj, file): Serializes obj and writes it directly to an open binary file stream ("wb" mode).
  • pickle.dumps(obj): Serializes obj and returns the serialized representation as a bytes object in memory.
  • pickle.load(file): Reads from an open binary file stream ("rb" mode) and reconstructs the Python object.
  • pickle.loads(bytes_obj): Deserializes an in-memory bytes object back into a Python object.
import pickle

class Employee:
    def __init__(self, emp_id: int, name: str, skills: list[str]) -> None:
        self.emp_id: int = emp_id
        self.name: str = name
        self.skills: list[str] = skills

    def __repr__(self) -> str:
        return f"Employee({self.emp_id}, '{self.name}', {self.skills})"

original_emp: Employee = Employee(101, "Alice", ["Python", "Docker", "PostgreSQL"])

# 1. In-memory pickling:
serialized_bytes: bytes = pickle.dumps(original_emp)
print(f"Pickled byte size: {len(serialized_bytes)} bytes")
print("Raw bytes preview:", serialized_bytes[:30])

# 2. In-memory unpickling:
reconstructed_emp: Employee = pickle.loads(serialized_bytes)
print("Reconstructed:", reconstructed_emp)
print("Type preserved:", type(reconstructed_emp))  # <class '__main__.Employee'>
print("Skills preserved:", reconstructed_emp.skills)

L2 Intermediate

2.2. Custom Pickling via __getstate__ and __setstate__

Certain resources cannot be pickled (e.g., open file descriptors, active database connections, thread locks, network sockets). By implementing __getstate__ and __setstate__, a class can filter out non-serializable fields before pickling and re-initialize them upon unpickling.

import pickle
from typing import Any

class SessionManager:
    def __init__(self, user: str, token: str) -> None:
        self.user: str = user
        self.token: str = token
        self.transient_lock: str = "Non-serializable system handle"

    def __getstate__(self) -> dict[str, Any]:
        """Called by pickle.dump/dumps to get state dictionary for serialization."""
        state: dict[str, Any] = self.__dict__.copy()
        # Omit transient resources:
        state.pop("transient_lock", None)
        return state

    def __setstate__(self, state: dict[str, Any]) -> None:
        """Called by pickle.load/loads to restore object state."""
        self.__dict__.update(state)
        # Re-initialize transient resource:
        self.transient_lock = "Freshly initialized lock"

sess: SessionManager = SessionManager("admin", "tok_xyz987")
raw: bytes = pickle.dumps(sess)
restored: SessionManager = pickle.loads(raw)
print("Restored user:", restored.user)
print("Restored lock:", restored.transient_lock)
CRITICAL SECURITY WARNING: NEVER UNPICKLE UNTRUSTED DATA!

The pickle module is NOT secure against erroneous or maliciously constructed data. An attacker can craft a malicious pickle byte stream using the __reduce__ protocol that instructs Python to execute arbitrary system commands (e.g. os.system('rm -rf /') or reverse shells) during pickle.loads() before returning! Only unpickle data that originated from trusted, authenticated sources (like your own internal cluster with cryptographic HMAC signatures).

3. JSON serialization / deserialization

L1 L2

L1 Fundamental

3.1. Standard json Module API

JavaScript Object Notation (JSON) is the global standard for cross-language data exchange. Python includes the json module:

  • json.dump(obj, file, indent=2): Serializes to a text file stream.
  • json.dumps(obj, indent=2, sort_keys=True): Serializes to a JSON-formatted string.
  • json.load(file): Parses a JSON file stream into Python data structures.
  • json.loads(json_str): Parses a JSON string into Python data structures.
import json
from typing import Any

payload: dict[str, Any] = {
    "status": "success",
    "code": 200,
    "authenticated": True,
    "user": {
        "id": 42,
        "name": "Bharat",
        "roles": ["admin", "developer"]
    },
    "metadata": None
}

# Serialize with formatting:
json_string: str = json.dumps(payload, indent=2, sort_keys=True)
print("Serialized JSON:\n", json_string)

# Deserialize:
parsed: dict[str, Any] = json.loads(json_string)
print("\nParsed username:", parsed["user"]["name"])
print("Parsed roles:", parsed["user"]["roles"])

L2 Intermediate

3.2. Custom JSON Encoders (Handling datetime, Decimal, and Custom Classes)

Standard JSON only supports numbers, strings, booleans, null, lists, and string-keyed dictionaries. If you attempt to serialize a datetime, Decimal, UUID, or custom class, Python raises a TypeError: Object of type X is not JSON serializable.

You can handle these types cleanly using the default parameter or by subclassing json.JSONEncoder.

import json
from datetime import datetime, date
from decimal import Decimal
from typing import Any
import uuid

def custom_json_serializer(obj: Any) -> Any:
    """Custom serializer function passed to json.dumps(default=...)."""
    if isinstance(obj, (datetime, date)):
        return obj.isoformat()
    if isinstance(obj, Decimal):
        return float(obj)
    if isinstance(obj, uuid.UUID):
        return str(obj)
    if hasattr(obj, "__dict__"):
        return obj.__dict__
    raise TypeError(f"Object of type {type(obj).__name__} is not JSON serializable")

transaction: dict[str, Any] = {
    "tx_id": uuid.uuid4(),
    "timestamp": datetime.now(),
    "amount": Decimal("1499.50"),
    "tags": {"finance", "cleared"}  # sets can also be handled: list(obj)
}

# Serializing with custom serializer:
json_output: str = json.dumps(transaction, default=custom_json_serializer, indent=2)
print("Serialized Custom Data:\n", json_output)

4. jsonpickle and API JSON examples

L1 L2

L1 Fundamental

4.1. What is jsonpickle?

While standard json only handles basic data structures and loses custom class identities, jsonpickle is a library that serializes arbitrary, complex Python object graphs (including circular references and custom class instances) directly into human-readable JSON. It preserves the exact Python module and class path via metadata keys (like "py/object").

# Install via: pip install jsonpickle
import jsonpickle

class Order:
    def __init__(self, order_id: str, customer: str, total: float) -> None:
        self.order_id: str = order_id
        self.customer: str = customer
        self.total: float = total

order: Order = Order("ORD-99", "Bharat", 299.95)

# 1. Encode into JSON with Python class metadata:
frozen_json: str = jsonpickle.encode(order, indent=2)
print("jsonpickle output:\n", frozen_json)
# {
#   "py/object": "__main__.Order",
#   "customer": "Bharat",
#   "order_id": "ORD-99",
#   "total": 299.95
# }

# 2. Reconstruct original class instance:
restored_order: Order = jsonpickle.decode(frozen_json)
print("Restored class instance:", type(restored_order))  # <class '__main__.Order'>
print("Order Total:", restored_order.total)

L2 Intermediate

4.2. Consuming REST API JSON Responses

In real-world web applications (using requests or urllib.request), API communication is conducted over JSON payloads.

import json
from typing import Any

# Simulating an HTTP API response string:
api_response_body: str = '{"data": [{"id": 1, "title": "Buy groceries"}, {"id": 2, "title": "Deploy API"}]}'

def parse_api_todos(response_text: str) -> list[str]:
    try:
        payload: dict[str, Any] = json.loads(response_text)
        todos: list[dict[str, Any]] = payload.get("data", [])
        return [str(item["title"]) for item in todos]
    except json.JSONDecodeError as err:
        print(f"Failed to decode API JSON response: {err}")
        return []

todo_titles: list[str] = parse_api_todos(api_response_body)
print("Parsed Todo Titles:", todo_titles)

5. YAML serialization

L1 L2

L1 Fundamental

5.1. Why YAML?

YAML (YAML Ain't Markup Language) is a human-readable data serialization format designed specifically for configuration files. It uses Python-style whitespace indentation instead of braces and brackets, supports inline comments (#), and avoids noisy quotes.

The standard Python library for YAML is PyYAML (installed via pip install pyyaml, imported as yaml).

import yaml
from typing import Any

server_config: dict[str, Any] = {
    "server": {
        "host": "0.0.0.0",
        "port": 8080,
        "workers": 4
    },
    "database": {
        "engine": "postgresql",
        "dbname": "app_db",
        "pool_size": 20
    },
    "features": ["caching", "rate_limiting", "audit_logging"]
}

# 1. Dumping to YAML text:
yaml_text: str = yaml.dump(server_config, sort_keys=False)
print("Generated YAML Config:\n", yaml_text)

# 2. Parsing YAML text:
parsed_config: dict[str, Any] = yaml.safe_load(yaml_text)
print("Parsed port:", parsed_config["server"]["port"])
print("Enabled features:", parsed_config["features"])

L2 Intermediate

5.2. Security: Always Use yaml.safe_load()

The traditional yaml.load() function has the power to instantiate arbitrary Python objects. If an attacker passes a YAML document containing Python constructor tags (e.g., !!python/object/apply:os.system ['rm -rf /']), yaml.load() will execute it!

The YAML Golden Rule: Always use yaml.safe_load() (or yaml.safe_load_all() for multi-document streams). safe_load restricts parsing strictly to standard simple data structures (dictionaries, lists, strings, numbers, booleans) and completely disables Python class instantiation tags.

5.3. Multi-Document YAML Streams

YAML supports storing multiple documents in a single file separated by three hyphens (---), widely used in Kubernetes manifests.

import yaml
from typing import Any

multi_doc: str = """
---
name: Service-A
version: 1.0.0
---
name: Service-B
version: 2.1.0
"""

# safe_load_all returns an iterator over all documents in the stream:
documents: list[dict[str, Any]] = list(yaml.safe_load_all(multi_doc))
for doc in documents:
    print(f"Service: {doc['name']}, Version: {doc['version']}")

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the difference between serialization and deserialization? ▾ Answer

Serialization is the conversion of an active in-memory object (such as a dictionary, list, or custom class) into a persistent or transmittable format (such as a stream of bytes, JSON string, or YAML document).

Deserialization is the inverse process: parsing that stream of bytes or formatted text back into a reconstructed, live in-memory Python object.

C.2. What is the difference between dump()/load() and dumps()/loads()? ▾ Answer

Across both the json and pickle modules:

  • Without "s" (dump, load): Operate on file streams. dump(obj, file) writes directly to a file handle; load(file) reads directly from a file handle.
  • With "s" (dumps, loads — "dump string"): Operate on strings or bytes in memory. dumps(obj) returns a string (JSON) or bytes (pickle); loads(data) parses an in-memory string or bytes object.
C.3. Why is unpickling untrusted data a major security vulnerability? ▾ Answer

The pickle protocol allows serialized objects to define a __reduce__ method that specifies a callable and arguments to execute upon unpickling. An attacker can construct a serialized payload specifying os.system or subprocess.Popen with arbitrary shell commands.

When pickle.loads() is invoked on that payload, Python automatically executes the shell command with the privileges of the running application, resulting in complete Remote Code Execution (RCE). Never use pickle for network APIs or untrusted user input.

C.4. What are the key trade-offs between pickle, JSON, and YAML? ▾ Answer
  • pickle: Fast binary format, natively serializes almost any Python object and preserves exact class types. However, it is Python-only and unsafe for untrusted input.
  • JSON: Ubiquitous, cross-platform standard supported by all languages. Safe and human-readable, but supports only basic data types (strings, numbers, booleans, lists, dicts).
  • YAML: Superb human readability, supports comments and clean whitespace hierarchy, making it the premier choice for complex configurations. Parsing is slightly slower than JSON.

L2 Intermediate

C.5. How do you serialize non-serializable objects (like datetime or Decimal) to JSON? ▾ Answer

You can pass a fallback function to the default parameter of json.dumps(), or subclass json.JSONEncoder:

from datetime import datetime
from decimal import Decimal
import json
from typing import Any

def serialize_custom(obj: Any) -> Any:
    if isinstance(obj, datetime):
        return obj.isoformat()
    if isinstance(obj, Decimal):
        return float(obj)
    raise TypeError

data: dict[str, Any] = {"created": datetime.now(), "price": Decimal("19.99")}
json.dumps(data, default=serialize_custom)
C.6. What is the difference between yaml.load() and yaml.safe_load()? ▾ Answer

yaml.load() allows tags that can instantiate arbitrary Python classes and invoke functions, which introduces arbitrary code execution vulnerabilities if parsing untrusted YAML.

yaml.safe_load() restricts the parser to a safe subset of standard YAML data types (strings, lists, dicts, integers, floats), preventing code execution and making it completely safe for parsing untrusted user inputs and configuration files.

C.7. How do __getstate__ and __setstate__ customize pickling behavior? ▾ Answer
  • __getstate__(self): Intercepts pickling and returns a dictionary of attributes to be serialized, allowing you to remove non-pickleable attributes (like database handles or file descriptors).
  • __setstate__(self, state): Intercepts unpickling, receiving the restored state dictionary, updating self.__dict__, and re-establishing or recreating transient resources.
C.8. Why can't lambda functions or generators be pickled by default? ▾ Answer

The pickle module serializes functions by saving their qualified module and name reference (e.g. math.sin), expecting to import that name upon unpickling. Because lambda functions are anonymous (all having the name <lambda>) and lack top-level global module bindings, pickle cannot serialize them. Generators hold active C-level stack execution state and instruction pointers that cannot be cleanly serialized across process boundaries.

P.3. Challenge

  1. Mini project — Build a Unified Serializer supporting JSON, YAML, and Pickle with automated format detection and secure safe loading. ▾ Solution 
    # Mini Project: Multi-Format Data Serializer
import json
import yaml
import pickle
from typing import Any

class DataSerializer:
    @staticmethod
    def serialize(data: Any, fmt: str = "json") -> str | bytes:
        fmt = fmt.lower()
        if fmt == "json":
            return json.dumps(data, indent=2)
        elif fmt in ("yaml", "yml"):
            return yaml.dump(data, sort_keys=False)
        elif fmt == "pickle":
            return pickle.dumps(data)
        else:
            raise ValueError(f"Unsupported format: {fmt}")

    @staticmethod
    def deserialize(raw_data: str | bytes, fmt: str = "json") -> Any:
        fmt = fmt.lower()
        if fmt == "json":
            return json.loads(raw_data if isinstance(raw_data, str) else raw_data.decode("utf-8"))
        elif fmt in ("yaml", "yml"):
            return yaml.safe_load(raw_data)
        elif fmt == "pickle":
            return pickle.loads(raw_data if isinstance(raw_data, bytes) else raw_data.encode("latin1"))
        else:
            raise ValueError(f"Unsupported format: {fmt}")

sample: dict[str, Any] = {"app": "Microservice", "replicas": 3, "active": True}
json_res: str | bytes = DataSerializer.serialize(sample, "json")
yaml_res: str | bytes = DataSerializer.serialize(sample, "yaml")

print("JSON parsed:", DataSerializer.deserialize(json_res, "json")["app"])
print("YAML parsed:", DataSerializer.deserialize(yaml_res, "yaml")["replicas"])
  2. Edge cases — Demonstrate handling circular references in JSON serialization vs pickle. ▾ Solution 
    # Edge Case: Circular references
import pickle
import json
from typing import Any

cyclic: list[Any] = [1, 2]
cyclic.append(cyclic)

# Pickle handles cycles naturally:
pickled_cycle: bytes = pickle.dumps(cyclic)
restored_cycle: list[Any] = pickle.loads(pickled_cycle)
print("Pickle cycle verified:", restored_cycle[2] is restored_cycle)  # True

# Standard json.dumps crashes on cyclic references:
try:
    json.dumps(cyclic)
except ValueError as err:
    print("JSON correctly rejected cycle:", err)  # Circular reference detected
