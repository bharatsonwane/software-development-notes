P.2. Core tasks

  1. Task 1: Debugging with assertions — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 1: Debugging with assertions
def parse_positive_int(s):
    val = int(s)
    # Assertion acts as an internal sanity check for developer logic
    assert val > 0, f"Expected positive integer, received: {val}"
    return val

print("Parsed:", parse_positive_int("42"))
try:
    parse_positive_int("-5")
except AssertionError as err:
    print(f"Caught assertion failure: {err}")
  2. Task 2: assert forms and when to use — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 2: Assert forms and when to use
class Account:
    def __init__(self, balance):
        # Assert invariant: balance cannot be negative on initialization
        assert balance >= 0, "Account cannot start with negative balance"
        self.balance = balance
    
    def deposit(self, amount):
        assert amount > 0, "Deposit amount must be positive"
        self.balance += amount

acc = Account(100)
acc.deposit(50)
print(f"Account balance verified: ${acc.balance}")
  3. Cheat sheet — Comment 5 key facts about Assertions. ▾ Solution 
    # Cheat sheet — 5 Key Facts about Assertions:
# 1. Assertions are strictly for debugging and checking internal invariants; NEVER for user input validation.
# 2. In production, running 'python -O main.py' disables ALL assert statements completely (__debug__ is False).
# 3. If you use assertions for security or permissions, running -O bypasses all checks!
# 4. Never put parentheses around assert condition and message: 'assert(cond, msg)' tests a truthy tuple!
# 5. An assertion should never perform mutations with side effects (e.g., assert pop() == 1).

    # Mini Project: Data Pipeline Pre-condition and Post-condition Auditor
def process_batch(items):
    # Pre-condition check:
    assert isinstance(items, list), "Batch input must be a list"
    assert len(items) > 0, "Batch cannot be empty"
    
    processed = [x * 2 for x in items if x is not None]
    
    # Post-condition check:
    assert len(processed) <= len(items), "Processed count cannot exceed input count"
    assert all(x >= 0 for x in processed), "All processed results must be non-negative"
    return processed

result = process_batch([1, 2, 3, 4])
print("Batch processed and verified:", result)
