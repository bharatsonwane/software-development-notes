4. Limitations of Python

L1

L1 Fundamental

  • Slower than C/C++/Rust for CPU-heavy loops (often mitigated with NumPy / C extensions).
  • GIL (CPython) limits true parallel CPU threads in one process — File 24.
  • Mobile / browser not primary targets (unlike JS on the web).
  • Runtime errors for type mistakes unless you add type checkers (mypy) — File 31.
  • Design choices (indentation, dynamic typing) can frustrate some teams — not “bugs,” but trade-offs.

5. Python release journey (2.x → 3.x)

L1 L2

L1 Fundamental

  • Python 2 reached end-of-life 1 Jan 2020. Do not start new projects on 2.x.
  • Python 3 cleaned up design: print is a function, text is Unicode str, integer division with / returns float, etc.
# Python 3
print("Hello")
print(5 / 2)   # 2.5
print(5 // 2)  # 2

L2 Intermediate

5.1. Notable 3.x milestones (high level)

  • 3.5+ — async/await
  • 3.6+ — f-strings
  • 3.7+ — dataclasses (stdlib)
  • 3.8+ — walrus operator :=
  • 3.10+ — match / case
  • 3.11+ — faster CPython, better errors
  • Check your version:
python3 --version
# or
import sys
print(sys.version)

6. Install, REPL, and first program

L1 L2

L1 Fundamental

6.1. Install

  • Download from python.org, or use OS package managers / pyenv. On macOS/Linux use python3; Windows often installs py launcher.

6.2. REPL (interactive shell)

$ python3
>>> 2 + 3
5
>>> print("hi")
hi
>>> exit()
  • REPL is great for experiments. Exit with exit() or Ctrl-D (Unix) / Ctrl-Z Enter (Windows).

6.3. First script

# hello.py
print("Hello, Python")
$ python3 hello.py
Hello, Python

L2 Intermediate

6.4. Virtual environments (preview)

  • Isolate project dependencies (full pip/packages story: Files 15–16):
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install requests

C. Common questions

L1 L2

L1 Fundamental

C.1. Is Python compiled or interpreted?

  • A: Source is compiled to bytecode, then executed by the Python VM (CPython). You usually do not compile to a native binary yourself.

C.2. Why prefer Python 3?

  • A: Python 2 is EOL. 3.x has better Unicode, cleaner syntax, and all modern libraries target 3.

L2 Intermediate

C.3. What is CPython?

  • A: The default reference implementation (written in C). Alternatives exist (PyPy, Jython, IronPython) but CPython is what most people mean by “Python.”
