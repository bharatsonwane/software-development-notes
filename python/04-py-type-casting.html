04. Type Casting

File 04 — converting between fundamental types with constructors.

int() float() str() bool()

L1 Fundamental

  • Type casting (type conversion) creates a value of another type using constructors like int(), float(), str(), bool(), complex().

L1 Fundamental

Default rule today: cast explicitly when reading input (int(input(...))). Watch for ValueError on bad strings and float→int truncation.

1. Casting between fundamental types

L1

L1 Fundamental

  • Python does not auto-convert incompatible types in all cases (e.g. "5" + 1 raises TypeError). Convert first.
"5" + "1"       # "51" — string concat
# "5" + 1       # TypeError
int("5") + 1    # 6

2. int / float / complex / bool / str

L1

L1 Fundamental

2.1. int()

int(3.9)        # 3 — truncates toward zero
int("42")       # 42
int(True)       # 1
# int("3.14")   # ValueError — use float first
int(float("3.14"))  # 3

2.2. float()

float(10)       # 10.0
float("3.14")   # 3.14
float("1e2")    # 100.0

2.3. complex()

complex(2, 3)   # (2+3j)
complex("1+2j") # (1+2j)

2.4. bool()

  • Falsy: False, 0, 0.0, 0j, None, "", [], {}, set(), empty ranges, etc. Everything else is truthy.
bool(0)         # False
bool(1)         # True
bool([])        # False
bool([0])       # True — non-empty list

2.5. str()

str(42)         # "42"
str(3.14)       # "3.14"
str(True)       # "True"
str(None)       # "None"

2.6. Collection constructors (preview)

list("abc")     # ["a", "b", "c"]
tuple([1, 2])   # (1, 2)
set([1, 1, 2])  # {1, 2}
dict([("a", 1)])  # {"a": 1}

3. Base conversions and pitfalls

L1 L2

L1 Fundamental

  • int(string, base) parses digits in a given base (2–36):
int("1010", 2)   # 10
int("FF", 16)    # 255
int("17", 8)     # 15
  • Format ints as other bases:
bin(10)   # '0b1010'
oct(10)   # '0o12'
hex(10)   # '0xa'
format(10, "b")  # '1010' without prefix

L2 Intermediate

3.1. Pitfalls

  • int(" 42 ") works (whitespace stripped); int("42abc") raises ValueError.
  • Float→int truncates; use round() if you need rounding.
  • bool("False") is True — non-empty string. Parse carefully for user input.
  • Implicit numeric conversion in mixed arithmetic: 1 + 2.5 → float. True + 1 → 2.

4. Common questions

L1 L2

L1 Fundamental

4.1. What does int(3.9) return?

  • A: 3 — truncates toward zero, does not round.

4.2. How do I convert user input to a number?

  • A: n = int(input("n: ")) or wrap in try/except ValueError (File 23).

L2 Intermediate

4.3. Why is bool("0") True?

  • A: Only empty string is falsy among strings. "0" is non-empty. Use int("0") then compare, or compare the string explicitly.
