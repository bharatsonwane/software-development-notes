1. Introduction

L1

L1 Fundamental

1.1. Overview

  • By default, a Python interpreter executes statements sequentially from top to bottom. Control Flow statements break this linear progression by branching decisions, repeating code blocks, or jumping to alternative locations.
  • Python categorizes flow control statements into three primary families:
    1. Conditional / Selection Statements: if, if-else, if-elif-else, and structural pattern matching (match-case in Python 3.10+).
    2. Iterative / Looping Statements: for (definite iteration over collections) and while (indefinite iteration controlled by a condition).
    3. Transfer / Jump Statements: break, continue, and pass.

1.2. The Indentation Philosophy in Python

Syntactic & Typing Rules: Unlike languages that use curly braces ({ }), Python defines code blocks strictly using whitespace indentation (4 spaces per PEP 8). Always type-annotate accumulator variables, status flags, and state trackers (total: int = 0, is_prime: bool = True, grade: str = "A") so branching logic and iterative counters maintain explicit types throughout execution.

2. Conditional statements (if / elif / else)

L1 L2

L1 Fundamental

2.1. Simple if Statement

Executes a block of code only when the specified condition evaluates to truthy.

age: int = 19
if age >= 18:
    print("Eligible to vote")

2.2. if-else Statement

Provides two mutually exclusive execution paths: one when the condition is truthy, and one when it is falsy.

n: int = 15
if n % 2 == 0:
    print(f"{n} is Even")
else:
    print(f"{n} is Odd")

2.3. if-elif-else Ladder

Handles multiple mutually exclusive conditions. Python tests conditions sequentially from top to bottom and executes only the first branch whose condition is truthy.

score: int = 82
grade: str

if score >= 90:
    grade = "A+"
elif score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 50:
    grade = "C"
else:
    grade = "F (Fail)"

print(f"Score: {score} -> Grade: {grade}")  # Grade: A

L2 Intermediate

2.4. Nested Conditional Statements

An if statement placed inside another if statement allows hierarchical decision making.

num: int = 12
if num > 0:
    if num % 2 == 0:
        print("Positive Even number")
    else:
        print("Positive Odd number")
elif num == 0:
    print("Zero")
else:
    print("Negative number")

2.5. Structural Pattern Matching: match-case (Python 3.10+)

  • Python historically lacked a switch-case statement, relying instead on if-elif-else or dictionary lookups.
  • Python 3.10 introduced Structural Pattern Matching via match and case, supporting value matching, wildcard defaults (case _), and sequence destructuring.
# Demonstrating Structural Pattern Matching on a command variable:
cmd: str = "load data.csv"

match cmd.split():
    case ["quit"]:
        print("Exiting system")
    case ["load", filename]:
        print(f"Loading file: {filename}")
    case ["save", filename, "force"]:
        print(f"Force saving to {filename}")
    case _:
        print("Unknown command")

2.6. Common Conditional Pitfalls

  • Assignment vs. Comparison: Using = instead of == inside if raises a SyntaxError (unlike C/C++ which permits accidental assignment).
  • Truthiness Over-Reliance: if x: behaves differently for 0, "", and None. Check if x is not None: when zero is a legitimate value.

3. Iterative statements (for, while, range)

L1 L2

L1 Fundamental

3.1. The for Loop

In Python, the for loop is fundamentally a collection iterator. It iterates across elements of an iterable sequence (string, list, tuple, set, dict, or generator) directly, without requiring manual index counters.

# 1. Iterating over a string:
for char in "PYTHON":
    print(char, end="-")  # P-Y-T-H-O-N-
print()

# 2. Iterating over a list:
names: list[str] = ["Alice", "Bob", "Charlie"]
for name in names:
    print(f"Hello, {name}")

# 3. Iterating over a dictionary (keys, values, items):
person: dict[str, str] = {"name": "Bharat", "role": "Engineer"}
for key, val in person.items():
    print(f"{key} -> {val}")

3.2. Deep Dive into range()

range generates an immutable sequence of numbers on-demand (lazy evaluation, requiring $O(1)$ memory regardless of size).

Syntax Form Arguments Generated Sequence Example Code
range(stop) Starts at 0, steps by 1, up to stop - 1 0, 1, 2, ..., stop - 1 range(5) → 0, 1, 2, 3, 4
range(start, stop) Starts at start, steps by 1, up to stop - 1 start, start+1, ..., stop - 1 range(2, 6) → 2, 3, 4, 5
range(start, stop, step) Increments by step (can be negative for countdown) start, start+step, ... range(10, 0, -2) → 10, 8, 6, 4, 2 
# Sum of first 100 positive integers:
total: int = sum(range(1, 101))
print("Sum 1..100:", total)  # 5050

# Countdown loop:
for t in range(5, 0, -1):
    print(t, end=" ")  # 5 4 3 2 1
print("Blastoff!")

3.3. The while Loop

A while loop executes its body repeatedly as long as its condition evaluates to truthy. It is primarily used when the total number of iterations is not known in advance (indefinite iteration).

# Sum digits of a number:
num: int = 12345
digit_sum: int = 0
while num > 0:
    digit_sum += num % 10
    num //= 10
print("Sum of digits:", digit_sum)  # 15

L2 Intermediate

3.4. Infinite Loops and Safe Exit Patterns

Creating an intentional infinite loop using while True: is standard practice for CLI menus, listener sockets, or polling jobs. The loop terminates when an internal break condition is satisfied.

# Sentinel loop pattern:
while True:
    entry = input("Enter number (or 'done' to finish): ").strip()
    if entry.lower() == "done":
        print("Finished processing.")
        break
    if not entry.isdigit():
        print("Invalid input, please enter digits.")
        continue
    print(f"Square of {entry} is {int(entry) ** 2}")

3.5. Nested Loops & 2D Matrix Traversal

When loops are nested, the inner loop executes its entire cycle for every single iteration of the outer loop ($N \times M$ total iterations).

# Multiplication table (1 to 3):
for row in range(1, 4):
    for col in range(1, 4):
        print(f"{row * col:2d}", end=" ")
    print()  # Newline after each row

4. Transfer statements (break, continue, pass)

L1 L2

L1 Fundamental

4.1. The break Statement

  • Immediately terminates the execution of the innermost enclosing loop.
  • Program control jumps directly to the first statement immediately following the loop block.
  • Commonly used for early search termination once a target item is found.
# Linear search with early exit:
target: int = 42
numbers: list[int] = [10, 25, 33, 42, 59, 80]

for idx, val in enumerate(numbers):
    if val == target:
        print(f"Found target {target} at index {idx}")
        break  # No need to scan remaining numbers

4.2. The continue Statement

  • Skips the remainder of the current iteration only.
  • Program control jumps to the next iteration (in for, it fetches the next item; in while, it re-evaluates the condition).
  • Used as a filter to bypass invalid or unwanted records without deeply nesting if blocks.
# Print only odd numbers, skip negatives:
data: list[int] = [-4, 7, 12, 15, -2, 9, 20]
for x in data:
    if x <= 0 or x % 2 == 0:
        continue  # Skip negatives and evens
    print(f"Valid odd number: {x}")

4.3. The pass Statement

  • pass is a syntactic no-op (null operation) statement.
  • Python requires non-empty code blocks under headers like if, for, def, and class. pass satisfies the parser when logic is intentionally stubbed for future implementation.
# 'pass' satisfies Python's mandatory block indentation syntax without doing anything:
status: str = "maintenance"
if status == "maintenance":
    pass  # Placeholder: business logic to be added in future release

for item in [10, 20, 30]:
    pass  # Loop stub

L2 Intermediate

4.4. The Loop else Suite (for-else / while-else)

Key Interview Concept: Python uniquely supports an else block on both for and while loops! The else block executes if and only if the loop completed naturally without hitting a break statement. 
# Flag-free prime number check using for-else:
# The else block executes ONLY if the loop completes without hitting 'break'!

# Test 1: n = 17 (Prime number)
n1: int = 17
for d in range(2, int(n1 ** 0.5) + 1):
    if n1 % d == 0:
        print(f"{n1} is divisible by {d} -> Not Prime")
        break
else:
    print(f"{n1} is a PRIME number!")  # Executes because no break occurred!

# Test 2: n = 15 (Composite number)
n2: int = 15
for d in range(2, int(n2 ** 0.5) + 1):
    if n2 % d == 0:
        print(f"{n2} is divisible by {d} -> Not Prime")
        break  # Bypasses the else block!
else:
    print(f"{n2} is a PRIME number!")

How the Nested Loop Engine Operates:

  • Outer Loop (i): Increments after an entire row finishes. It triggers print() to issue a newline (\n) and move down one vertical line.
  • Inner Loop (j): Moves horizontally from left to right along row i. Uses end=" " or end="" to keep prints on the same line.
  • Total Matrix Iterations: N × M steps (e.g. 4 × 4 = 16 total cell decisions).
# Nested loop matrix traversal template:
n: int = 4

    for j in range(n):     # Column index (horizontal)
        # Decision at coordinate (i, j):
        print(f"({i},{j})", end=" ")
    print()                # Row terminator: newline

L1 Fundamental

6.1. Prime Number Verification

A prime number is a positive integer greater than 1 with no positive divisors other than 1 and itself. In optimized loop execution, divisors need only be checked up to ⌊√n⌋.

# Prime Number Verification using while / for and break:
num: int = 29
is_prime: bool = True

if num < 2:
    is_prime = False
else:
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            is_prime = False
            break

print(f"{num} is prime:", is_prime)  # True

6.2. Armstrong (Narcissistic) Number

An Armstrong number of k digits is an integer such that the sum of each digit raised to the power of k equals the number itself (e.g. 153 = 1³ + 5³ + 3³ = 1 + 125 + 27 = 153).

# Armstrong Number Verification using a while loop:
num: int = 153
temp: int = num
num_digits: int = len(str(num))
armstrong_sum: int = 0

while temp > 0:
    digit: int = temp % 10
    armstrong_sum += digit ** num_digits
    temp //= 10

if armstrong_sum == num:
    print(f"{num} is an Armstrong number!")  # True
else:
    print(f"{num} is NOT an Armstrong number.")

6.4. Palindrome Number Check

A palindrome number reads identically forward and backward (e.g. 12321). We can verify it arithmetically without string conversion:

# Palindrome Number Check without string conversion (arithmetic digit reversal):
num: int = 12321
original: int = num
reversed_num: int = 0

while num > 0:
    last_digit: int = num % 10
    reversed_num = (reversed_num * 10) + last_digit
    num //= 10

if original == reversed_num:
    print(f"{original} is a PALINDROME number!")  # True
else:
    print(f"{original} is NOT a palindrome.")

7.1. Problem Statement & Design

A classic computer science challenge testing control flow, integer arithmetic, and string mapping: convert any integer from 0 up to 99,999 into its standard English spoken word representation.

L2 Intermediate

7.2. Complete Python Implementation

test_cases: list[int] = [0, 7, 19, 42, 105, 512, 1000, 4520, 24050, 99999]

units: list[str] = [
    "", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine",
    "Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen",
    "Seventeen", "Eighteen", "Nineteen"
]
tens: list[str] = [
    "", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"
]

for num in test_cases:
    original: int = num
    words_repr: str = ""
    if num == 0:
        words_repr = "Zero"
    else:
        parts: list[str] = []

        # 1. Process Thousands (1 to 99)
        thousands: int = num // 1000
        if thousands > 0:
            t_words: list[str] = []
            if thousands >= 100:
                t_words.append(units[thousands // 100] + " Hundred")
                thousands %= 100
            if 1 <= thousands <= 19:
                t_words.append(units[thousands])
            elif thousands >= 20:
                t_words.append(tens[thousands // 10])
                if thousands % 10 != 0:
                    t_words.append(units[thousands % 10])
            parts.append(" ".join(t_words) + " Thousand")
            num %= 1000

        # 2. Process Remaining Hundreds and below (1 to 999)
        if num > 0:
            h_words: list[str] = []
            if num >= 100:
                h_words.append(units[num // 100] + " Hundred")
                num %= 100
            if 1 <= num <= 19:
                h_words.append(units[num])
            elif num >= 20:
                h_words.append(tens[num // 10])
                if num % 10 != 0:
                    h_words.append(units[num % 10])
            parts.append(" ".join(h_words))

        words_repr = " ".join(parts)

    print(f"{original:>6d} -> {words_repr}")

C. Common questions

L1 L2

L1 Fundamental

C.1. What is the difference between break, continue, and pass? ▾ Answer
  • break: Immediately exits the enclosing loop entirely; no further iterations occur.
  • continue: Aborts only the current iteration and proceeds immediately to the next iteration of the loop.
  • pass: A null operation (no-op) that does nothing. It acts as a syntactic placeholder so an empty block parses without error.
C.2. How does the else block in for-else and while-else work? ▾ Answer

The loop else block executes if and only if the loop completes all iterations normally without encountering a break statement. If a break occurs, the else block is completely skipped. It is ideal for search algorithms where you want fallback behavior if no target was found.

C.3. Why does Python NOT have a traditional C-style for loop (for (int i=0; i<n; i++))? ▾ Answer

Python's for loop is designed around the iterator protocol (PEP 234). Instead of managing low-level index arithmetic (which is prone to off-by-one errors and array bounds violations), Python loops iterate directly over the elements of any iterable object. When numeric indices are required, range() or enumerate() cleanly provides them.

L2 Intermediate

C.4. What happens if you modify a list while iterating over it with a for loop? ▾ Answer

Modifying a list in-place (e.g. via remove() or del) while looping over it alters the underlying index offsets, causing the loop to skip elements or process items multiple times unexpectedly.
Correct Approach: Iterate over a shallow copy of the list (for x in items[:]:) or construct a new filtered list using a list comprehension (items = [x for x in items if keep(x)]).

C.5. How can you break out of multiple nested loops in Python? ▾ Answer

Since break only terminates the innermost loop, breaking out of multiple nested loops can be achieved cleanly in three ways:

  1. Refactor into a function: Use a return statement to exit all loops simultaneously (recommended).
  2. Use loop else with break: Have the inner loop break, and check a flag in the outer loop or re-trigger a break in the outer loop.
  3. Raise an exception: Catch a custom exception outside the outer loop.

C.6. What is the difference between pass and ... (Ellipsis)? ▾ Answer

pass is a statement that does nothing. ... (Ellipsis) is an actual singleton object of type ellipsis. While both can syntactically serve as empty body placeholders, ... is also used in type annotations (Callable[..., int]) and multidimensional slicing in NumPy.

C.7. Why is range(1000000000) memory efficient in Python 3? ▾ Answer

In Python 3, range is an immutable sequence type that calculates numbers dynamically on-demand using arithmetic (storing only start, stop, and step). It consumes only 48 bytes of memory regardless of whether the range contains 10 items or 10 billion items (unlike Python 2's range() which eagerly created an entire list in RAM).

C.8. How does Python's match-case differ from C/Java's switch? ▾ Answer

Python's match-case does not have implicit fall-through (no break is needed between cases). More importantly, it performs structural destructuring: it can unpack lists, tuples, and objects, match nested types, and bind sub-components to local variables in a single expression.
