Python

Notes for core Python, mapped to a full classroom / video syllabus and arranged in learning order.

L1 Fundamental L2 Intermediate L3 Advanced
  • Prerequisite: none for basics. Helpful if you know another language — see JavaScript Language for parallel concepts.
  • Scope: this track covers the full concept list from the source video course (intro → OOP → threads → regex → DB → serialization → logging → testing → pydoc). Personality-development sessions are out of scope.
  • Default rule today: use a venv, prefer f-strings, master built-in collections and OOP, then add files, exceptions, concurrency, and tooling as needed.
All chapters 01–32 use 1. Introduction, numbered topics, then C. Common questions and P. Practical Assignment. Files 01–05 have full notes; 06–32 have outline stubs plus practice — expand notes over time. Checklist: notes.txt.
Try it in the browser: open the Python Playground to run snippets with a vendored Pyodide runtime (no install, no CDN). Stdlib / pure-Python only in v1.

Learning Path

Read files in order 01 → 32. For each pass, stay at one depth across many concepts instead of finishing one file to L3 first.

Pass 1 → L1 across 01–18, 23     Core language, collections, functions, modules, files, OOP basics, exceptions
Pass 2 → L2 across 14–23, 25–32  Functional tools, inheritance, polymorphism, decorators, generators, copy, regex, DB, tooling
Pass 3 → L3 on 20, 24            Deep OOP edge cases and multithreading
Each file uses relative section numbers like 1., 1.1., and 1.1.1. within that file. Levels are a default guide, not a rigid wall.
