3. int, float, complex, bool, None

L1

L1 Fundamental

3.1. int

  • Arbitrary precision integers (no fixed 32/64-bit limit in CPython for normal ints).
a = 10
b = 0b1010      # binary → 10
c = 0o12        # octal → 10
d = 0xA         # hex → 10
big = 10**100   # OK

3.2. float

  • IEEE floating point — approximate decimals.
x = 3.14
y = 1.5e2       # 150.0
0.1 + 0.2       # 0.30000000000000004 — classic float quirk

3.3. complex

z = 2 + 3j
z.real          # 2.0
z.imag          # 3.0

3.4. bool

  • Subclass of int: True == 1, False == 0.
True + True     # 2
bool(0)         # False
bool("hi")      # True
bool("")        # False

3.5. None

  • Singleton meaning “no value.” Default return of functions with no return.
x = None
x is None       # True — preferred check
# x == None     # works but prefer `is`

4. Immutability concepts

L1

L1 Fundamental

  • Immutable — object contents cannot change after creation: int, float, bool, str, tuple, frozenset, bytes.
  • Mutable — can change in place: list, dict, set, bytearray.
a = 10
print(id(a))
a = a + 1       # new int object; name `a` rebound
print(id(a))    # usually different id

s = "hi"
# s[0] = "H"    # TypeError — str immutable

lst = [1, 2]
print(id(lst))
lst.append(3)   # same list object mutated
print(id(lst))  # same id
  • Reassignment (a = …) always rebinds the name. Mutation changes the object the name still points to.
  • Aliasing / shallow / deep copy: File 25.

5. range and sequence forms

L1 L2

L1 Fundamental

  • range is an immutable sequence of integers — lazy (does not build a full list).
range(5)          # 0..4
range(1, 5)       # 1..4
range(1, 10, 2)   # 1, 3, 5, 7, 9
list(range(3))    # [0, 1, 2]

L2 Intermediate

  • Forms: range(stop), range(start, stop), range(start, stop, step). stop is exclusive. Negative step allowed.
list(range(5, 0, -1))  # [5, 4, 3, 2, 1]
len(range(1_000_000))  # cheap — no million-element list

6. Bytes / bytearray (intro)

L1 L2

L1 Fundamental

  • bytes — immutable sequence of bytes (0–255). bytearray — mutable version.
b = b"hi"
ba = bytearray(b"hi")
ba[0] = ord("H")
print(ba)          # bytearray(b'Hi')

L2 Intermediate

  • Text uses str; binary files / protocols use bytes. Encode/decode: "hi".encode("utf-8"), b"hi".decode("utf-8"). More in Files 08 and 17.

C. Common questions

L1 L2

L1 Fundamental

C.1. How do I check a type?

  • A: Prefer isinstance(x, int) over type(x) == int (handles subclasses). For exact type, type(x) is int.

C.2. Why is bool a subclass of int?

  • A: Historical design — booleans participate in arithmetic. Prefer clear boolean logic over relying on that.

L2 Intermediate

C.3. Does a = a + 1 mutate the int?

  • A: No. Integers are immutable. A new int is created and the name is rebound.
