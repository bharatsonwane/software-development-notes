3. Fundamental Type Casting & Constructors

L1 L2

L1 Fundamental

Python provides 5 built-in constructor functions to perform explicit type casting between scalar types: int(), float(), complex(), bool(), and str().

3.1. int() Casting Rules

  • From float: Truncates the fractional digits toward zero (int(10.99) -> 10, int(-10.99) -> -10). It does not perform mathematical rounding.
  • From complex: CANNOT be converted to int. Raises TypeError: can't convert complex to int. (To extract the real integer, use int(z.real)).
  • From bool: int(True) -> 1, int(False) -> 0.
  • From str: The string must strictly represent an integer literal in base-10:
    • Valid: int("10") -> 10, int("-5") -> -5, int(" 42 ") -> 42 (leading/trailing spaces are stripped).
    • Invalid (raises ValueError): Strings with decimal points (int("10.5")), alphabetic words (int("ten")), or binary/hex prefixes (int("0b1111") without explicit base parameter).
# --- int() Conversion Examples ---
print(int(15.89))      # 15 (truncated)
print(int(-15.89))     # -15 (truncated toward zero)
print(int(True))       # 1
print(int(False))      # 0
print(int("100"))      # 100

# Errors:
# int(10 + 5j)         # TypeError: can't convert complex to int
# int("10.5")          # ValueError: invalid literal for int() with base 10: '10.5'
# Fix for float string:
print(int(float("10.5")))  # 10

3.2. float() Casting Rules

  • From int: Converts integer to float with .0 (float(10) -> 10.0).
  • From complex: CANNOT be converted to float. Raises TypeError: can't convert complex to float.
  • From bool: float(True) -> 1.0, float(False) -> 0.0.
  • From str: Can convert strings containing integers, decimal fractions, scientific exponential notation, or infinity/NaN:
    float("10") -> 10.0, float("10.5") -> 10.5, float("1.2e3") -> 1200.0, float("inf") -> inf. 
# --- float() Conversion Examples ---
print(float(50))         # 50.0
print(float(True))       # 1.0
print(float(False))      # 0.0
print(float("3.14159"))  # 3.14159
print(float("2.5e-3"))   # 0.0025
print(float("inf"))      # inf

# Errors:
# float(10 + 2j)         # TypeError: can't convert complex to float
# float("abc")           # ValueError: could not convert string to float: 'abc'

L2 Intermediate

3.3. complex() Casting Rules & Whitespace Pitfall

The complex() constructor has two primary call forms:

  1. Form 1 — complex(real): Returns real + 0j. Can take int, float, or bool (complex(10) -> (10+0j), complex(True) -> (1+0j)).
  2. Form 2 — complex(real, imag): Returns real + imag*j (complex(10, -2) -> (10-2j), complex(True, False) -> (1+0j)).
Classroom Trap — The Complex String Whitespace Syntax Bug: When converting a string representation to complex using complex("10+5j"), there MUST NOT be any whitespace surrounding the + or - operator inside the string!
• complex("10+5j") → (10+5j) (Valid)
• complex("10 + 5j") → ValueError: complex() arg is a malformed string 
# --- complex() Examples ---
print(complex(10))        # (10+0j)
print(complex(10.5))      # (10.5+0j)
print(complex(True))      # (1+0j)
print(complex(10, 20))    # (10+20j)
print(complex(1.5, -2.5)) # (1.5-2.5j)

# String conversions:
print(complex("10+20j"))  # (10+20j) - No spaces around '+'
print(complex("5.5-3.2j"))# (5.5-3.2j)

# Whitespace Syntax Pitfall:
# complex("10 + 20j")     # ValueError: complex() arg is a malformed string

# Second argument cannot be string:
# complex(10, "20")       # TypeError: complex() second arg can't be string
# complex("10", "20")     # TypeError: complex() can't take second arg if first is a string

3.4. bool() Truthiness Rules

Any object in Python can be evaluated by bool(x). The rules are absolute:

Data Type Falsy Values (bool(x) == False) Truthy Values (bool(x) == True)
Numbers (int, float, complex) Zero: 0, 0.0, 0j, 0.0 + 0.0j Any non-zero value: 1, -10, 0.0001, 0.1j
Strings (str) Empty string: "", '' Any string with length ≥ 1: "hello", " " (space), "0", "False"
Collections (list, tuple, set, dict) Empty collections: [], (), set(), {}, range(0) Any non-empty collection: [0], (False,), {"a": 0}
Special None, False True, valid functions, objects, modules

3.5. str() Casting

  • The str() constructor converts any Python object into its human-readable string representation by invoking the object's __str__() dunder method.
print(str(100))        # "100"
print(str(10.5))       # "10.5"
print(str(True))       # "True"
print(str(10 + 5j))    # "(10+5j)"
print(str([1, 2, 3]))  # "[1, 2, 3]"
print(str(None))       # "None"

3.6. Collection Type Casting

Python provides constructors to convert between sequence and collection types seamlessly:

Constructor Source Type Examples Output Type & Characteristics
list(iterable) list("abc"), list((1, 2, 3)), list({1, 2}) Mutable ordered list (['a', 'b', 'c']).
tuple(iterable) tuple([1, 2, 3]), tuple("xy") Immutable ordered tuple ((1, 2, 3)).
set(iterable) set([1, 2, 2, 3, 1]) Mutable unordered set; automatically removes duplicates ({1, 2, 3}).
frozenset(iterable) frozenset([1, 2, 3]) Immutable set; hashable and can be used as dict keys.
dict(pairs) dict([("a", 1), ("b", 2)]) Key-value mapping. Argument must be an iterable of 2-item key-value pairs. 
# Converting string to list of characters:
chars = list("Python")
print("list('Python'):", chars)  # ['P', 'y', 't', 'h', 'o', 'n']

# Removing duplicates using set():
duplicates = [10, 20, 20, 30, 10, 40]
unique_list = list(set(duplicates))
print("Deduplicated:   ", unique_list)

# Constructing dict from key-value tuples:
pairs = [("roll", 101), ("name", "Alice"), ("active", True)]
student = dict(pairs)
print("dict(pairs):    ", student)  # {'roll': 101, 'name': 'Alice', 'active': True}

4. Base conversions and pitfalls

L1 L2

L1 Fundamental

  • int(string, base) parses digits in a given base (2–36):
int("1010", 2)   # 10
int("FF", 16)    # 255
int("17", 8)     # 15
  • Format ints as other bases:
bin(10)   # '0b1010'
oct(10)   # '0o12'
hex(10)   # '0xa'
format(10, "b")  # '1010' without prefix

L2 Intermediate

4.1. Pitfalls

  • int(" 42 ") works (whitespace stripped); int("42abc") raises ValueError.
  • Float→int truncates; use round() if you need rounding.
  • bool("False") is True — non-empty string. Parse carefully for user input.
  • Implicit numeric conversion in mixed arithmetic: 1 + 2.5 → float. True + 1 → 2.

C. Common questions

L1 L2

L1 Fundamental

C.1. What does int(3.9) return? ▾ Answer

3 — truncates toward zero, does not round.

C.2. How do I convert user input to a number? ▾ Answer

n = int(input("n: ")) or wrap in try/except ValueError (File 24).

L2 Intermediate

C.3. Why is bool("0") True? ▾ Answer

Only empty string is falsy among strings. "0" is non-empty. Use int("0") then compare, or compare the string explicitly.

C.4. Can we convert a complex number to an int or float using int() or float()? ▾ Answer

No. Attempting int(10+5j) or float(10+5j) raises TypeError: can't convert complex to int or TypeError: can't convert complex to float. Complex numbers contain two distinct components; to convert, explicitly access the attribute first: int(z.real).

C.5. Why does complex("10 + 20j") raise a ValueError while complex("10+20j") works? ▾ Answer

Python's internal parser for complex string conversions strictly prohibits spaces surrounding the + or - sign. complex("10+20j") parses correctly, but complex("10 + 20j") fails with ValueError: complex() arg is a malformed string.

C.6. Why does int("10.5") raise a ValueError while int(10.5) succeeds? ▾ Answer

int(10.5) takes an existing float object and truncates its fractional part to produce 10. However, int("10.5") treats the input as a string literal representing a base-10 integer; because '.' is not a valid integer digit, it raises ValueError. To convert safely, nest conversions: int(float("10.5")).

s = "42"
val_int = int(s)
print(f"int('{s}') ->", val_int, type(val_int))

f = 3.9

print("int(True):", int(True))    # 1

  3. Use int("1010", 2) and hex/bin/oct helpers. ▾ Solution

n = int("1010", 2)

# Conversion helpers:
num = 42
print("bin:", bin(num))  # '0b101010'

P.2. Core tasks

  1. safe int conversion checks — Check and convert strings to int, handling non-digits and float strings safely. ▾ Solution 
    # Demonstrating safe string-to-int conversion:
# Case 1: Pure digits (succeeds directly)
s1 = "123"
num1 = int(s1) if s1.isdigit() else None
print(f"s1={s1!r} -> {num1}")  # 123

# Case 2: Alphabetic text (rejected safely)
s2 = "abc"
num2 = int(s2) if s2.isdigit() else None
print(f"s2={s2!r} -> {num2}")  # None

# Case 3: Float string (requires two-step float-then-int conversion)
s3 = "12.5"
# Direct int("12.5") raises ValueError; two-step conversion truncates cleanly:
num3 = int(float(s3))
print(f"s3={s3!r} -> {num3}")  # 12
  2. to_bool mapping — Convert common user inputs ("yes", "no", "1", "0") to bool using membership checks. ▾ Solution 
    # Mapping user string inputs to booleans using membership checks:
true_inputs = ("1", "true", "yes", "y", "on")
false_inputs = ("0", "false", "no", "n", "off")

val1 = "yes"
is_active1 = val1.strip().lower() in true_inputs
print(f"Input: {val1!r} -> Boolean: {is_active1}")  # True

val2 = "0"
is_active2 = val2.strip().lower() in true_inputs
print(f"Input: {val2!r} -> Boolean: {is_active2}")  # False

val3 = "TRUE"
is_active3 = val3.strip().lower() in true_inputs
print(f"Input: {val3!r} -> Boolean: {is_active3}")  # True
  3. float money — Parse "12.50" to float; format back with 2 decimals. ▾ Solution 
    # Parsing currency string and formatting back:
price_str = "12.50"
price = float(price_str)
tax = price * 0.08
total = price + tax

# Format back with 2 decimal places:
print(f"Subtotal: ${price:.2f}")
print(f"Tax (8%):  ${tax:.2f}")
print(f"Total:     ${total:.2f}")
  4. base table — Print 0–15 in binary, octal, hex. ▾ Solution 
    # Base table: 0 to 15 in Decimal, Binary, Octal, Hexadecimal
print(f"{'Dec':<5} {'Binary':<8} {'Octal':<6} {'Hex':<4}")
print("-" * 25)
for i in range(16):
    print(f"{i:<5} {bin(i):<8} {oct(i):<6} {hex(i):<4}")

P.3. Challenge

  1. Show a pitfall: float("nan") or int("3.14") behavior; comment the rule. ▾ Solution 
    # Pitfall 1: int() fails directly on float strings:
# int("3.14") -> ValueError: invalid literal for int() with base 10: '3.14'
# Proper fix: convert to float first, then int:
print("int(float('3.14')):", int(float("3.14")))

# Pitfall 2: float('nan') never equals itself:
nan_val = float("nan")
print("nan == nan:", nan_val == nan_val)  # False!
import math
print("math.isnan(nan):", math.isnan(nan_val))  # True
  2. Convert between str and bytes with encode/decode for utf-8. ▾ Solution 
    # UTF-8 Encoding and Decoding between str and bytes:
text = "Hello, Python! 🐍"  # Includes snake emoji
print("Original str:", text)

# String to bytes (encode):
encoded_bytes = text.encode("utf-8")
print("Encoded bytes:", encoded_bytes)

# Bytes back to string (decode):
decoded_str = encoded_bytes.decode("utf-8")
print("Decoded str:", decoded_str)
print("Matches original:", text == decoded_str)
