2. Casting between fundamental types

L1

L1 Fundamental

  • Python does not auto-convert incompatible types in all cases (e.g. "5" + 1 raises TypeError). Convert first.
"5" + "1"       # "51" — string concat
# "5" + 1       # TypeError
int("5") + 1    # 6

3. int / float / complex / bool / str

L1

L1 Fundamental

3.1. int()

int(3.9)        # 3 — truncates toward zero
int("42")       # 42
int(True)       # 1
# int("3.14")   # ValueError — use float first
int(float("3.14"))  # 3

3.2. float()

float(10)       # 10.0
float("3.14")   # 3.14
float("1e2")    # 100.0

3.3. complex()

complex(2, 3)   # (2+3j)
complex("1+2j") # (1+2j)

3.4. bool()

  • Falsy: False, 0, 0.0, 0j, None, "", [], {}, set(), empty ranges, etc. Everything else is truthy.
bool(0)         # False
bool(1)         # True
bool([])        # False
bool([0])       # True — non-empty list

3.5. str()

str(42)         # "42"
str(3.14)       # "3.14"
str(True)       # "True"
str(None)       # "None"

3.6. Collection constructors (preview)

list("abc")     # ["a", "b", "c"]
tuple([1, 2])   # (1, 2)
set([1, 1, 2])  # {1, 2}
dict([("a", 1)])  # {"a": 1}

4. Base conversions and pitfalls

L1 L2

L1 Fundamental

  • int(string, base) parses digits in a given base (2–36):
int("1010", 2)   # 10
int("FF", 16)    # 255
int("17", 8)     # 15
  • Format ints as other bases:
bin(10)   # '0b1010'
oct(10)   # '0o12'
hex(10)   # '0xa'
format(10, "b")  # '1010' without prefix

L2 Intermediate

4.1. Pitfalls

  • int(" 42 ") works (whitespace stripped); int("42abc") raises ValueError.
  • Float→int truncates; use round() if you need rounding.
  • bool("False") is True — non-empty string. Parse carefully for user input.
  • Implicit numeric conversion in mixed arithmetic: 1 + 2.5 → float. True + 1 → 2.

C. Common questions

L1 L2

L1 Fundamental

C.1. What does int(3.9) return? ▾ Answer

3 — truncates toward zero, does not round.

C.2. How do I convert user input to a number? ▾ Answer

n = int(input("n: ")) or wrap in try/except ValueError (File 24).

L2 Intermediate

C.3. Why is bool("0") True? ▾ Answer

Only empty string is falsy among strings. "0" is non-empty. Use int("0") then compare, or compare the string explicitly.

P.1. Warm-up

  1. Cast "42" to int and 3.9 to int; note truncation. ▾ Solution 
    # Casting string to int:
s = "42"
val_int = int(s)
print(f"int('{s}') ->", val_int, type(val_int))

# Float to int truncation (drops decimals, no rounding):
f = 3.9
trunc = int(f)
print(f"int({f}) ->", trunc, "(truncated toward zero)")
  2. Cast True/False to int. ▾ Solution 
    # Casting boolean values to int:
print("int(True):", int(True))    # 1
print("int(False):", int(False))  # 0
print("float(True):", float(True)) # 1.0
  3. Use int("1010", 2) and hex/bin/oct helpers. ▾ Solution 
    # Base conversions:
# Binary string to int (base 2):
n = int("1010", 2)
print("int('1010', 2):", n)  # 10

# Conversion helpers:
num = 42
print("bin:", bin(num))  # '0b101010'
print("oct:", oct(num))  # '0o52'
print("hex:", hex(num))  # '0x2a'

P.2. Core tasks

  1. safe_int(s) — Return int or None if conversion fails. ▾ Solution 
    def safe_int(s):
    """Safely convert string to int; return None on failure."""
    try:
        return int(s)
    except (ValueError, TypeError):
        return None

print(safe_int("123"))    # 123
print(safe_int("abc"))    # None
print(safe_int("12.5"))   # None (float string cannot be directly cast with int())
print(safe_int(None))     # None
  2. to_bool — Convert common strings "yes"/"no"/"1"/"0" to bool. ▾ Solution 
    def to_bool(val):
    """Convert common user inputs ('yes', 'no', '1', '0') to bool."""
    if isinstance(val, bool):
        return val
    s = str(val).strip().lower()
    if s in ("1", "true", "yes", "y", "t", "on"):
        return True
    if s in ("0", "false", "no", "n", "f", "off"):
        return False
    raise ValueError(f"Cannot convert {val} to boolean")

print(to_bool("yes"))  # True
print(to_bool("0"))    # False
print(to_bool("TRUE")) # True
  3. float money — Parse "12.50" to float; format back with 2 decimals. ▾ Solution 
    # Parsing currency string and formatting back:
price_str = "12.50"
price = float(price_str)
tax = price * 0.08
total = price + tax

# Format back with 2 decimal places:
print(f"Subtotal: ${price:.2f}")
print(f"Tax (8%):  ${tax:.2f}")
print(f"Total:     ${total:.2f}")
  4. base table — Print 0–15 in binary, octal, hex. ▾ Solution 
    # Base table: 0 to 15 in Decimal, Binary, Octal, Hexadecimal
print(f"{'Dec':<5} {'Binary':<8} {'Octal':<6} {'Hex':<4}")
print("-" * 25)
for i in range(16):
    print(f"{i:<5} {bin(i):<8} {oct(i):<6} {hex(i):<4}")

L2 Intermediate

P.3. Challenge

  1. Show a pitfall: float("nan") or int("3.14") behavior; comment the rule. ▾ Solution 
    # Pitfall 1: int() fails directly on float strings:
# int("3.14") -> ValueError: invalid literal for int() with base 10: '3.14'
# Proper fix: convert to float first, then int:
print("int(float('3.14')):", int(float("3.14")))

# Pitfall 2: float('nan') never equals itself:
nan_val = float("nan")
print("nan == nan:", nan_val == nan_val)  # False!
import math
print("math.isnan(nan):", math.isnan(nan_val))  # True
  2. Convert between str and bytes with encode/decode for utf-8. ▾ Solution 
    # UTF-8 Encoding and Decoding between str and bytes:
text = "Hello, Python! 🐍"  # Includes snake emoji
print("Original str:", text)

# String to bytes (encode):
encoded_bytes = text.encode("utf-8")
print("Encoded bytes:", encoded_bytes)

# Bytes back to string (decode):
decoded_str = encoded_bytes.decode("utf-8")
print("Decoded str:", decoded_str)
print("Matches original:", text == decoded_str)
