P.1. Warm-up

  1. Skim the section map; write a 3-bullet comment summarizing Anonymous / lambda functions. ▾ Solution 
    # Summary of Anonymous / Lambda Functions:
# 1. Lambdas are small, anonymous one-expression functions created using 'lambda args: expression'.
# 2. They cannot contain statements (no if/else blocks, assignments, or multiple lines).
# 3. Best suited for short throwaway functions passed into higher-order utilities (filter, map, sorted).
  2. Create a tiny example related to filter() with lambda and print the result. ▾ Solution 
    # filter() with lambda:
numbers = [12, 7, 19, 24, 33, 40, 55, 60]
# Filter numbers divisible by 6:
div_by_6 = list(filter(lambda x: x % 6 == 0, numbers))
print("Divisible by 6:", div_by_6)  # [12, 24, 60]

P.2. Core tasks

  1. Task 1: Anonymous / lambda functions — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 1: Anonymous / lambda functions
# Basic lambda syntax:
multiply = lambda a, b: a * b
is_even = lambda n: n % 2 == 0
get_last_char = lambda s: s[-1] if s else ""

print("multiply(6, 7):", multiply(6, 7))
print("is_even(14):", is_even(14))
print("get_last_char('Python'):", get_last_char("Python"))

# Custom sort key using lambda:
users = [("Alice", 25), ("Bob", 19), ("Charlie", 32)]
users.sort(key=lambda u: u[1])  # Sort by age
print("Sorted by age:", users)
  2. Task 2: filter() with lambda — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 2: filter() with lambda
data = ["apple", "", "banana", None, "cherry", False, "date"]
# Filter out truthy non-empty strings:
valid_words = list(filter(lambda item: isinstance(item, str) and len(item) > 0, data))
print("Valid words:", valid_words)

# Filter prime candidates (odd numbers > 2):
numbers = range(1, 20)
odd_gt_2 = list(filter(lambda x: x > 2 and x % 2 != 0, numbers))
print("Odd numbers > 2:", odd_gt_2)
  3. Task 3: map() with lambda — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 3: map() with lambda
prices_usd = [19.99, 49.50, 99.00, 150.25]
tax_rate = 1.08

# Calculate final price including tax:
final_prices = list(map(lambda p: round(p * tax_rate, 2), prices_usd))
print("Prices with tax:", final_prices)

# Parallel map across two iterables:
first_names = ["Bharat", "John", "Sarah"]
last_names = ["Sonwane", "Doe", "Smith"]
full_names = list(map(lambda fn, ln: f"{fn} {ln}", first_names, last_names))
print("Full names:", full_names)
  4. Task 4: reduce() (functools) — Write a small working demo (10–20 lines) covering the idea; print outputs. ▾ Solution 
    # Task 4: reduce() (functools)
from functools import reduce

nums = [1, 2, 3, 4, 5]

# Cumulative product (factorial of 5):
product = reduce(lambda acc, x: acc * x, nums)
print("Product (1*2*3*4*5):", product)  # 120

# Find maximum element using reduce:
values = [42, 17, 99, 83, 25]
maximum = reduce(lambda a, b: a if a > b else b, values)
print("Maximum value:", maximum)  # 99

P.3. Challenge

  1. Mini project — Combine two topics from this file into one short script related to Lambda, filter, map, reduce. ▾ Solution 
    # Mini Project: Functional Data Processing Pipeline
from functools import reduce

transactions = [
    {"id": 1, "type": "DEPOSIT", "amount": 1000.0},
    {"id": 2, "type": "WITHDRAWAL", "amount": 250.0},
    {"id": 3, "type": "DEPOSIT", "amount": 500.0},
    {"id": 4, "type": "FEE", "amount": 15.0},
    {"id": 5, "type": "DEPOSIT", "amount": 750.0}
]

# 1. filter() deposits:
deposits = filter(lambda t: t["type"] == "DEPOSIT", transactions)

# 2. map() extract amounts:
amounts = map(lambda t: t["amount"], deposits)

# 3. reduce() calculate total:
total_deposits = reduce(lambda acc, val: acc + val, amounts, 0.0)

print(f"Total verified deposits: ${total_deposits:,.2f}")
  2. Edge cases — List 3 edge cases or mistakes beginners make; demonstrate at least one safely. ▾ Solution 
    # Lambda & Functional Pitfalls:
# 1. Late binding in closures inside loops:
funcs = [lambda: i for i in range(3)]
print("Late binding pitfall:", [f() for f in funcs])  # [2, 2, 2] !
# Fix: default argument forces early binding:
fixed_funcs = [lambda i=i: i for i in range(3)]
print("Fixed early binding:", [f() for f in fixed_funcs])  # [0, 1, 2]

# 2. Don't overuse lambda where list comprehensions are clearer:
# Prefer: [x * 2 for x in nums] over list(map(lambda x: x * 2, nums))
