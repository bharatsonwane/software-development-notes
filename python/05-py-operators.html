05. Operators

File 05 — arithmetic, relational, logical, bitwise, membership, identity, precedence.

L1 Fundamental

  • Operators combine values into expressions. Python’s set is similar to other languages, with important details: / vs //, and/or/not (words, not &&), and is vs ==.

L1 Fundamental

Default rule today: use == for value equality, is only for None (and similar singletons). Prefer and/or/not for boolean logic.

4. Membership (in) and identity (is)

L1 L2

L1 Fundamental

4.1. in / not in

"a" in "cat"        # True
3 in [1, 2, 3]      # True
"x" not in {"a": 1} # True — checks keys

4.2. is / is not

  • is tests object identity (same object in memory), not equality of value.
a = [1, 2]
b = a
c = [1, 2]
a is b          # True — same object
a is c          # False
a == c          # True — same contents

x = None
x is None       # correct None check

L2 Intermediate

  • Small ints / interned strings may share identity for equal values — do not rely on is for ints/strings. Use ==.
a = 256
b = 256
a is b          # often True (implementation detail)

a = 257
b = 257
a is b          # often False — use ==

6. Common questions

L1 L2

L1 Fundamental

6.1. Difference between / and //?

  • A: / always does true (float) division in Python 3. // does floor division.

6.2. Difference between == and is?

  • A: == compares values. is compares identity. Use is for None.

L2 Intermediate

6.3. What do and/or return?

  • A: The last evaluated operand — not necessarily True/False. Useful for defaults: name or "Guest".

6.4. Why is -5 // 2 equal to -3?

  • A: Floor division rounds toward negative infinity, not toward zero.
